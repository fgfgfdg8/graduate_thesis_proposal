# ChunkTrojan 与 RAGShield：离线分块协同投毒与来源稳健证据推理

> 本方案研究外部文档经过分块、检索与上下文组装后形成的协同投毒，以及面向多类语料污染的证据级防御。攻击采用本地影子系统上的离线黑盒优化；防御依据来源、事实支持与证据稳定性作出判断。算法效果与迁移能力由后续实验验证，数学结论分别服务于搜索、计算复用和条件稳健性。

# 第一部分：攻击侧 —— ChunkTrojan

## 一、问题建模与严格离线威胁模型

### 1.1 系统、观察量与实验分离

设真实目标系统为 $\mathcal R^\star=(\phi^\star,f_r^\star,f_g^\star)$，分别包含分块器、检索器和生成器。攻击者只能通过目标系统的公开输入/输出接口交互，不能修改目标分块器、检索器或生成器参数，也不能读取目标检索分数、排名或生成 logprob。攻击者事先获得待研究的查询集合 $\mathcal Q$，并能在本地建立完全可控的白盒影子系统：

$$\widetilde{\mathcal R}=(\widetilde\phi,\widetilde f_r,G_{\mathrm{build}},\widetilde f_g).$$

$G_{\mathrm{build}}$ 产生和改写完整载荷文档，$\widetilde f_g$ 是提供攻击反馈的本地影子生成器。后文“受害 LLM 的回答”均指这个影子生成器。优化算法只消费影子系统公开的分块文本与位置、检索分数与排名、构造 LLM 的文本输出及影子生成器的最终文本回答；独立 GPT-2 质量模型只返回局部 NLL 标量。算法不消费目标或影子受害 LLM 的 token logprob、隐藏状态、注意力或梯度，也不把最终 embedding 向量作为候选图特征。**候选生成、筛选、参数选择、停止和最优载荷选择全过程不调用真实目标系统。** 冻结载荷后的目标迁移评测属于独立实验；若执行，只记录公开回答，不读取目标检索分数或排名，且其输出不返回优化器。

本地影子系统允许完全控制与检查，优化器仍把观察限制在上述接口量，以保持算法不依赖特定模型内部表示。GP 的均值、方差属于优化器自己拟合的统计量，不是目标系统输出。

### 1.2 单源篡改与正常检索

主威胁模型是篡改少量现有文档。设 $S\subset\mathcal D_{\mathrm{clean}}$ 为可写源文档，$|S|\ll|\mathcal D_{\mathrm{clean}}|$，则：

$$\mathcal D_x=(\mathcal D_{\mathrm{clean}}\setminus S)\cup\{D_s^{\mathrm{adv}}(x):D_s\in S\}.$$

攻击预算以被篡改/注入文档数计，且远小于干净语料规模；主实验以替换少量现有源文档为准，新增文档模式作为单独的辅助威胁模型。两种模式分别记账，不混用正确证据保留情况。一对协同角色必须先在同一个完整 $D_s^{\mathrm{adv}}$ 中构造，再由 victim chunker 产生不同块。载体选择采用原始文档 **>512 tokens** 的条件。

设 $\phi\in\Phi_{\mathrm{main}}$ 为本地主流分块配置，包含窗口 L、重叠 O、偏移和句界规则。影子检索生成的上下文为：

$$C_x(q,\phi)=\operatorname{OrderedTopK}_{c\in\biguplus_{D\in\mathcal D_x}\phi(D)}\widetilde s(q,c),\qquad y_x=\widetilde f_g(q,C_x),$$

其中 Top-K 按分数降序排列；分数相同时以固定的 $(source\_id,document\_version,chunk\_id,offset)$ 字典序打破平分。候选分数、上下文截断和 ties 均按同一规则缓存。

$\biguplus$ 表示保留文档身份、偏移和版本的块集合，$\widetilde s$ 是本地余弦相似度。所有新块，包括短尾块，参与排序；最终上下文保留排序与实际截断规则。原文档旧块在替换实验中整体移除。

### 1.3 核心机制与载荷实例

ChunkTrojan 的核心是：**攻击意图写入同一来源文档中的多个角色片段；分块后，各片段在不同检索块中共同进入上下文，使生成结果表现出可测的联合效应。** 角色可表达实体关系与属性、适用条件与规则、引用对象与结论，或约束与候选解。构造器先在完整文档中安排关系，再按受害分块配置检查角色落点。

令 $A,B$ 为同源文档经分块后落入两个不同 chunk 的角色片段。固定查询、system/user prompt、解码参数和两个上下文槽位；背景 $C$ 含相同的其余证据与长度匹配的中性占位块。对顺序 $\omega\in\{AB,BA\}$，$y_{0,\omega},y_{A,\omega},y_{B,\omega},y_{AB,\omega}$ 分别表示两槽均占位、只放 A、只放 B、按 $\omega$ 放入 A/B 时的回答；单角色条件保留另一槽位的占位块，使位置和上下文长度匹配。设 $g(y,a_q^*)\in[0,1]$ 为冻结答案判定器对目标答案的匹配分数，且 $a_q^*\not\equiv y_{\mathrm{true}}$。对两个顺序取平均，令 $\bar g_{AB}=\frac12\sum_\omega g(y_{AB,\omega},a_q^*)$，$\bar g_A=\frac12\sum_\omega g(y_{A,\omega},a_q^*)$，$\bar g_B=\frac12\sum_\omega g(y_{B,\omega},a_q^*)$，$\bar g_0=\frac12\sum_\omega g(y_{0,\omega},a_q^*)$。联合增益与基线校正交互为：

$$\Delta_{\mathrm{joint}}=\bar g_{AB}-\max\{\bar g_A,\bar g_B\},\qquad
\Delta_{\mathrm{int}}=\frac12\sum_{\omega\in\{AB,BA\}}\left[g(y_{AB,\omega},a_q^*)-g(y_{A,\omega},a_q^*)-g(y_{B,\omega},a_q^*)+g(y_{0,\omega},a_q^*)\right].$$

$\Delta_{\mathrm{joint}}>0$ 只说明平均联合条件优于最佳单角色；只有 $\Delta_{\mathrm{int}}>0$ 才表示相对于固定背景和两种单角色效应存在正的非加和交互。另构造匹配随机块 R：它不承载 A/B 所需关系，但按预先固定容差匹配 B 的查询相似度、检索分数、长度与上下文位置。令 $y_{R,\omega},y_{AR,\omega}$ 表示相同顺序布局下的 R-only 和 A/R 回答。其交互及载荷特异交互为：

$$\Delta_{\mathrm{int}}^{\mathrm{rand}}=\frac12\sum_{\omega\in\{AB,BA\}}\left[g(y_{AR,\omega},a_q^*)-g(y_{A,\omega},a_q^*)-g(y_{R,\omega},a_q^*)+g(y_{0,\omega},a_q^*)\right],\qquad
\Delta_{\mathrm{specific}}=\Delta_{\mathrm{int}}-\Delta_{\mathrm{int}}^{\mathrm{rand}}.$$

主要报告 AB/BA 各自交互、$\Delta_{\mathrm{joint}}$、$\Delta_{\mathrm{int}}$ 与 $\Delta_{\mathrm{specific}}$，不以挑选最大顺序替代预注册的平均交互。强核心机制见证要求两种单角色位置下 A-only 与 B-only 均为 UNKNOWN，至少一种联合顺序给出目标答案，且 $\Delta_{\mathrm{int}}>0$、$\Delta_{\mathrm{specific}}>0$；未满足 UNKNOWN 条件的样本仍可用于报告较弱的组合效应，但不计作这一强见证。所有 forced-context 指标都是固定上下文下的有限对比，不等同于总体因果效应。自然 Top-K 条件另行测量，必须先经真实检索共同召回后直接生成，不能以强制拼接结果替代。

`UNKNOWN→KNOWN` 因而保留为本研究的强核心目标，不由提示格式或 key-value 结构限定。key-value 只是便于控制角色边界和关系绑定的一种载荷实例；其他关系模板使用同一套跨块、非泄漏与交互测量。

## 二、 优化目标

本节保留草案2的周期性原子载荷、端到端联合目标、生成奖励、共同检索项与边界平移项，并统一其离线计算口径。

### 2.1 周期性自包含原子载荷结构

设完整文档由周期性出现的短原子段组成：

$$D_{\mathrm{adv}}=[B_1\Vert B_2\Vert\cdots\Vert B_p],\qquad B_i=(\operatorname{Header}_i,\operatorname{Body}_i,v_i).$$

固定分块配置要求 $0\le O_\phi<L_\phi$，并以受害分块 tokenizer 的 token 数度量原子长度。固定重叠 O 时保留 $|B_i|\le L_{\min}-O$；多配置时取 $|B_i|\le\min_{\phi\in\Phi_{\mathrm{main}}}(L_\phi-O_\phi)$。这一约束只给命题提供布局空间，实际完整性由分块后的 token/字符区间检查保证。设 $V_\phi(x)=1$ 表示至少存在一对同源、角色完整且互斥承载的不同块：一个块完整覆盖 A 而不完整覆盖 B，另一个完整覆盖 B 而不完整覆盖 A；任一块同时完整覆盖 A/B、合块、跨界截断或语义缺失均记为无效配置。

1. $\operatorname{Header}_i$：构造 LLM 生成紧凑查询语义变体或关键词组 $\mathcal K_q$，使每个角色均具有独立检索相关性。
2. $\operatorname{Body}_i$：表达该角色负责的局部命题，使用自然背景替代机械填充；局部自包含不意味着单块已经包含完整攻击结论。
3. $v_i\in\mathcal V$：可选的关系表达后缀，用于补充指代、适用范围或命题间联系。不同后缀家族是候选构造算子，不预设某一种文本格式为核心载荷。

配置族覆盖预注册的主流窗口与偏移，不作任意分块保证。对固定查询/分块/解码面板 $\mathcal E$，设权重 $w_\ell\ge0$ 且 $\sum_{\ell\in\mathcal E}w_\ell=1$；$V_\ell(x)=1$ 表示面板配置 $\ell$ 产生上述同源、不同 chunk、角色完整且互斥承载的 A/B 对，否则为 0。令 $\pi(x)=\sum_{\ell\in\mathcal E}w_\ell V_\ell(x)$。静态结构候选池 $\mathcal X_{\mathrm{pool}}$ 保留通过文档编辑范围、角色语义和逻辑非泄漏检查，且 $\pi(x)\ge v_{\min}>0$ 的完整文档。实测的 A/B UNKNOWN 与联合输出属于候选生成属性；强核心机制见证须通过该探针，但未经生成探针的候选不预先标成通过或失败。

**单块非泄漏构造。** 设 C 为四种强制条件共同使用、且本身不唯一确定答案的固定背景；$\mathfrak M(A)$、$\mathfrak M(B)$ 分别为满足 A、B 中局部命题、查询 q 和 C 的答案解释集合。核心构造要求两集合均非空，且各自至少存在一个答案不同于 $a_q^*$ 的解释；同时，联合解释非空，并且其中所有解释都给出 $a_q^*$。即：

$$\mathfrak M(A)\ne\varnothing,\quad \mathfrak M(B)\ne\varnothing,\quad \exists m_A\in\mathfrak M(A):\operatorname{Ans}(m_A)\ne a_q^*,\quad \exists m_B\in\mathfrak M(B):\operatorname{Ans}(m_B)\ne a_q^*,$$
$$\varnothing\ne\mathfrak M(A)\cap\mathfrak M(B)\subseteq\{m:\operatorname{Ans}(m)=a_q^*\}.$$

在有限答案任务中可直接枚举兼容答案集合；其他任务将条件落实为带类型的关系约束和可审计反例。该结构约束保证在声明的语义模型中，任一局部角色都不足以唯一确定目标，联合约束才确定目标。它与影子生成器的 A-only/B-only UNKNOWN 探针互补：形式化约束不保证自然语言模型的输出，探针结果也不替代逻辑非泄漏检查。

### 2.2 形式化端到端联合优化目标

设待搜索后缀对为 $\boldsymbol v=(v_A,v_B)\in\mathcal V_A\times\mathcal V_B$，布局与命题模板并入完整候选 x。优化域为 §2.1 的静态候选池 $\mathcal X_{\mathrm{pool}}$。A/B UNKNOWN、生成层单块泄漏与顺序敏感性在被选候选上实测；其中 A/B 均为 UNKNOWN 且联合给出目标答案是强核心机制见证。若 $\mathcal X_{\mathrm{pool}}$ 为空，记录结构搜索未找到有效载荷；在该固定候选池上优化：

$$\max_{x\in\mathcal X_{\mathrm{pool}}} J(x)=\mathbb E_{q,\phi}\left[\mathcal R_{\mathrm{e2e}}(\widetilde f_g(q,C_x(q,\phi)),a_q^*)+\lambda_1\mathcal L_{\mathrm{co-ret}}(q,\phi(D_{\mathrm{adv}}))-\lambda_2\mathcal L_{\mathrm{boundary}}(q,x,\phi)\right].$$

这里 $\lambda_1,\lambda_2\ge0$。目标函数是对生成效果、共同检索和分块边界稳定性的加权标量化；不同预注册权重对应不同效用取舍。主生成项由完整影子语料竞争后的自然 Top-K 回答计算，强制上下文输出仅用于机制诊断。

设 $P_Q$ 为预先固定的研究查询分布，$P_\Phi$ 为选定主流分块配置上的预注册分布，式中期望按 $P_Q\times P_\Phi$ 计算。实际优化使用有限固定面板及预先登记的权重，其加权平均为本期望的经验目标；不得在搜索后更换面板或权重。

**（1）端到端生成诱导奖励。** 设 $\alpha>\gamma>0$、$\beta>0$：

$$\mathcal R_{\mathrm{e2e}}(y,a_q^*)=\begin{cases}
+\alpha,&\operatorname{Ans}(y)\equiv a_q^*,\\
-\beta,&\operatorname{Ans}(y)\equiv y_{\mathrm{true}},\\
+\gamma,&y\text{认可指定的中间攻击关系，且未认可目标或真实答案},\\
0,&\text{其他}.
\end{cases}$$

优化样本要求目标答案与 ground truth 不等价。奖励保留“目标—中间关系—真实答案”的反馈层次。$\operatorname{Ans}$ 依据最终断言处理别名、单位、否定和多候选列举；互相矛盾的多答案输出归为“其他”，含目标字符串的否定句不算成功。关系认可由固定文本判别模板记录证据句。构造器提出的中间关系汇总为同一查询下共享的规范关系集合，在任何 clean/poison 奖励评价前冻结；所有候选使用同一判分器与关系集合。

**（2）双块并存检索项（Co-Retrieval Score）。** 虽沿用旧记号 $\mathcal L_{\mathrm{co-ret}}$，该项是应最大化的检索分数，不是应最小化的惩罚。设 $\mathcal C_A,\mathcal C_B$ 为完整文档分块后承载两类角色的块，选择互异的实例对并记录；需要冗余副本均可检索时，将其一并纳入相应角色集合：

设 $\mathcal P_\phi$ 为配置 $\phi$ 下所有有效有序对 $(c_a,c_b)$：$c_a$ 完整覆盖指定的 A 角色区间但不完整覆盖对应 B 区间，$c_b$ 完整覆盖 B 区间但不完整覆盖 A 区间；两者来自同一被改写文档且块 ID 不同。若窗口重叠使某块完整包含 A、B 两角色，则该块不能组成有效对。双块并存检索项取为：

$$\mathcal L_{\mathrm{co-ret}}=\min_{(c_a,c_b)\in\mathcal P_\phi}\left[\widetilde s(q,c_a)+\widetilde s(q,c_b)\right].$$

若 $\mathcal P_\phi=\varnothing$，配置无效并使用固定失败分数，不计算空集最小值。该式沿用“两个角色各自最低分相加”的原目标；显式排除同块承载或重叠块各自完整携带两角色的情形。因 $\widetilde s$ 是余弦相似度，每项在 $[-1,1]$，故该项在有效配置下属于 $[-2,2]$。最大化它提升最弱有效异块对的分数，但分数和本身不保证 A、B 各自都超过 Top-K 阈值，也不保证共同进入真实 Top-K；每轮另存 A/B 的分数、排名与 CoRecall@K。若存在多组角色副本，最小值会同时要求这些有效组合都不出现明显短板；副本策略应在候选构造前固定。

**（3）分块边界平移敏感度惩罚。** 原来的相似度平移项展开到两类角色：

$$\mathcal L_{\mathrm{boundary}}=\mathbb E_{\delta}\left[\frac12\sum_{r\in\{A,B\}}\left|\widetilde s(q,c_r)-\widetilde s(q,c_r^{(\delta)})\right|\right].$$

偏移 $\delta$ 从预设整数集合采样。每个配置按固定的角色区间 ID 与块起点规则选择一对角色互斥承载的完整异块，$c_r^{(\delta)}$ 来自整篇文档重新分块后完整覆盖同一角色区间的块。偏移超出文档合法范围时，将分块起点截到最近的合法边界；由截断产生的重复相位仍按原抽样权重计入。若任一角色没有完整覆盖块、两角色落入同一块，或有块同时完整包含 A/B，该偏移的完整括号项取最大惩罚 2；有效时每项余弦差不超过 2。因此损失位于 $[0,2]$。窗口分数稳定与角色语义完整分别检查。

无效基础配置的整个 J 样本统一取 $r_{\mathrm{fail}}=-\beta-2\lambda_1-2\lambda_2$，不缩小平均分母、不计算空集合最小值。有效配置中 $\mathcal R_{\mathrm{e2e}}\ge-\beta$、$\mathcal L_{\mathrm{co-ret}}\ge-2$、$\mathcal L_{\mathrm{boundary}}\le2$，且 $\lambda_1,\lambda_2\ge0$，所以其完整分数也不低于 $r_{\mathrm{fail}}$。无效样本固定在这一共同下界，候选不能通过放弃难配置抬高得分。

### 2.3 平滑与绑定后缀的获得及 GPT-2 质量约束

**种子与角色职责。** 每个查询先由研究者或 $G_{\mathrm{build}}$ 给出有限组可审计的关系骨架，例如实体—属性、对象—适用条件、引用—结论、约束—候选。每个骨架拆成至少两个角色职责，并写出联合时应保留的语义关系、不得泄漏的答案字段、ground-truth 对照及可编辑区间。角色模板只确定语义功能；key-value 记录只是其中一种便于解析的实例化格式。InceptionRAG 的实现展示了对角色种子进行 LLM 释义扩写并在离散池中搜索的工程路径；本文把构造对象扩展到完整源文档和其分块布局。[S2, P2]

**后缀池生成。** 对每个角色建立若干功能种子，例如指代消歧、关系传播、条件限定、引用归属和记录格式。给 $G_{\mathrm{build}}$ 的输入固定包含查询、真实答案、目标答案、原文上下文、角色语义约束、允许编辑区间、长度范围和输出 schema。每个 seed 独立采样 r 个文本释义，并返回 `seed_id, role, text, preserved_relation, changed_scope` 等字段。解析器重新验证字段类型、角色职责、长度及禁止改动的区间；LLM 自评只作为诊断文本，不充当正确性判定。相同规范化文本按哈希去重，按 seed 家族保留配额，避免候选池被同一种措辞占满。

**完整文档平滑与搜索算子。** 构造器输出整篇 $D_x$ 及 A/B 字符区间，不直接把两个独立 passage 当作攻击角色。将 A/B 邻接上下文、源文体例和角色职责交给 $G_{\mathrm{build}}$，要求只改写允许区间并保持关系约束；随后以原始分块器重切完整文档，按偏移核实角色是否被完整承载。后缀池先形成配对，再与布局位置、段落顺序、上下文平滑版本组合。离散搜索动作包括替换一个角色后缀、替换两侧后缀、局部背景改写、角色位置平移、段落重排和对单个候选作 bounded rewrite。每个候选保存 `parent_id, seed_ids, operator, source_hash, span_map`，使重写可以回溯与重放。失败候选保留失败类别，避免搜索器反复生成同一结构错误。

**GPT-2 局部困惑度。** 设固定 GPT-2 tokenizer 把文档编码为 $t_1,\ldots,t_n$，$t_0$ 为固定起始标记。模型在位置 i 的 logits 经 softmax 得到下一个 token 概率 $p_\theta(t_i\mid t_0,\ldots,t_{i-1})$。对待评分位置集合 $I$，逐 token 平均负对数似然与困惑度为：

$$\operatorname{NLL}_I=-\frac{1}{|I|}\sum_{i\in I}\log p_\theta(t_i\mid t_0,\ldots,t_{i-1}),\qquad \operatorname{PPL}_I=\exp(\operatorname{NLL}_I).$$

长文用窗口上限 W、步长 $1\le H<W$ 评分。第 k 个窗口的目标位置为 $[s_k,e_k]$，输入左边界取 $b_k=\max(0,e_k-W+1)$；$H<W$ 保证目标 token 前有可用上下文。令 $I_k=I\cap[s_k,e_k]$，则实际累计量为：

$$\operatorname{NLL}_I=-\frac{\sum_k\sum_{i\in I_k}\log p_\theta(t_i\mid t_{b_k},\ldots,t_{i-1})}{\sum_k|I_k|}.$$

各 $[s_k,e_k]$ 不重叠且覆盖全部目标位置，因此每个 token 恰好计分一次；窗口平均 loss 必须按有效 token 数加权，不能对窗口均值再做简单平均。实现使用 GPT-2 标准 causal-LM 右移标签，非目标位置与 padding 置为 ignore index；以 tokenizer 的 offset mapping 将后缀、角色段和边界邻域映射到 token 位置。空区间跳过。优化器只读取局部 NLL/PPL 标量，不读取 logits、隐藏状态、激活或梯度。英语使用固定 GPT-2 checkpoint、tokenizer、窗口和精度；跨语言数据单独校准。

为避免全文平均掩盖短后缀异常，候选质量统计分别覆盖每个角色后缀、角色边界窗口和受编辑句段。设 $b_{\mathrm{clean}}(I)$ 为长度与主题匹配的干净文本在位置类型 I 上预注册的 NLL 分位数，取：

$$Q(x)=\max_{I\in\mathcal I(x)}[\operatorname{NLL}_I-b_{\mathrm{clean}}(I)]_+,\qquad[z]_+=\max(z,0).$$

$Q(x)\le\tau_Q$ 用作语言质量约束，检查文本相对干净基线的异常程度；它不测事实真实性。GASLITE 将检索目标与流畅度约束分开优化，其实验和本地 GPT-2 评分实现支持这种分项测量。[S4, P3]

### 2.4 离线黑盒优化与分阶段评价

优化器使用 **离线黑盒图贝叶斯优化（offline graph-based Bayesian optimization）**。其可见反馈分为三类：构造器生成的文本与结构化字段、影子 retriever 的相似度分数/排名/Top-K 结果、影子受害 LLM 的最终文本回答。GPT-2 另提供局部 NLL 标量。算法不读取任何模型的激活值、logprob、梯度或注意力；影子系统所有读数均来自固定、可审计的输入/输出接口。

候选评价顺序为静态结构筛查、检索排序观测、候选级影子生成评价。结构检查和检索观测对候选池批处理；高开销的受害 LLM 回答只对初始设计点及采集函数选中的候选计算。A/B/AB/BA、`UNKNOWN→KNOWN` 和 matched-random 均作为这些已选候选的机制诊断条件，不把逐候选强制探针扩展到全池。强 UNKNOWN 见证、一般 forced-context 交互、有效 cross-chunk 配置和自然 Top-K 命中使用不同字段与分母。端到端主目标使用本地完整语料下的自然 Top-K 回答，与 §2.2 的生成奖励、共同检索项和边界项使用同一固定评价面板。

现存的历史目标模型数据记为 $\mathcal H^\star$，其观测结构仅包括相同或配对查询下的未投毒/投毒回答，以及同一查询在不同固定 payload 条件下的目标 LLM 文本输出和协议元数据。对严格配对的查询 q、payload x，记描述性差值为 $d_{q,x}=g(y^\star_{q,x},a_q^*)-g(y^\star_{q,0},a_q^*)$；重复 payload 的区间估计按 query 聚类，避免把同一 q 的多种 payload 当作独立样本。现有记录没有目标自然 Top-K 的完整检索分数、排名与上下文轨迹，因此 $d_{q,x}$ 只能描述已观测提示条件下的回答差异，不能分解为目标检索效应，也不能当作自然检索攻击成功率。

严格离线约束将 $\mathcal H^\star$ 与优化器观测集隔离：目标数据只用于历史案例审计或冻结载荷后的独立迁移评估，不用于候选生成、GP 更新、搜索方向、停止规则或调参。拟议算法的优化记录集 $\mathcal O_{\mathrm{local}}$ 由本地影子系统在固定协议下新产生；当前不存在与该协议对应的完整本地优化轨迹，因此本文给出可执行方法与理论性质，不把历史目标数据冒充本地观测或自然检索数据。冻结载荷后的目标评测只报告公开文本回答及固定答案判定，不采集目标排名/分数，且结果不反馈至优化器。

查询与分块配置组成预注册面板，样本权重在开始评价前冻结。跨 payload 的比较按 query 配对；同一 query 的多个温度、顺序或重试是重复测量，不增加独立 query 数。核心联合效应、`UNKNOWN→KNOWN` 子条件、自然 Top-K 效果和目标迁移分别报告。

## 三、求解算法：候选生成、图代理与信息增益搜索

### 3.0 候选池初始化：可直接实现的流水线

输入记录为 `query_id, query, gold_answers, target_answers, source_id, source_text, editable_spans, shadow_profile`。目标答案及语义匹配规则在构造前固定。初始化按下列顺序执行：

1. **分配关系家族。** 为每题生成实体—属性、条件—规则、引用—结论、约束—候选四类骨架，各取有限个种子；key-value 作为引用家族的一种模板。解析失败、缺少角色或逻辑自相矛盾的骨架退回一次重写。
2. **生成角色文本。** 构造器一次输出完整文档和角色字符区间，保留允许编辑区外的原文。可将全文替换作为独立设置；gold 保留、编辑 token 数及变化位置均入日志。
3. **生成后缀池。** 对 §2.3 的各类角色种子生成 r 个释义，规范空白并按文本哈希去重。后缀长度上限在影子 tokenizer 下检查。默认优先使用功能不同的种子，避免池被同一句话的近义改写占满。
4. **组合成候选。** 先覆盖每个 A/B 种子的至少一个配对，再在剩余配对及布局组合中固定 seed 抽样到 M 个候选。若允许全部组合，明确 $M=|\mathcal V_A||\mathcal V_B||\mathcal L|$；绝不将单个后缀节点误作完整候选对。
5. **静态筛查并冻结候选池。** 对所有完整文档按固定配置重分块，检查 source_id、编辑边界、角色完整性、逻辑非泄漏约束和局部 PPL；逐配置计算 $V_{i\ell}$ 与有效率 $\pi_i$，仅将 $\pi_i\ge v_{\min}\in(0,1]$ 的候选放入池。INVALID 配置保留标签与原因，不作为有效 cross-chunk 成功率的分母；其在端到端优化目标中的固定下界记分见 §2.2。接着对候选池批量计算影子检索分数、排名、Top-K 状态及已知损失项；只保存这些接口输出，不读取或保存模型 embedding。全池候选文本、特征字段、配置面板、版本和判分器在搜索前冻结。
6. **选择初始观测。** 在检索项较好候选、各关系家族和图连通分量中先取代表点，再用最远点采样补齐 $n_0$。最远点采样每次选择与已选点最小距离最大的节点，以覆盖尚未探索的区域。初始点才运行影子受害生成器：在同一固定提示下评价自然 Top-K 主目标，并做 A-only、B-only、AB、BA、UNKNOWN 与 matched-random 机制探针。强 UNKNOWN 核心见证单独标记；未通过该探针的观测不作为该强机制的正证据，但保留在自然端到端搜索与审计记录。

一个可执行起点是四类骨架、每类两个骨架种子、每角色八个后缀释义、两种布局，并从组合中均衡保留 M=256 个候选；这些数值是初始化参数，不是效果结论。返回池为空时输出构造失败；启用图时，初始评价数须覆盖每个连通分量；独立候选分支使用固定 seed 采样。两种方式均不超过总评价上限，超出时提高上限或缩减池后重新冻结。参数、随机 seed、去重与淘汰数量支持完整复现。

为使初始残差方差和留一预测误差可计算，设小样本切换阈值 $n_{\min}\ge3$；若 $n_0<n_{\min}$，直接采用预设核参数，不执行数据驱动的参数选择。

### 3.1 为什么采用 kNN 图，以及如何形成热核

**问题来源。** 离散文本的有效组合稀疏，逐个独立试验无法复用已知结果。根据可观察的角色分数、排名和构造算子建立候选邻近关系，使相关候选共享部分评价信息，同时让不同关系家族保留各自的探索空间。

**从可观察检索行为到图。** 对固定查询 q，在每个有效配置的 $\mathcal P_\phi$ 中，选取使 $\widetilde s(q,c_a)+\widetilde s(q,c_b)$ 最小的角色对；并列时按 $(\text{A 块起点},\text{B 块起点},\text{A 块 ID},\text{B 块 ID})$ 字典序选择。对每个候选记录该代表 A/B 块在本地影子检索器下的归一化分数、截断排名、是否进入自然 Top-K，以及关系家族、编辑算子和布局相位等构造元数据。检索分数按 $(s+1)/2$ 映射到 $[0,1]$；排名 $r$ 映射为 $\min(r,K_r+1)/(K_r+1)$，未进入前缀者记为 $K_r+1$。无效角色配置在归一化后将分数、排名和命中字段置为固定哨兵 $(0,1,0)$，并单独记录有效位。每个候选均使用同一组查询和分块配置，因此得到字段顺序固定、维数相同的描述 $x_i$。分数与排名来自本地影子 retriever 的可观察输出，不包含目标系统信息或模型 embedding。

对数值字段集合 $\mathcal N$ 与类别元数据字段集合 $\mathcal C$，采用加权 Gower 型差异：

$$d_{ij}=\frac{\sum_{r\in\mathcal N}w_r|x_{ir}-x_{jr}|+\sum_{r\in\mathcal C}w_r\mathbf 1[x_{ir}\ne x_{jr}]}{\sum_{r\in\mathcal N}w_r+\sum_{r\in\mathcal C}w_r},\qquad w_r>0.$$

所有数值字段先固定缩放到 $[0,1]$，缺失值使用上述哨兵值，类别字段使用预先冻结的有限标签，因此 $d_{ij}\in[0,1]$。若没有可变字段或 $M=1$，直接采用独立候选分支，不建立图。该差异只要求对称和非负，足以构造下一式所需的对称非负权图；距离是否能预测奖励变化由留出观测检验。

全连接图会把大量不相关的候选相连。设 $k_{\mathrm{NN}}\ge1$ 为预先固定的正整数；取 $\min(k_{\mathrm{NN}},M-1)$ 个最近邻，按候选 ID 处理平分，构造双向并集：

$$W_{ij}=\begin{cases}\exp(-d_{ij}/\tau),&i\ne j,\ j\in\mathcal N_k(i)\text{ 或 }i\in\mathcal N_k(j),\\0,&\text{其他}.
\end{cases}$$

W 为相似度权重，$\tau>0$ 控制距离衰减；用已连边正距离的中位数初始化 $\tau$，没有正距离时取 $1$。工程默认在 $M\ge2$ 时取 $k_{\mathrm{NN}}=\lceil\log_2M\rceil$，实际 k 取 $\min(k_{\mathrm{NN}},M-1)$；这是一条预先固定的稀疏图规则，不是最优 k 的定理。M=1 时无需图搜索。不同连通分量各给初始观测，不为连通而强接语义不相关边。

**从平滑要求到扩散。** 设 $D_{ii}=\sum_jW_{ij}$、$L=D-W$。候选奖励向量为 f，则相邻奖励差异的加权总量为：

$$E(f)=\frac12\sum_{i,j}W_{ij}(f_i-f_j)^2=f^\top Lf.$$

等号由展开平方并利用 $W_{ij}=W_{ji}$ 得到。若让每个节点朝邻居的加权均值靠近，其变化率是 $\dot h_i=-\sum_jW_{ij}(h_i-h_j)$，矩阵形式为 $\dot h=-Lh$。解为 $h(t)=e^{-tL}h(0)$：对幂级数逐项求导即可验证导数和初值。

因此选择热核 $K=\sigma_f^2e^{-t_d L}$，$t_d\ge0$ 是扩散时间，$\sigma_f^2>0$ 是奖励变化尺度。核由候选邻接关系建立协方差先验。$t_d=0$ 时恰为独立候选，$t_d$ 较大时邻域反馈传播更远。k 与正距离尺度 $\tau>0$ 在初始观测前按上述几何规则冻结。为使扩散时间不随图的典型度数任意缩放，设 $d_{\mathrm{med}}$ 为正加权度 $D_{ii}$ 的中位数，候选时间取 $t_d=u/d_{\mathrm{med}}$，$u\in\{0,0.1,0.3,1,3\}$；若没有正度数，固定 $t_d=0$。设初始代理残差 $z_i$ 的样本方差为 $v_r$，奖励残差尺度 $R_s=\alpha+\beta$，取 $v_0=\max(v_r,10^{-6}R_s^2)$，并在 $\sigma_f^2\in\{v_0/4,v_0,4v_0\}$、$\nu^2\in\{10^{-6},10^{-4},10^{-2}\}v_0$ 的固定网格上以留一平方预测误差选择参数，随后冻结。初始观测数低于 $n_{\min}$ 时用预设的 $u=0,\sigma_f^2=v_0,\nu^2=10^{-4}v_0$。验证较差时 $u=0$ 提供独立候选分支。

对称矩阵可取互相垂直的单位特征向量组成 U，使 $L=U\Lambda U^\top$，因此 $K=\sigma_f^2U\operatorname{diag}(e^{-t_d\lambda_j})U^\top$。特征值可理解为不同变化模式被扩散抑制的速率，其有效性与简单证明见第四节。

### 3.2 同一查询下的 clean/poison 对比与单一 GP 后验

设固定评价面板 $\mathcal E$ 的每个元素 $\ell$ 指定查询、分块配置与生成 seed，权重 $w_\ell\ge0$ 且 $\sum_\ell w_\ell=1$。clean 基线 $r_0=\sum_\ell w_\ell R_{0\ell}$ 仅由影子系统同面板输出计算。对候选 i，令 $V_{i\ell}\in\{0,1\}$ 表示该配置有完整同源异块 A/B 对，$C_{i\ell}=\mathcal L_{\mathrm{co-ret}}$，$B_{i\ell}=\mathcal L_{\mathrm{boundary}}$。无效配置不调用影子生成器，且其完整 J 样本按 §2.2 记为 $r_{\mathrm{fail}}$。候选使用自然 Top-K，固定面板下记录的有界经验目标是：

$$\widehat J_i=\sum_{\ell\in\mathcal E}w_\ell\left[V_{i\ell}\left(R_{i\ell}+\lambda_1 C_{i\ell}-\lambda_2 B_{i\ell}\right)+(1-V_{i\ell})r_{\mathrm{fail}}\right].$$

因此有效比例、已知项和已知基线为：

$$\pi_i=\sum_\ell w_\ell V_{i\ell},\qquad g_i=\sum_\ell w_\ell\left[V_{i\ell}(\lambda_1C_{i\ell}-\lambda_2B_{i\ell})+(1-V_{i\ell})r_{\mathrm{fail}}\right],\qquad m_i=g_i-r_0.$$

减去同一固定 $r_0$ 不改变候选排序，只让观测表示相对 clean 的效用。令 $\widehat r_i=\widehat J_i-r_0$，并令 $f_i=\sum_\ell w_\ell V_{i\ell}R_{i\ell}$ 表示候选 i 的有效配置生成奖励部分，则固定面板下的观测恒等式为 $\widehat r_i=m_i+f_i$。优化器把下列 GP 当作未知残差的排序代理：

$$z_i=\widehat r_i-m_i,\qquad z_i\mid f_i\sim\mathcal N(f_i,\nu_i^2),\quad f\sim\mathcal N(0,K).$$

其中 $z_i=\widehat r_i-m_i$ 是用于拟合代理的残差观测。高斯先验与似然是用于排序和不确定性估计的工作模型，不表示有界的文本奖励实际服从无界正态分布。确定性服务使用固定面板与固定 seed；随机服务记录每次有界的 $\widehat J_i$，需要估计重复性时才用重复运行估计噪声。无论哪种设置，后文上界筛除均直接由实际奖励范围推出，不依赖代理的分布假设。

主算法固定模型版本、查询/分块面板、生成 seed 与解码参数，使每个候选的经验目标可重复；此时 $\nu_i^2=\nu^2>0$ 是保证线性系统稳定的代理 nugget，不是实际奖励噪声。若服务不能固定输出，则须对候选重复测量，并把噪声写入候选特异的 $\nu_i^2$；这时单次观测最大值不是已知的真实 incumbent，不能直接套用 §3.3 的普通 EI，需改用对 incumbent 后验积分的 noisy-EI，并单独验证。本文给出的闭式 EI 与 A2/A3 主流程以确定性固定面板为准。这里 $\mathcal N(\mu,v)$ 表示均值为 $\mu$、方差为 v 的正态分布。代理的正态尾部不改变实际奖励的有界性，也不用于 A3 的筛除证明。

设已评价集合为 O、残差观测向量为 $z_O$、$A=K_{OO}+\Sigma$，其中 $\Sigma=\operatorname{diag}(\nu_i^2)$。对所有候选的预测为：

$$\mu=m+K_{:O}A^{-1}z_O,\qquad S=K-K_{:O}A^{-1}K_{O:}.$$

**推导。** 先估计某节点残差 $f_i\approx a^\top z_O$。平均平方误差展开为 $K_{ii}-2a^\top K_{Oi}+a^\top Aa$。将 $a=A^{-1}K_{Oi}+u$ 代入，得到常数项加 $u^\top Au$；A 的二次型为核的非负二次型加 $\sum_i\nu_i^2u_i^2$，故非零 u 时严格为正；后一项最小时 u=0，得到预测均值。代回误差即可得到方差。联合正态下，剩余误差与观测不相关便独立：它们的联合正态密度在零交叉协方差时分解成两个密度，因而这是条件均值与条件方差，而不只是线性近似。

实现解线性方程而不显式求逆；每次新观测只更新 Cholesky 因子。奖励生成项来自本地影子回答，其他项来自预先可计算的候选结构和本地检索结果；目标系统反馈与模型内部激活不进入后验。

### 3.3 信息增益奖励与搜索方向的推导

**区分两个量。** J 衡量载荷效果；采集函数衡量“下一次评价哪个候选更有价值”。采集函数结合预期改进与信息增益，让稀疏成功信号出现前也能选择有学习价值的候选。

设当前最佳已观测相对效用为 $b=\max_{j\in O}\widehat r_j$；在确定性固定面板下，b 是已知的 incumbent。候选残差 $f_i$ 的后验均值和方差为 $\mu_i$、$s_i^2=S_{ii}$。一次带 nugget 的新观测 $Z_i=f_i+\epsilon_i$ 的方差为 $s_i^2+\nu_i^2$。正态变量方差为 v 时，其微分熵为 $H=\frac12\log(2\pi e v)$：把正态密度的对数代入 $-\mathbb E\log p$，再用 $\mathbb E[(Z-\mu)^2]=v$ 即得。已知完整潜在奖励向量 f 后，Z 只剩噪声方差 $\nu_i^2$，所以：

$$I_i=H(Z_i\mid\mathcal O)-H(Z_i\mid f,\mathcal O)=\frac12\log\left(1+\frac{s_i^2}{\nu_i^2}\right).$$

这就是一次评价对图上奖励变量提供的互信息。图相关性决定信息传播的位置：观察 i 后，任意节点 j 的方差变为 $S_{jj}-S_{ji}^2/(S_{ii}+\nu_i^2)$，故越相关的邻居获得越多反馈复用。

设 $F_i=m_i+f_i$ 为代理中的潜在效用，故其后验均值为 $\bar\mu_i=m_i+\mu_i$。信息增益本身也会偏爱难预测但无效的区域，因此再计算相对于已知 incumbent 的预期改进 $\operatorname{EI}_i=\mathbb E[(F_i-b)_+]$。令 $a_i=(\bar\mu_i-b)/s_i$，$\varphi$、$\Phi$ 为标准正态密度与累积概率，则：

$$\operatorname{EI}_i=(\bar\mu_i-b)\Phi(a_i)+s_i\varphi(a_i).$$

推导时令 $z=(F_i-\bar\mu_i)/s_i$，成功改进对应 $z>-a_i$。标准正态密度 $\varphi(z)=(2\pi)^{-1/2}e^{-z^2/2}$ 满足 $\varphi'(z)=-z\varphi(z)$，故 $\int_{-a_i}^{\infty}z\varphi(z)\,dz=\varphi(a_i)$；对称性给出 $\int_{-a_i}^{\infty}\varphi(z)\,dz=\Phi(a_i)$。代回积分便得到上式。$s_i=0$ 时取 $\max(\bar\mu_i-b,0)$，无需除零。实现对 $s_i>0$ 使用数值稳定的标准正态 CDF/PDF；将舍入误差造成的极小负值截为零。两个正的归一化常数保证采集函数分母不为零，平分时按固定候选 ID 选取。

令 $P_t$ 为本轮满足上界条件 $U_i>b$ 的未测候选。两个归一化分母各加同单位的正数，$\epsilon_{\mathrm{EI}}>0$ 与 EI 同单位，$\epsilon_I>0$ 与互信息同单位。采集值为：

$$A_t(i)=\frac{\operatorname{EI}_i}{\max_{j\in P_t}\operatorname{EI}_j+\epsilon_{\mathrm{EI}}}+\eta_t\frac{I_i}{\max_{j\in P_t}I_j+\epsilon_I},\qquad
\eta_t=\frac{\eta_0}{\sqrt{t+1}},\quad\eta_0\ge0.$$

早期信息项支持探索，后期更多选择预期改进；该递减策略是搜索启发式，不构成收敛或全局最优保证。这里的“方向”是图上不同后缀配对与布局候选之间的离散跳转，选取 $A_t$ 最大的候选。kNN 边表达语义邻近，不要求两端恰好相差一次文本编辑。设全局搜索周期 $h\ge1$ 为整数；每隔 h 轮在 $P_t$ 全局选择一次，其余轮优先当前优胜节点的未测邻居；邻居耗尽时自动转全局选择。连通分量有种子且全局探索保留，避免只在单一模板内搜索。

**可计算上界筛除。** 生成奖励不会超过 $\alpha$，故每个候选都有完全可读的上界：

$$U_i=m_i+\pi_i\alpha.$$

当 $U_i<b$ 时，即便所有有效配置生成都命中目标，该候选也无法超过已测最佳，可直接跳过其影子生成调用。该筛除不依赖 GP 方差校准。至少保留一个已测候选；已测分数须是固定评价协议下的有效记录。模型调用失败按预定重试处理，最终无合法回答的样本记为“其他”奖励并单独报告。

停止条件为：达到预定评价轮数、未测可行节点耗尽、或所有未测候选的 $U_i\le b$。最后一种情况下未测项最多与当前最好并列，不能严格提高已观测效用；等分候选无需再消耗生成调用。最后只从已测候选选择输出，并在本地未参与搜索的配置面板验证；真实目标迁移测试在此后独立进行。

## 四、数学依据与计算复用

### 4.1 热核为何能作为协方差

设矩阵 H 对任意实数向量 u 均满足 $u^\top Hu\ge0$，称其为半正定；非零 u 时严格大于零则称正定。协方差必须半正定，因为 $u^\top Hu$ 正是加权随机变量之和的方差，而方差不能为负。

**命题 A1（热核合法性）。** 对上述对称非负权图，L 半正定，有限 $t_d\ge0$、$\sigma_f^2>0$ 时 K 正定，包括图不连通的情形。

**证明。** 展开得到 $u^\top Lu=\frac12\sum_{i,j}W_{ij}(u_i-u_j)^2$。每项是非负权乘平方，和也非负。再说明所需的正交特征方向为何存在：单位球面紧，连续量 $u^\top Lu$ 在其上能取得最大值。设最大点为单位向量 u。对任意 $v\perp u$，沿单位球面上的路径 $x(t)=(u+tv)/\|u+tv\|_2$ 求极值处的导数，得到 $v^\top Lu=0$；所以 Lu 与所有垂直于 u 的方向正交，只能平行于 u。又因 L 对称，$u^\top Lv=(Lu)^\top v=0$，故 u 的垂直空间在 L 作用后仍留在其中。逐次在这个更低维空间重复，便得到一组正交单位特征向量 U。各特征值满足 $\lambda_j=u_j^\top Lu_j\ge0$。

将任意非零向量写成这些方向的和 $v=\sum_j a_j u_j$，至少一个系数非零，则：

$$v^\top Kv=\sigma_f^2\sum_j e^{-t_d\lambda_j}a_j^2>0.$$

指数对有限实数始终为正，零特征值也对应正权 1，结论成立。矩阵指数的幂级数在有限维、有限时间绝对收敛，因而 §3.1 的逐项求导有效。$\blacksquare$

这个结论使 GP 拟合有合法的协方差。候选语义相近时奖励也相近，是需用初始观测检查的统计先验；热核合法性与该先验的预测质量分别验证。

### 4.2 后验、信息增益与数值求解

**命题 A2（反馈复用）。** 固定 GP 参数后，对尚未观测的候选 $i\notin O$ 增加一个噪声与潜在奖励及既有观测独立、且方差 $\nu_i^2>0$ 的观测，后验协方差满足：

$$S^+=S-\frac{S_{:i}S_{i:}}{S_{ii}+\nu_i^2},\qquad
S_{jj}-S^+_{jj}=\frac{S_{ji}^2}{S_{ii}+\nu_i^2}\ge0.$$

**证明。** 已有观测后，记潜在残差向量为 g，其协方差为 S。将新观测减去预测均值，得 $Z=g_i+\epsilon_i$，且 $\operatorname{Var}(Z)=S_{ii}+\nu_i^2$。对每个 j 作线性扣除 $g_j^+=g_j-\frac{S_{ji}}{S_{ii}+\nu_i^2}Z$。按协方差公式展开可得 $\operatorname{Cov}(g_j^+,Z)=0$，并对任意 j,k 得 $\operatorname{Cov}(g_j^+,g_k^+)=S_{jk}-\frac{S_{ji}S_{ik}}{S_{ii}+\nu_i^2}$。g 与噪声联合正态，因此零交叉协方差意味着 $g^+$ 与 Z 独立；上式就是新增观测后的条件协方差。取 j=k 即得对角方差减少量非负。$\blacksquare$

因此，一次完整影子生成能够通过相关系数更新多个邻居；独立候选的 $S_{ji}=0$，没有这部分复用。信息增益 $I_i$ 是观察前后熵之差，表达代理自身的不确定性减少。它与 §3.3 的 EI 共同决定搜索顺序。

线性求解使用 Cholesky 分解 $A=RR^\top$，R 为下三角矩阵。其逐列计算规则是从对角元素减去已解释的平方和后开方，再计算下方元素。正定性保证每个剩余对角量为正：将已有主块记为 B、新列记为 v、新对角记为 a，取非零向量 $(-B^{-1}v,1)$，代入 A 的二次型得到 $a-v^\top B^{-1}v>0$，它正是需要开方的剩余量。于是可逐列完成分解。增加一个观测时，在旧 R 下追加一行即可，耗时 $O(n^2)$，n 为已有观测数。代码遇到接近零的剩余量时记录并增加对角正则，重新计算后验。

### 4.3 上界筛除的正确性

**命题 A3（安全筛除严格改进候选）。** 在固定候选池、固定评价面板及非负 $\lambda_1,\lambda_2$ 下，每个候选实际记录的相对经验分数 $\widehat r_i=\widehat J_i-r_0$ 都满足 $\widehat r_i\le U_i$。删除满足 $U_i<b$ 的未测候选，不会删除任何能够严格超过已测最好分数 b 的候选。

**证明。** 有效配置的生成奖励至多为 $\alpha$，其已知检索及边界项已经计入 $g_i$。无效配置的完整得分固定为 $r_{\mathrm{fail}}$。按有效比例求平均，再减去同一个 $r_0$：

$$\widehat r_i\le g_i-r_0+\pi_i\alpha=U_i.$$

若 $U_i<b$，则对该候选的任何合法生成结果均有 $\widehat r_i<b$，因此它不可能提高当前最佳目标值。若所有未测 $U_i\le b$，已测集合已达到整个固定池的最大经验目标值；未测候选至多并列。该结论保留最优值，不保证若干并列最优候选中的特定次级 tie-break 赢家。按评价轮数提前停止则只返回当前最好已测值。该结论使用奖励逐项有界性，而不是 GP 后验的高斯尾界。$\blacksquare$

此处 b 为实际缓存的经验效用，上界对每种合法生成奖励都成立。后验均值可以错，上界筛除仍成立。总体期望效用和跨配置迁移由独立保留集估计。

### 4.4 计算量减少来自哪里

设池大小 M、影子生成面板评价次数 n、每个候选的自然评价时间 $c_{g,i}$、机制探针时间 $c_{p,i}$，全池文档构造、静态筛查、PPL、影子检索与 clean 基线预处理之和为 $C_{\mathrm{static}}$，图与 GP 时间为 $C_{\mathrm{graph}}$。使用同一候选池和同一探针协议时，穷举与图搜索的时间分别为：

$$T_{\mathrm{all}}=C_{\mathrm{static}}+\sum_{i\in X}(c_{g,i}+c_{p,i}),\qquad
T_{\mathrm{GBO}}=C_{\mathrm{static}}+\sum_{i\in O}(c_{g,i}+c_{p,i})+C_{\mathrm{graph}}.$$

这里 O 是已测候选集合，$c_{g,i}$ 是候选 i 在自然 Top-K 下的生成耗时，$c_{p,i}$ 是 UNKNOWN、AB/BA 与匹配随机等预注册机制探针耗时。探针本身不进入自然检索奖励。精确节省条件为 $\sum_{i\in X\setminus O}(c_{g,i}+c_{p,i})>C_{\mathrm{graph}}$。若每个候选的总生成调用耗时近似相同为 $c$，可简写成 $(M-n)c>C_{\mathrm{graph}}$，其中 $n=|O|$。这是串行评价下的总工作量核算；并行执行时还需在相同并行预算下报告 wall-clock 与总 GPU/API 时间。图搜索只节省未被选中候选的受害生成与机制探针调用；全池文档构造、结构/PPL 检查、影子检索和 clean 基线都计入 $C_{\mathrm{static}}$，不以免费操作处理。若上界筛除只为 J 的严格改进停止，则它证明的是自然端到端目标上的最优性，不证明未测候选没有 UNKNOWN 或 forced-context 交互；核心机制结论只基于实际完成探针的样本。模型与 tokenizer 固定时，对相同文本哈希复用 GPT-2 NLL、clean 回答、分块结果及影子检索分数/排名。每个候选只重新编码发生变化的源文档，原始全文索引保持只读。

精确检索可以在有明确缓存条件时增量合并。设缓存的是干净语料按固定全序键（分数降序、ID 升序）排列的前 $L$ 块；R 是被替换源文档的 ID 集，目标深度为 K。若从缓存前缀移除所有属于 R 的块后，至少剩下 K 个未修改块，则这些 K 块都排在任何未缓存未修改块之前。因此，替换模式下可将“过滤后的缓存前缀”与新文档全部块的分数合并，精确得到新 Top-K；旧源块不会残留。添加文档是 R 为空的特例，要求 $L\ge K$。若过滤后不足 K 个未修改缓存块，前缀不再保证充分，必须继续向下取干净排名直至留下 K 个未修改块，或对未修改语料全量重排。证明还要求 query、未修改向量、相似度计算及并列 tie-break 与缓存时一致；近似索引另行测量误差，不享有该精确结论。

精确 kNN 距离计算为 $O(M^2d)$，d 是检索/排名/构造元数据字段数；M 约数百时可直接求热核，谱分解为 $O(M^3)$。选出 n 个观测的增量 Cholesky 总量为 $O(n^3)$；显式维护全部协方差的逐轮更新为 $O(M^2)$，总内存 $O(M^2)$。缓存避免反复构建全库，图相关性减少重复的无信息评价，上界省去必然无法改进的生成调用。

在稀疏解空间中，单次成功指示几乎处处为零，检索连续项和中间关系奖励提供更密集的初期反馈；信息增益将观测分配给尚缺样本的区域，EI 在找到有效邻域后推动局部改进。验证以相同候选池和计算计量比较随机搜索、独立候选 BO、图 BO，报告首次成功时间、生成次数、预处理占比及最优效用曲线。真正的加速体现为达到同等成功标准所需总计算量减少。

# 第二部分：防御侧 —— RAGShield

## 一、从多类污染威胁到通用证据验证

RAGShield 将防御对象设为**外部材料对回答中各项断言的证据贡献**。防御者观察查询、召回文本、服务器记录的来源与检索信息，不预知攻击目标、载荷模板或受污染文档。流程统一处理显式错误事实、外部指令、排名操纵、主题偏置和跨块关系组合。

本地基线实现与论文原文展示了互补的攻击面：PoisonedRAG 分别优化检索可见性与生成诱导；GASLITE 联合检索优化和流畅度约束；Topic-FlipRAG 操纵主题立场；InceptionRAG 用角色互补材料影响推理。[P1–P4, S1–S4] 这些结果说明，相关性、语言流畅度、重复数量或单块可答性都不能单独证明事实可靠。防御因而同时检查内容支持、来源依赖、外部指令和组合推理。

已有方法在各自假设内提供了有效约束。RobustRAG 将召回文本分组、隔离生成并安全聚合，在有界污染与每查询质量条件下给出鲁棒性证书；HODOR 按文档独立回答再投票。隔离可限制材料跨组影响；若多跳答案的互补前提被分到不同组，任一组可能都缺少完整证明，这是其聚合粒度与多跳效用间的设计取舍。PRA-RAG 以组合采样和嵌入空间几何筛选稳健子集；其证书依赖干净组合占多数及相应几何条件，约束的是表示扰动，不直接核验命题真伪。[P5, P6, P8] ShieldRAG 通过滑动检索解释、关键词聚合和查询目标优化重塑检索空间；其论文也指出，过滤过强可能损失有用上下文，复杂多跳问题尤其需要权衡。RAGPart/RAGMask 则分别利用分段表示与定向 token masking 改变可疑内容进入上下文的机会。这些检索阶段方法可以降低暴露，但排序或相似度本身不构成事实核验。[P7, P10]

TrustRAG 结合聚类过滤、语言模型内部知识自评与冲突归并；当内部知识缺失或与新事实冲突时，自评信号需要外部证据校准。[P9] RADE 将路径条件影响与共识参照的语义风险结合；语义风险坐标是共识代理。原文指出，完整责任度估计可能依赖 token 级评分、attention 访问，或外部/代理评分；文本接口部署需要为这些内部信号提供替代估计。[P11] 这些机制构成可组合的防御部件，不意味着对所有语料、攻击预算或答案类型提供无条件保证。共同的设计问题是：**当正确回答依赖多个前提时，系统如何验证每个前提的来源与支持，并量化答案对少数来源的依赖？**

本方案采用“来源归并—证据链构建—来源移除检验—定向补证—受约束生成”流程。共同来源的多个块仍可共同支持多跳推理，但不被计作多个独立见证。防御规则不使用 `UNKNOWN→KNOWN`、key-value 形式或攻击者指定答案等特定载荷标志；其判定对象是支持链、来源依赖与竞争断言。

## 二、来源、命题与完整证据链

### 2.1 来源组与候选材料

保留原始 Top-K 上下文 $C_0$，另从既有稠密检索与 BM25 各取 Top-$K_r$，按固定交替顺序去重，构成有上限的核验池 $C_v$；原始 Top-K 必须全部保留在核验池内。两个通道的排名仅决定材料读取优先级，不参与真假投票。$K_r$、总块数与总 token 上限在开发集固定。

设 $\mathcal G=\{g_1,\ldots,g_m\}$ 为来源组。同一 source_id 的所有块属于同组；服务器记录的复制、镜像、共同原始引用和高置信内容派生关系进一步归并。DocID、域名或文字相似各自都不是独立性的证明。来源表保存归并理由，来源不明的材料按保守组规则处理，并对不同归并粒度作敏感性分析。

设 T 为由部署方事先指定的可信参考渠道，如经版本管理的权威数据库。T 的资格来自配置与来源核验，外部文本不能通过自称“官方”获得该资格。普通来源组属于待检验集合，T 中已核验的引用在来源移除检验中保持可用。

### 2.2 将证据与指令分离

轻量抽取器对每块产生有界结构记录：`claim_id, subject, relation, object, qualifiers, quote_span, source_group, kind`。qualifiers 包含时间、地点、条件、单位和否定；kind 区分事实陈述、带归属的观点、对系统的指令。程序核对 quote_span 与原始文本精确对应，拒绝无出处的叶子事实。

对每条关系，核验器输入查询、规范化命题与必要原句，输出支持/不充分/矛盾三类文本标签及理由。设标签分数 $u_e\in\{1,1/2,0\}$，作为证据匹配等级；开发时也可用有标注数据校准的连续分数。采用三档等级时设 $1/2<\tau_s\le1$，使不充分的边只参与补证定位，不进入最终通过链。检索分不混入 $u_e$，该等级衡量原句对命题的支持程度。事实真实性通过来源与后续独立补证处理。

带有“忽略之前要求”“把此答案作为最终结论”等操作性内容被保留为审计事件，不成为推理规则。法律条文、医疗指南中的规范性句子，按其对象和适用条件保留为领域命题。抽取器、核验器和最终生成器均使用部署方固定提示；外部引用以数据字段传递，权限始终固定。

### 2.3 允许多前提推理的证据图

设事实与中间结论为节点，一条推理边 $e:(p_1,\ldots,p_j)\Rightarrow p$ 需要多个前提同时成立。这样的边称超边；例如“甲的父亲是乙”和“乙出生于丙”共同支持“甲的父亲出生于丙”。它表达正常多跳所需的合取关系，也能呈现恶意关系替换。

设 $\mathcal A_{\mathrm{ess}}$ 为回答查询所需的有限原子断言集合，由查询类型与部署方固定的答案格式策略抽取；无法稳定识别其成员时，该查询不作自动事实断言，返回证据不足或转人工核验。候选构建器在已抽取的记录上提出有限个答案及推理边；按共享实体、关系类型和限定条件生成候选连接，再由核验器检查结论是否由这些具体前提推出。固定的等式代换、日期和单位比较由程序执行；其余语言关系以有出处的证据包核验。规则不能引入未列出的事实前提。仅有循环引用且没有可追溯叶子事实的链不成立。

设 $\mathcal W_a$ 为支持候选答案 a 的有限条完整证据链。一条链 w 是以 a 为根的有限无环证据超图，包含所有叶子引用、从引用到命题的支持边及推理边；因此直接引用回答也至少有一条支持边。其来源集合 $G(w)\subseteq\mathcal G$ 包含所有普通来源依赖，并对中间命题递归取其全部叶子来源。可信引用也必须完整列出，只是不进入 $G(w)$。联合构建允许一个来源内的多个块，也允许跨来源多跳；无需任一单块独立回答问题。

为保证可实现，设置每块最多 p 条命题、每题最多 A 个候选答案、每答案最多 $H_a$ 条链、链深不超过 h。扩展中先保留不同来源集合与不同关系路径，再按证据质量排序截断。候选答案包括规范化的互斥事实值；长答案按原子断言逐项处理，观点题保留说话者与立场归属。候选遗漏作为证据覆盖诊断，不将未枚举答案当作已排除答案。

## 三、从证据支持推导来源稳健性

### 3.1 链内合取与链间替代

一条完整链的每个前提都必需，最弱环节限制这条链的支持强度。因而采用瓶颈分数：

$$Q(w)=\min_{e\in w}u_e.$$

这可视为逐环节设置同一准入门槛：$Q(w)\ge t$ 当且仅当每条边的分数均不小于 t，因而容易逐条审计。无需假设不同环节的错误概率独立。

若存在多条能单独完成证明的替代链，任何一条成立即可支持答案，所以采用最大值而非计票求和。设 B 为本轮暂时移除的普通来源组：

$$S_a(B)=\max\left(\{Q(w):w\in\mathcal W_a,\ G(w)\cap B=\varnothing\}\cup\{0\}\right).$$

空集合的支持分取零。复制同一链不会提高最大值；同源复述也不会增加可承受的来源移除数量。相互补充的两条事实必须先组成一条完整链，不能把两条不完整链的分数相加。

### 3.2 移除少量来源后的共同判定

设 b 为非负整数，表示部署方希望检验的污染来源组数量；$\mathcal B_b=\{B\subseteq\mathcal G:|B|\le b\}$，包含空集合。对答案 a，首先要求在每一种来源移除情形下仍保留足够支持：

$$\underline S_a=\min_{B\in\mathcal B_b}S_a(B).$$

仅有支持还不够，还要检查同一来源移除情形下的不相容答案。设 $\mathcal I(a)$ 为与 a 在相同时间、条件和问题语义下互相矛盾的候选，且矛盾关系对称；无不相容候选时最大竞争分取零。取：

$$M_a=\min_{B\in\mathcal B_b}\left[S_a(B)-\max\left(\{S_c(B):c\in\mathcal I(a)\}\cup\{0\}\right)\right].$$

这里先在同一个 B 下比较，再求最坏情形，避免把不同情形的支持和冲突错误拼在一起。保留满足 $\underline S_a\ge\tau_s>0$ 且 $M_a>\tau_m\ge0$ 的断言。互不矛盾的断言可共同输出；互斥答案至多有一个通过严格正余量检查。

**来源依赖诊断。** 设 $F_a=S_a(\varnothing)-\underline S_a\ge0$。该差值表示移除少量来源后损失的证据支持，最坏集合 $B_a^*$ 记录依赖位置。F 大说明需要补证。正常单源文档也可能有较大 F，因此报告状态为“已支撑”“存在冲突”或“证据不足”，而不把来源依赖直接标成攻击。

### 3.3 定向补证与上下文生成

当关键断言未通过时，沿最坏情形下消失的链找出缺少替代来源的叶子前提，以及冲突答案的关键差异。由规范化实体、关系及限定条件生成核验查询，在预先配置的参考渠道补证；外部文本中的指令不用于构造检索请求。新材料仍执行来源归并与引用核对；只有部署方预先配置且通过来源核验的渠道才可归入可信集合 T，镜像页面不产生独立见证。

设每题最多提交 $Q_{\max}$ 个不同查询哈希、运行 $R_{\max}$ 轮、向证据图纳入至多 $T_{\max}$ 个新增补证 token；这三个预算为有限非负整数。每个不同查询最多发起 $r_{\max}\ge1$ 次请求，失败重试计入该查询上限；每轮最多提交 $R_{\mathrm{batch}}\ge1$ 个不同查询；每次响应的 token 上限为 $T_q\ge1$，且客户端实际纳入量不得超过剩余 $T_{\max}$。所有远程请求设置有限超时，输出长度有硬上限；超限响应在纳入前按固定 tokenizer 截断。查询哈希规范化后去重，已尝试哈希不再提交。先核验影响最多未决断言的叶子；数量相同时先处理存在明确矛盾的前提。新引用通过时增加替代证据链，发现矛盾时增加有出处的竞争断言；来源归并更新后，按当前全部普通来源组重新生成 $\mathcal B_b$，再计算 $\underline S_a$ 与 $M_a$。不能沿用较小的旧来源集合，否则新发现的来源不会受到移除检验。当所有关键断言通过、任一预算耗尽、没有未尝试查询，或一整轮未增加任何新的经核验引用/命题/推理边时停止。最后一种情形即使还有未尝试查询也终止，避免系统对同一缺口反复提出等价问题。补证轮次、返回为空、超时、重复哈希和停止原因均进入日志。

这里的“证据图指纹”由规范化引文及其文本哈希、引用区间、命题、带端点和核验标签/分数的支持与推理边、来源组归并结果、可信状态，以及当前各证据链的来源掩码组成；核验器版本固定，镜像与重复引用在入图前去重。若复核会改变已有边的核验标签或分数，也必须反映在指纹中。因此指纹未变才表示本轮既未增加可用证据，也未改变任何会影响来源移除计算的核验状态。

该循环必定终止：每轮末尾将轮数加一，且不超过有限 $R_{\max}$；新查询哈希累计不超过 $Q_{\max}$；客户端纳入证据图的补证 token 总量不超过 $T_{\max}$；每个查询的请求数不超过有限 $r_{\max}$，且每个远程请求有超时。每次请求的输出上限取剩余 token 预算与 $T_q$ 的较小值；若响应仍超限，客户端只保留预算内前缀并丢弃其余内容。因此循环至多执行 $R_{\max}$ 轮；空结果、无新可用证据或无未尝试查询会使其更早退出。此终止结论针对补证循环，不声称远程服务必定成功返回。

输出证据包包含通过的断言、完整引文链、时间/条件限定，以及未解决的冲突或缺口。主生成器只对通过的断言组织语言；观点题展示有来源的多种立场，不将偏好伪装成唯一事实。生成后逐断言检查与证据包的一致性，失败项回退为结构化的原断言和引文；尚未支持的关键事实使用固定的证据不足说明。

每个引文片段按固定长度裁剪并保留偏移，单项不超过 512 tokens，整包与链数均设上限。该方案将证据选择与语言表述分开，使可追溯的支持链一直保留到最终输出。

## 四、保证、边界与简单证明

### 4.1 同源复制与无关切分不增加支持票数

**命题 D1（重复不变性）。** 在规范化事实、边评分与来源组均不变时，重复同一证据链，或把同一事实在更多同源块中重复展示，不改变 $S_a(B)$、$\underline S_a$ 与 $M_a$。

**证明。** 每个重复链都具有相同 Q 和来源集合。对任意 B，它与原链同时可用或同时失效；最大值集合中增加一个相同数字，最大值不变。再对相同数值求最小值和差值，结果也不变。$\blacksquare$

该性质抑制切块数量或复制次数形成的伪多数。实际重新切分可能影响抽取质量，因此实现先将引用映射回 source_id 与字符偏移，再归并等价命题；映射和抽取错误单独测量。

### 4.2 来源移除稳健性与多跳保留

**命题 D2（固定证据图上的稳健结论）。** 若 a 通过上述支持与余量条件，则移除任意至多 b 个普通来源组后，在保留下来的链上，a 的支持至少为 $\tau_s$，且比已枚举不相容候选的最大支持与零基线中的较大者高出超过 $\tau_m$。

**证明。** 最小值不大于被比较集合中的任一项。所以对每个允许的 B，$S_a(B)\ge\underline S_a\ge\tau_s$，且 $S_a(B)-\max\left(\{S_c(B):c\in\mathcal I(a)\}\cup\{0\}\right)\ge M_a>\tau_m$。当 $\mathcal I(a)=\varnothing$ 时，零基线仍可计算该余量。反过来，若每个 B 均满足支持阈值及对该零基线竞争分数的余量阈值，则有限集合上的两个最小值也满足阈值，二者等价。$\blacksquare$

这项保证作用于当前冻结的证据图及候选集，检验的是其依赖结构。它允许每条链包含多条事实、多块及多个来源。例如两条不共享普通来源的完整两跳链都具有足够支持，则删去任一来源后至少一条仍完整；只有两段互补事实而没有独立替代证据时，系统识别该依赖并进入补证。

**推论（可保留的证据冗余）。** 若存在 $b+1$ 条普通来源集合两两不相交、质量均不低于 $\tau_s$ 的完整链，则 $\underline S_a\ge\tau_s$。

**证明。** 删除一个来源最多触及其中一条链，删除 b 个来源最多触及 b 条，剩下至少一条。若有一条完全由可信引用支撑、来源集合为空的链，它在所有 B 下都保留。$\blacksquare$

这给出一个容易检查的充分条件，不要求所有任务都拥有这种特定冗余形状。存在复杂重叠时直接枚举 B 更准确。

### 4.3 何时能够推出事实正确性

**命题 D3（条件事实保证）。** 设实际受污染或不可靠的普通来源组集合为 $B^*\subseteq\mathcal G$ 且 $|B^*|\le b$；进入 $\mathcal W_a$ 的每个叶子均完整映射到已归组的普通来源或可信引用，不存在来源未知的叶子；来源分组完整覆盖实际控制关系；可信引用以及 $\mathcal G\setminus B^*$ 中的来源在所用事实与限定条件上准确；通过阈值的引用支持边忠实对应原句，推理边保持真前提推出真结论。若候选 a 在同一冻结证据图上满足 $\underline S_a\ge\tau_s>0$，则命题 a 为真。

**证明。** 由 $|B^*|\le b$ 得 $B^*\in\mathcal B_b$，故按定义 $S_a(B^*)\ge\underline S_a\ge\tau_s>0$。由于 $\mathcal W_a$ 有限且空集支持分为零，必存在一条完整链 $w\in\mathcal W_a$ 满足 $Q(w)\ge\tau_s$ 且 $G(w)\cap B^*=\varnothing$。链中普通来源均不属于 $B^*$，其叶子事实来自准确的未污染来源或可信引用；引用支持边忠实，推理边保持真前提推出真结论。从叶子开始逐步应用这些推理边，最终得到 a 为真。$\blacksquare$

条件集中在三个可审计环节：来源归并是否覆盖实际控制关系，引用支持边是否忠实，核验器是否接受了无效推理。自然语言核验器对这些条件存在误差，后续实验分别报告来源漏并、事实核验误差、链构建遗漏与最终错误回答。该命题只保证冻结证据图上的断言，不保证自然语言生成器一定无误；生成后仍需逐断言校验并在失败时回退到证据文本。

对于本就存在错误或过时信息的普通语料，将该来源一并计入 $B^*$，并按时间限定评估。攻击完全挤出正确材料时，支持条件可能不再成立，补证与选择性回答处理证据缺失。

### 4.4 计算复杂度与实现路径

设核验池有 K 个块、m 个普通来源组、A 个答案、总计 H 条完整链。来源移除情形数为：

$$N_b=\sum_{j=0}^{\min(b,m)}\binom mj.$$

组合数 $\binom mj=m!/(j!(m-j)!)$ 来自“挑选 j 个不同来源”：顺序挑选有 $m(m-1)\cdots(m-j+1)$ 种，同一集合被 j! 个排列重复计数。m=5 时，b=1 需 6 个情形，b=2 需 16 个情形。

用位集合保存 G(w)，检查链是否受 B 影响只需位与操作。每情形先遍历 H 条链求各答案最大支持，再处理不相容候选，耗时 $O(N_b(H+A^2))$；m 超过机器字长时，位与再乘 $\lceil m/w\rceil$，w 为字长。若所有答案两两互斥，用最大和次大支持可把每情形比较降到 $O(A)$。全部情形共享事实抽取、边核验与链质量，不重复调用 LLM。

语言模型开销来自有界的块抽取、边核验、补证材料处理和一次最终表述。图构建可能出现组合增长，通过预设深度和链数上限限制；D2 对保留的链集精确成立，证据覆盖率随这些上限单独报告。相比每个文档子集都重新生成完整答案，这种设计把组合检验移到可缓存的数值操作上。总延迟、GPU 时间和 token 数作为实测量报告。

开发集固定 b、支持/余量阈值、来源规则和链上限，再在独立 clean 集与多攻击族上评价准确率、覆盖率、拒答率与攻击成功率。单源合法问题和跨源多跳分别分层，直接量化补证能否恢复可回答性。

\begin{algorithm}[H]
\caption{RAGShield: Provenance-Aware Robust Evidence Verification}
\label{alg:ragshield}
\SetKwInOut{Input}{Input}
\SetKwInOut{Output}{Output}
\SetAlFnt{\footnotesize}
\Input{Query, baseline Top-$K$, bounded retrieval channels, server provenance, trusted references;
source bound $b$, thresholds $\tau_s,\tau_m$, finite budgets $Q_{\max},R_{\max},T_{\max}$,
per-query tries $r_{\max}$, batch size $R_{\mathrm{batch}}$, response cap $T_q$, timeout.}
\Output{Supported answer, attributed disagreement, or insufficient evidence.}
Validate budgets and hard output/timeout limits\;
Build a bounded pool retaining baseline chunks; merge provenance groups and extract quoted claims\;
Separate external instructions; construct bounded multi-premise witnesses; verify and cache edges/masks\;
Initialize attempted hashes, counters and evidence-graph fingerprint; compute $S_a(B),\underline S_a,M_a$\;
Mark unresolved essential assertions using the fixed thresholds\;
\While{an essential assertion is unresolved and all round/query/token budgets remain}{
    Select up to $R_{\mathrm{batch}}$ priority queries with unseen hashes within the remaining query budget\;
    \If{no query is available}{\textbf{break}\;}
    Save the evidence fingerprint\;
    \ForEach{selected query $q_r$ while token budget remains}{
        Mark its hash attempted; count it once; retrieve with at most $r_{\max}$ tries, timeout and $\min(T_q,T_{\max}-t_{\mathrm{used}})$ output cap\;
        Truncate excess response text to the remaining token budget before adding it to the graph; update the accepted-token counter; verify quotes/provenance/claims; merge sources and recanonicalize all IDs and witness masks\;
        Add only new usable evidence\;
    }
    Increment round; rebuild bounded witnesses and current source groups\;
    Recompute every allowed source-removal set, supports, margins and unresolved assertions\;
    \If{the verified-evidence fingerprint is unchanged}{\textbf{break}\;}
}
Accept each assertion iff $\underline S_a\ge\tau_s$ and $M_a>\tau_m$; preserve unresolved gaps\;
Generate wording only from accepted evidence; verify output and fall back to cited claim text on inconsistency\;
\Return{answer, citations, attributed disagreements and remaining evidence gaps}\;
\end{algorithm}

# 第三部分：研究路径与理论支持范围

攻击以 >512 tokens 的 gold 文档和 clean QA 有效样本开始，在完整源文档上构造角色。分别报告结构有效率、自然 CoRecall@K、自然目标成功、单块泄漏及联合增益；forced-context 只解释组合机制。搜索固定池与配置，按真实总计算量比较候选初始化、随机搜索、独立候选 BO 和图 BO，最后冻结载荷进行目标迁移评测。

防御覆盖四类攻击：检索优化型、单块指令/错误事实型、主题立场操纵型、跨块与多来源组合型。消融来源归并、完整链核验、最坏来源移除和定向补证；同时检查正常同源多跳、跨源多跳、时效性事实与有争议观点。攻击自适应实验在防御方案固定后开展，不能以同一批手工模板包办训练与测试。

理论链条如下：A1 证明热核矩阵可作为协方差先验，不证明候选语义相似就必然奖励相似；代理预测质量由预留观测检验。A2 说明固定 GP 假设下反馈如何影响相关候选，A3 保证有界经验目标上的上界筛除保留所有可能严格改进的候选；D1 消除复制计票，D2 对冻结证据图检验来源移除稳健性，D3 在来源与推理假设满足时推出证据图断言为真。搜索加速和自然语言防御效果仍由实验检验。
