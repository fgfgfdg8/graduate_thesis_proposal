# RAG 安全攻防文献筛选方案
## 1. 方案定位

用于从检索得到的 RAG 安全攻防文献列表中，筛选值得优先阅读与分析的论文。

最终得分采用：

> **加平滑的加权几何平均 + 独立开源因子乘子**

三维主项保持：

1. Venue 级别 \(V_i\)；
2. 时间归一化引用速度 \(R_i\)；
3. 领域自适应新近度 \(T_i\)。

开源因子 \(O_i\) **不参与三维权重分配**，而是作为**独立乘子**平滑接入，避免破坏原有 \(w_V+w_R+w_T=1\) 的结构。

---

## 2. 最终公式

\[
\boxed{
P_i=
V_i^{\,w_V^{(i)}}
\cdot
(R_i+\epsilon_R)^{\,w_R^{(i)}}
\cdot
(T_i+\epsilon_T)^{\,w_T^{(i)}}
\cdot
O_i^{\,\gamma}
}
\]

等价 log 形式：

\[
\boxed{
P_i=
\exp\Big[
w_V^{(i)}\ln V_i+
w_R^{(i)}\ln(R_i+\epsilon_R)+
w_T^{(i)}\ln(T_i+\epsilon_T)+
\gamma\ln O_i
\Big]
}
\]

其中：

- \(O_i\)：开源因子，取值 \(O_i\in[0.5,\,1.5]\)；
- \(\gamma\)：开源因子强度，推荐 \(\gamma=0.3\)；
- \(\epsilon_R=\epsilon_T=0.01\)；
- \(V_i\ge 0.01\)；
- \(w_V^{(i)}+w_R^{(i)}+w_T^{(i)}=1\)。

**关键点**：开源因子用 \(\gamma\) 控制强度，且 \(O_i\) 被限制在 \([0.5,1.5]\)，避免开源论文因代码仓库火而压过顶会经典，也避免闭源论文被过度惩罚。

---

## 3. 符号定义

| 符号 | 含义 |
|---|---|
| \(V_i\) | 会议/期刊级别得分 |
| \(C_i\) | 清洗后的引用数 |
| \(t_i\) | 发表时间或 arXiv 首次公开时间 |
| \(T\) | 当前时间 |
| \(a_i\) | 发表至今月数，\(a_i=\max(0.5,(T-t_i)/30)\) |
| \(g(i)\) | 子领域分组 |
| \(\bar r_{g(i)}\) | 子领域局部平均引用速度先验 |
| \(\tilde r_i\) | 贝叶斯收缩后的引用速度 |
| \(R_i\) | 归一化引用项 |
| \(T_i\) | 时间新近度 |
| \(O_i\) | 开源因子 |
| \(n_i\) | 是否 3 个月内 arXiv |
| \(\gamma\) | 开源因子强度 |
| \(P_i\) | 最终优先级 |

## 4. Venue 级别得分 \(V_i\)

| 级别 | 示例 | \(V_i\) |
|---|---|---|
| 顶会/顶刊 | S&P, CCS, USENIX Security, NDSS, CRYPTO, IEEE TIFS, TDSC | 1.00 |
| 一流会议/期刊 | ACSAC, RAID, ESORICS, DSN, ICSE, FSE, TOSEM | 0.80 |
| 知名会议/期刊 | AsiaCCS, SAC, IFIP SEC, Computers & Security | 0.60 |
| 普通同行评议 | 一般 SCI/EI 期刊或会议 | 0.40 |
| 预印本/未同行评议 | arXiv, TechRxiv | 0.20 |
| 其他/未匹配 | workshop、非同行评议 | 0.10 |

多来源取最大：

\[
V_i=\max(V_{i,\text{venue}},V_{i,\text{preprint}})
\]

若 arXiv 已中顶会，按顶会算。

防零：

\[
V_i\leftarrow \max(V_i,0.01)
\]

---

## 5. 引用数清洗

### 5.1 剔除自引

\[
C_i^{(1)}=C_i^{\text{raw}}-\text{SelfCite}_i
\]

### 5.2 异常引用增量检测

\[
z_{i,m}=
\frac{\Delta C_{i,m}-\text{median}(\Delta C_{i,\cdot})}
{1.4826\cdot\text{MAD}(\Delta C_{i,\cdot})+\epsilon}
\]

若 \(z_{i,m}>3.5\)，对该月增量截尾或剔除。

### 5.3 FWCI 思想

\[
C_i^{\text{FWCI}}=
\frac{C_i^{(2)}}{\bar C_{g(i),a_i}}
\]

最终：

\[
C_i=\max(0,\ C_i^{(2)}\ \text{或}\ C_i^{\text{FWCI}})
\]

---

## 6. 分层贝叶斯先验

### 6.1 分组

1. Venue Tier × 年份；
2. 关键词聚类：LLM Security、Hardware Security、Crypto、AI Safety、System Security；
3. 全局兜底。

组内样本 \(<10\) 时回退。

### 6.2 局部先验

\[
\bar r_g=
\frac{1}{|\mathcal D_g|}
\sum_{j\in\mathcal D_g}
\frac{C_j}{a_j}
\]

样本不足时收缩：

\[
\bar r_g^{\text{shrunk}}=
\frac{n_g\bar r_g+n_0\bar r_{\text{parent}}}
{n_g+n_0}
\]

推荐 \(n_0=10\)。

### 6.3 贝叶斯收缩

\[
\boxed{
\tilde r_i=
\frac{C_i+\alpha\,\bar r_{g(i)}}{a_i+\alpha}
}
\]

推荐 \(\alpha=6\sim12\)，回测校准。

---

## 7. 引用项归一化

\[
R_i=
\frac{\text{rank}(\tilde r_i)}{N-1+\epsilon}
\]

或：

\[
R_i=
\frac{
\log(1+\tilde r_i)-\min_j\log(1+\tilde r_j)
}{
\max_j\log(1+\tilde r_j)-\min_j\log(1+\tilde r_j)+\epsilon
}
\]

平滑：

\[
R_i\leftarrow \max(R_i,0.01)
\]

---

## 8. 领域自适应时间衰减

\[
\boxed{
T_i=
\exp\left(
-\frac{T-t_i}{\kappa_{g(i)}\cdot\tau}
\right)
}
\]

推荐 \(\tau=24\) 个月。

| 领域 | \(\kappa\) |
|---|---|
| Crypto / 理论 | 1.5 |
| Hardware Security | 1.2 |
| System Security | 0.9 |
| AI / LLM Security | 0.8 |
| AI Safety | 0.7 |

若有引用半衰期 \(h_g\)：

\[
\tau_g=\frac{h_g}{\ln 2}
\]

平滑：

\[
T_i\leftarrow \max(T_i,0.01)
\]

---

## 9. 开源因子 \(O_i\)（独立计算）

开源因子**单独计算**，不占三维权重，最终以 \(\gamma\) 强度平滑接入。

### 9.1 设计原则

- 鼓励开源，但不唯开源；
- 闭源论文不被一票否决；
- 开源质量比“是否开源”更重要；
- 限制取值范围，避免失调。

### 9.2 分项打分

| 维度 | 说明 | 分值 |
|---|---|---|
| 代码公开 | 有可访问仓库 | 0.40 |
| 数据/评测集公开 | 数据集、benchmark 公开 | 0.25 |
| 模型权重公开 | 模型或 checkpoint 公开 | 0.20 |
| 文档/复现脚本 | README、复现实验脚本完整 | 0.10 |
| 社区活跃度 | Star、Issue、PR、更新频率 | 0.05 |

各项加和得 \(O_i^{\text{raw}}\in[0,1]\)。

### 9.3 平滑映射到 \([0.5,1.5]\)

\[
\boxed{
O_i=
0.5+O_i^{\text{raw}}
}
\]

因此：

- 完全闭源：\(O_i=0.5\)；
- 仅代码公开：\(O_i=0.9\)；
- 代码+数据+权重+文档：\(O_i=1.5\)。

若信息缺失，默认：

\[
O_i=1.0
\]

避免误伤未标注开源的论文。

### 9.4 接入方式

\[
P_i=
V_i^{\,w_V^{(i)}}
\cdot
(R_i+\epsilon_R)^{\,w_R^{(i)}}
\cdot
(T_i+\epsilon_T)^{\,w_T^{(i)}}
\cdot
O_i^{\,\gamma}
\]

推荐：

\[
\gamma=0.3
\]

含义：

- \(O_i=1.5\) 时，乘子 \(1.5^{0.3}\approx1.13\)，提升约 13%；
- \(O_i=0.5\) 时，乘子 \(0.5^{0.3}\approx0.81\)，下降约 19%。

强度温和，不破坏主结构。

## 10. arXiv 新文献冷启动保护

定义：

\[
n_i=
\begin{cases}
1, & \text{arXiv 且 } T-t_i<3\text{ 个月}\\
0, & \text{否则}
\end{cases}
\]

基础权重：

\[
w_V=0.45,\quad w_R=0.40,\quad w_T=0.15
\]

调整：

\[
w_R^{(i)}=w_R(1-\lambda n_i)
\]

\[
w_V^{(i)}=w_V+\frac{\lambda n_i w_R}{2}
\]

\[
w_T^{(i)}=w_T+\frac{\lambda n_i w_R}{2}
\]

推荐 \(\lambda=0.6\)：

\[
w_V^{(i)}=0.57,\quad w_R^{(i)}=0.16,\quad w_T^{(i)}=0.27
\]

非 arXiv 新文献或 older arXiv 保持：

\[
w_V=0.45,\quad w_R=0.40,\quad w_T=0.15
\]

---

## 11. 最终筛选规则

### 11.1 计算得分

\[
P_i=
V_i^{\,w_V^{(i)}}
\cdot
(R_i+0.01)^{\,w_R^{(i)}}
\cdot
(T_i+0.01)^{\,w_T^{(i)}}
\cdot
O_i^{0.3}
\]

### 11.2 排序

按 \(P_i\) 降序。

### 11.3 分层

| 层级 | 规则 | 用途 |
|---|---|---|
| S 级 | \(P_i\ge P_{90}\) | 必读 |
| A 级 | \(P_{75}\le P_i<P_{90}\) | 优先读 |
| B 级 | \(P_{50}\le P_i<P_{75}\) | 选读 |
| C 级 | \(P_i<P_{50}\) | 暂缓 |

### 11.4 人工兜底

- 3 个月内 arXiv 且主题高度相关；
- 顶会/顶刊但发表时间很短；
- 被 top-k 论文高频引用；
- 作者为领域知名团队；
- 开源生态极强但引用尚少的新论文。

---

## 12. 完整计算流程

1. 收集文献：venue、引用数、发表时间、是否 arXiv、关键词、作者、开源信息。
2. 清洗引用：剔自引 → 异常增量 → 可选 FWCI。
3. 映射 \(V_i\)，取 \(\max(V_i,0.01)\)。
4. 计算 \(a_i=\max(0.5,(T-t_i)/30)\)。
5. 分组 \(g(i)\)。
6. 计算局部先验 \(\bar r_{g(i)}\)，样本少时收缩。
7. 贝叶斯收缩得 \(\tilde r_i\)。
8. 归一化得 \(R_i\)，取 \(\max(R_i,0.01)\)。
9. 计算 \(T_i\)，取 \(\max(T_i,0.01)\)。
10. 计算开源因子 \(O_i=0.5+O_i^{\text{raw}}\)，缺失时 \(O_i=1.0\)。
11. 判断 \(n_i\)，调整权重。
12. 计算 \(P_i\)。
13. 按 \(P_i\) 降序，分 S/A/B/C。
14. 人工复核兜底项。

## 14. 开源因子回测校准

将 \(\gamma\) 加入网格搜索：

\[
\gamma\in\{0.1,0.2,0.3,0.5\}
\]

评估指标：

- Spearman \(\rho\)；
- NDCG@10；
- Precision@10。

若加入开源因子后 NDCG@10 提升，则保留；否则降低 \(\gamma\) 或置 0。

## 16. 最终一句话总结

\[
\boxed{
P_i=
V_i^{\,w_V^{(i)}}
\cdot
(R_i+0.01)^{\,w_R^{(i)}}
\cdot
(T_i+0.01)^{\,w_T^{(i)}}
\cdot
O_i^{\,0.3}
}
\]

其中：

- 三维主项保持 \(w_V+w_R+w_T=1\)，结构不变；
- 开源因子 \(O_i=0.5+O_i^{\text{raw}}\in[0.5,1.5]\)，独立计算；
- 通过 \(\gamma=0.3\) 平滑接入，开源强提升约 13%，闭源下降约 19%；
- 信息缺失默认 \(O_i=1.0\)，避免误伤；
- 3 个月内 arXiv：\(w_R\downarrow,\ w_V\uparrow,\ w_T\uparrow\)；
- 最终按 \(P_i\) 降序，分 S/A/B/C，人工复核兜底。

该版本将开源因子**单算、平滑、限幅、可回测**地接入几何平均，既不破坏原有三维权重，又能真实反映 RAG 安全攻防领域“代码/数据/模型可复现性”的重要价值。
