# Lazy Grounding: Attacking Search Agents with Factual Evidence

**本次结论。** 这是开题攻防的直接机制近邻：多条与原问题很像、但支持相邻问题答案的搜索结果，可使智能体把对相邻问题成立的答案错误地当成原问题的答案；这种错误支持并不要求文档包含明确攻击指令。**但论文没有证明“同一源文档分块后两个互补块分别不足、共同必要”**。它默认每个合成记录就带相邻问题和答案；既有多记录实验也没有做开题的四种固定上下文反事实。对于防御，论文已实测“固定原问题约束并核对每条证据支持什么”的提示，直接限制该方向的宽泛首创性，但不等于验证了开题的随机森林、跨块关系和异源锚点组合。

## 3. 攻击机制：能造成错误支持，但没有证明双块共同必要

设原问题 q 的正确答案为 a，语义相近的 q′ 改变时间、对象层级、关系、范围或回答槽位，答案为 b，b 对 q′ 成立而对 q 不成立。作者设计的失败是：模型遇到支持 q′→b 的材料后，在回答 q 时照搬 b，或把 b 当作错误的中间前提（p.1–3、p.11–14）。Figure 1 中可见关于颁奖混淆的结果和“最初宣布赢家”问答这两个不同结果：把后者用于“正式获奖者”会产生错误归因；**该示意不能证明两条结果分别必要**。

主设置每题准备 **10 条合成搜索记录**：单改写组 1 条原 q′ 加 9 条仅改问题措辞的同答案改写；每条带标题、显示 URL、摘要和访问后的合成页面，正文在答案字段、摘要等处重复相邻答案（p.9）。多改写组也使用 10 条，可覆盖不止一个 q′/b（p.4–5、p.9）。它们确实让不同结果/页面反复提供看似相关的支持；但此处“结果/页面”不等于被目标文档分块器切出的同源 chunk，而且每条记录可单独显式给出 b。论文没有逐一去掉两条互补块并检查每条单独无效、两条同时有效，也没有证明文中错误由多块组合推理造成。**结论是已有多结果误导证据，不是已证明多块联合必要。**

在 web 基准，作者没有将页面公开发布并等待真实搜索引擎索引；他们在 search/visit 层合成增强结果，合并真实候选后重排，模拟检索表面（p.2、p.10）。BrowseComp+ 使用本地后端；论文 §2.2 将其概念化为向本地语料添加，附录 C.1 则具体说明对检索结果加入近邻记录并接管 search/visit，不能直接当作已验证外部数据库持久写入。真实发布、索引、站点声誉与跨分块器存活均没有端到端验证（p.5）。

## 4. 实验、具体结果和统计边界

**设置。** 通义 Deep Research（30B-A3B）、GPT-5 Mini、Gemini 3 Flash，共用 ReAct 搜索框架；XBench DeepSearch、GAIA、BrowseComp+、HLE 各 100 个原问题；每题干净/增强各 3 次。改写生成和核验使用与受测 agent 分离的 GPT-5.4。指标：原问题正确率 Acc；RAA 为增强运行中采用目标近邻答案的比例；RAA-C/F 分别以配对干净轨迹正确/错误为条件（p.3、p.10）。表 1 的 ± 为三次运行的样本标准差，并非三个独立问题样本；表 7 的 95% 区间以问题为簇，保留三次重复和两臂，重采样 100,000 次（p.3、p.11–12）。

- **时序**：100 次条件下，Tongyi 的早/中/晚轮 RAA 为 9.0/10.0/15.0；在每次被选中的搜索结果页中记录都置前，所以这里改变的是**跨轮时序**，不是比较同一页不同排名（Table 2，p.4）。
- **格式**：同 100 个 GAIA 问题，答案字段组/自然语句组的 RAA 为 23.0/19.0，增强准确率为 59.0/60.0；自然文本也会造成迁移（Table 3，p.4）。
- **多改写**：四基准均衡的 100 题、每题 10 条，单改写组 RAA 20.2、增强准确率 49.5；多改写组 15.0、73.0；分别有 99 和 100 次完成（Table 4，p.4–5）。这检验不同近邻答案的证据池，**没有证明任何两条证据共同必要**；不同完成数及条件差异也不支持直接解读为每题必然改善。
- **约束检查防御**：GPT-5 Mini、同 100 个 XBench 问题、各 3 次：对照/约束提示 Clean 为 64.0/64.3，Aug. 为 52.0/53.7，RAA 为 20.7/14.3；下降 6.4 点，配对 bootstrap 95% CI [0.7, 12.0]。同一控制组另行运行，所以数值与 Table 1 略异；这是提示消融，不是通用防御或开题全流程的效能证明（Table 5，p.5；提示原文位置 p.15）。

**真实性和评价边界。** 论文希望 q′ 的证据真实，但人工抽查只有每个基准 10 条、总共 40 条：40/40 的 b 不正确回答 q；其中仅 **34/40** 的 b 被核实正确回答 q′，另 6 条未核实正确，不能直接等同“6 条已证伪”。三位标注者的该二元判断 pairwise agreement 0.950、Fleiss κ 0.771（Table 6，p.9–10）。自动判分的另一个 48 条小样本由三作者与判分器一致核验（p.10）；这不足以证明全部生成事实、全部判分或外部基准均已独立人工验证。

**近邻判断。** 对“真实但适用条件不同的证据引发错误归因”、多结果吸引和约束核验提示，已有直接方法/机制先例；对“单源文档经未知或变化的分块后形成两个互补角色块、双块共召回且固定对照下共同触发”，本文尚未提供相同证据。这个差异是可检验的窄化空间，不是自动的新颖性证明；仍需与其他跨块/联合归因近邻共同比较。

## 7. 可用于后续研究的严格对照（建议，非论文已完成结果）

1. 在相同候选、相同 top-k 和输出预算下，至少比较原排序 clean、同一 dense reranker 的 clean、同一 reranker 的增强组；另单独消融查询自适应摘要、显示域名和 visit 别名。记录每个查询的真实结果排名、近邻暴露、实际打开和答案变化，拆分检索、呈现和生成因素。
2. 若要主张开题双块协同，固定同一背景、位置、长度及语义相称的中性替代，执行 C00/C10/C01/C11 多随机种子试验；同时报告载荷完整率、双块共召回、受控 Y 组合与端到端 ASR。单块无目标命中不等于输出必须为 UNKNOWN；不同 chunker 和背景需分别测，不能由单次二值门控外推。
3. 将 q′ 的答案 b 作为**对 q 不直接支持、但可作为中间线索**的有标签硬负例；核对实体、时点、范围、属性和关系，同时保留正常互补桥接。分别报告 RAA、原问题准确率、证据适配、受检/误删、正常多跳效用及时延；正常证据可能真实且有用，不以“相近”自动标毒。
4. 若复验论文数值，先取得并版本固定对应 benchmark、私有改写与证据清单、真实搜索快照/轨迹、模型版本及成本；仓库的 toy fixture 和论文配置本身不构成原始样本复现。
