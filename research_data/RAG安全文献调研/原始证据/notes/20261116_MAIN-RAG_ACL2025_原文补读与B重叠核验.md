# MAIN-RAG 正式版补读及开题 B 重叠核验

## 结论和切换依据

本轮补读 **MAIN-RAG: Multi-Agent Filtering Retrieval-Augmented Generation**。它在检索后、生成前使用逐文档 LLM 判断、按当前查询的得分分布自适应过滤并排序，与开题 B 的“检索上下文筛选与正常问答效用”直接重叠，适合作为一般噪声过滤及计算成本的强基线。它没有在可核实范围内报告对抗投毒的攻击成功率、良性桥接块误删率或正常多跳证据集合保留率，因此不能把普通 QA 改善当作投毒防御已经成立。其动态阈值不是用独立干净查询最大风险分数做查询级误报校准。

原优先目标 **Rethinking the Reranker: Boundary-Aware Evidence Selection for Robust Retrieval-Augmented Generation** 的[证据地图条目](<../../../../docs/RAG安全证据地图_20261102.md#src-89c14d081918208b>)登记为 L2；其原本机笔记（仅在本机可用）记录：正式 PDF 物理 p.1–8 的引言、§2.1–2.5、§3.1–3.6、§4 和 p.9 结论／Impact Statement 已读，另选读附录；这一范围覆盖其所列全部正文节。为避免重复精读，本轮依据原记录视为正文已覆盖并切换，**没有再次精读这些正文**。旧笔记仍自定 L2、未逐段留有全部正文审计记录，尚未通读全部文献与附录；因此这里不擅自更改其等级，也不把“按所列范围覆盖”冒充本轮逐段重验。地图仍有同一论文另一个 L1 目录项，不能当成独立研究或覆盖已读正式版。

本轮选取 MAIN-RAG 的依据：证据地图和原本机笔记（仅在本机可用）均为 L2；正式出版于 ACL 2025 主会 long papers；与 B 在线过滤的关系比一般生成质量论文更直接；而原笔记明确未覆盖若干页并将 §4.1–4.4 标成局部，仍有可补读内容。两项选择及下文风险判断是本次审读判断，不是论文作者对开题的评价。

## 方法、结果与可比较的分母

**运行过程。** p.2 图 1 与 p.12 图 11，结合旧笔记已读 §3：每条查询默认取 top-20 文档；Predictor 针对每份文档独立生成候选答案；Judge 输入文档、问题与候选答案，判断文档是否提供回答所需的具体信息以及该答案是否基于文档直接回答问题。Judge 的 Yes/No token 对数概率差用作相关分，按当前查询各候选的均值减 `n` 倍标准差设置阈值（默认 `n=0`），保留过阈值的文档并按分数排序，Final-Predictor 用保留结果回答。这里的“多代理”是功能角色协作，不意味着多家独立来源的事实共识。该流程无需对 LLM 做任务微调，但推理时包含多个逐文档模型调用；training-free 不等于推理零成本。

**主表（物理 p.7 Table 1）。** 同为 Llama3-8B，表内 training-free 普通 RAG 与 MAIN-RAG 的对比如下；百分数差是**百分点**，不是攻击指标：

| 数据集／指标 | 普通 RAG | MAIN-RAG | 差值 |
|---|---:|---:|---:|
| TriviaQA accuracy | 73.1 | 74.1 | +1.0 |
| PopQA accuracy | 61.8 | 64.0 | +2.2 |
| ARC-C accuracy | 55.6 | 61.9 | +6.3 |
| ASQA str-em | 37.1 | 39.2 | +2.1 |
| ASQA ROUGE | 36.5 | 42.0 | +5.5 |
| ASQA MAUVE | 63.0 | 70.6 | +7.6 |

这些数字是不同任务的回答／文本质量指标，不能称为 ASR、投毒检出率、FPR、块误删率或多跳证据保留率；也不能将所有数据集的指标分母相加。该表没有由此证明与 B 等预算、等模型调用数或显著性结论。

**分母（p.5 §4.1 定点复核）。** TriviaQA-unfiltered 原测试集不可公开，作者使用 Asai 等工作提供的验证／测试设置，文中称评测包括 **11,313 testing queries**；不要进一步误称为 TriviaQA 原始隐藏 test 集。PopQA 是月维基浏览量少于 100 的长尾子集，**1,399 个稀有实体查询**；不据此自行补写其原始 split。TriviaQA 和 PopQA 的 accuracy 按生成文本是否包含金标答案判分，并非严格的整句 exact match。ARC-Challenge 是选择题任务，ASQA 是长答案任务；本次核对未确认两者用于该表的精确样本数，记为未知。每个表格数字按相应数据集和指标理解；MAIN-RAG 的 1,399 条与其他论文使用的 PopQA 全集并不自动同分母。

**阈值和排序消融（p.7–8 Table 2）。** 以 Mistral-7B、降序为例：TriviaQA 默认均值阈值 71.0，减 `0.5σ` 为 71.2；PopQA 默认 58.9，减 `1.0σ` 为 58.0。升序时 PopQA 为 53.5，对应降序 58.9。这些均为 accuracy；阈值／排序改变效用的方向因数据集、模型和设置而异，不能把均值或 `μ−nσ` 解释为经过独立干净校准得到的有限样本 FPR 保证。

**案例、局限与成本（p.8–16）。** p.14 图 13 的 Andreas Rüdiger 问题把哲学家和足球运动员的同名线索混入保留上下文，最终回答职业为足球运动员，而给定金标为 philosopher；这是一个自然噪声／实体混淆的定性失败案例，既不是恶意攻击演示，也不是可外推的误删比例。p.12 Judge 要求文档对作答有具体支持并要求候选答案基于该文档；**推断**：在必须联合多份文档的查询中，单个必要桥接块即使有价值，也可能因不能单独支持完整答案而被低分或过滤。论文未在此给出该概率、证明桥接块一定误删，或提供 HotpotQA 等正常多跳保留实验。p.11 附录 A 列出 4 张 80GB A100；p.9 作者指出推理和重复实验的环境成本，但没有给出本次已核实的逐查询端到端延迟或完整 token／费用曲线，不能由硬件数量替代实际成本评测。

本轮对 PDF 全文文字做定位检索：`poison*`、`adversari*`、`attack*`、`false positive*`、`multi-hop` 和 `HotpotQA` 均无字面匹配。这与上述已读材料一起支持“未发现相应实验报告”，但关键词扫描不是对语义等价表述的形式化穷尽证明；尤其不能凭零命中声称证明论文绝不涉及所有相关概念。

## 与开题 B 的直接交集和边界

对照对象为项目[开题 B 正文](../../../../partitions/section3_content.tex)中 §研究点二，特别是检索后防御、特征融合、阈值校准、跨块关系与 LLM 复核。其当前内容是研究设计，不是已实现、已验证的性能结论。

| 维度 | MAIN-RAG | 开题 B／可比性判断 |
|---|---|---|
| 所处阶段与目标 | 检索后在线逐文档判断、过滤、排序，改善自然噪声下 QA | 同在检索后、生成前，拟对可疑投毒块送审并保留正常效用。**直接近邻**：不能笼统宣称“LLM 审文档＋自适应阈值＋正常效用”首创。 |
| 局部打分与成本 | Predictor 与 Judge 的文档—问题—答案判断，需可获得相关 token 分数；再调用 Final-Predictor | B 拟将四项统计特征与冻结的 ModernBERT 查询—块表示、PCA、随机森林融合，之后选择待审块给 LLM。架构不同不意味着必然更快，须量化编码、图构建、参照检索、所有 LLM 调用和总延迟。 |
| 阈值 | 当前 query 的候选分数均值及其标准差；直接筛选保留集 | B 拟在独立干净校准查询上取各查询 Top-K **最大风险**的有限样本分位数，超阈值块送 LLM 复核。若固定评分器且校准与未来干净查询最大风险可交换，针对的是统计分支查询级告警；不是跨块触发率或最终 LLM 误删率的保证。具体实现和实际覆盖率仍需实验验证。 |
| 多块与来源 | Judge 的基本单位是单文档及对应答案，未证明跨文档事实或来源独立；相互支持不自动等于真实 | B 拟检查实体—命题关系、来源及异源参照，并尽量保留合法桥接证据。方法目标不同；提取误差、异源质量、同源协同伪装和正常多跳误删仍需检验。 |
| 威胁与效用 | 四项常规 QA；无已核实的投毒 ASR、查询级 FPR、良性桥接误删或完整多跳支持集合保留结果 | B 面向投毒与干净效用联合评价，不能将 MAIN-RAG 表 1 的 QA 提升换算成攻击防御。应在相同检索池、模型、top-K 和攻击条件下纳入直接基线。 |

**推荐的明确分母（本次研究设计建议，不是 MAIN-RAG 已报告指标）：** (1) 攻击 ASR：命中攻击目标的受攻击查询数／按协议进入相应端到端测试的受攻击查询数；若另报保证注入／召回的条件 ASR，应单列其条件及分母。(2) 统计分支查询级告警：至少一块超风险阈值的干净查询数／干净查询总数；最终良性误删另报“被删除良性块／检索到的良性块”及“至少误删一块的干净查询／干净查询”。(3) 桥接块召回：最终保留的必要良性桥接块数／进入原始候选集的必要良性桥接块数；完整支持集保留率：保留全部必要块的查询数／所有必要块原本均进入候选集的查询数。另报原始检索支持集召回，避免把检索漏召算成防御误删。以上依赖明确标注、样本划分和预算；论文没有提供这些分母或结果。

## 原目标对 B 的既有证据，不重复阅读

下列内容**转述 Rethinking 原 L2 笔记已注明的正文／附录**，不是本轮新增的正文阅读：其 selector 按生成器的回答难度／能力边界挑选证据集合，再交替训练生成器；selector 仅用于训练，推理时移除，因此它是正常多证据选择和多跳效用强近邻，而不是运行时恶意过滤器。论文旧记录中七项 QA 评估包含多跳任务；p.16 Table 5 所列 NQ、HotpotQA、TriviaQA、PopQA、2Wiki、MuSiQue、Bamboogle 分别为 3,610、7,405、11,313、14,267、12,576、2,417、125 个评估查询。它们不是恶意攻击、误删或多跳证据保留率的分母。p.13–14 的 remove-all-cited／keep-only-cited 是被引用**集合**的反事实，不等于每个桥接块都必要或来源可信。原笔记还记录了 p.7 NQ 数字与主表不一致的未决问题，使用前应查原表，不静默合并。

与 B 的实质边界同样包括：未见对抗投毒、源文档替换、查询级 FPR、块级误删及完整桥接证据保留的已记录实验；没有以 B 的四统计与冻结表示／随机森林给块评分，也没有其独立干净查询最大风险分位校准。能力边界目标与 B 统计送审阈值有不同语义。对开题 A，普通多证据集合选择不能替代单源改写、未知分块和同源双块协同攻击的威胁模型。
