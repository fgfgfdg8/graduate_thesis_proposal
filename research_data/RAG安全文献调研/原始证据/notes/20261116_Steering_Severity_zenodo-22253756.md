## 威胁模型、方法和实验口径

1. **受攻击对象。** 对某个 CVE，agent 检索与该 CVE 相关的 CTI 文档并输出严重性等级，攻击者控制并发布其中 **一篇**可能被检索到的 CTI 来源，目标是使等级上调或下调。攻击者不能修改模型权重、系统提示、诚实来源或检索算法；训练期后门、系统提示注入、主机入侵和多文档协同均被排除（p.2 §II）。这是针对外部 RAG/CTI 来源的事实性单源投毒，不是改用户 prompt。论文没有证明真实开放网络中的实际发布、收录或检索命中率。
2. **管线和模型。** 作者描述 BGE-M3 稠密表示、NumPy 精确余弦检索，Llama 3 8B、Qwen2.5 7B、Mistral 7B 本地 Ollama；主设置为 temperature 0、固定种子 1337（p.2）。本次不核查具体实现，也不将本地运行表述为零计算成本或已验证部署延迟。
3. **样本与对照。** 8 个虚构 CVE、每例 3 条作者编写的诚实来源，共 24 条；其中 4 例设计为下调 CRITICAL、4 例设计为上调 MEDIUM/LOW（p.3 Table I）。诚实来源的事实和措辞由作者构造，所谓独立来源是实验设计假设，不等于对真实来源溯源独立性的验证。攻击比较使用同一模型的干净基线与单源污染条件；论文还在 Llama 上比较 2 条与 3 条诚实来源。每个攻击方向仅 4 个 CVE，跨模型是同一组 8 个 CVE，不能视作 24 个独立真实漏洞。
4. **留一防御。** 不训练新检测模型：对完整来源集合及逐一移除的子集做联合严重性判断，查找移除某个来源后能留下至少 3 条内部一致来源、且候选唯一的情形；识别该来源并用剩余来源的联合判断作为修正。无唯一候选时作者写作不判有毒；总来源不足 4 条时弃判（p.3 §IV-D）。正文未给出足以独立复算所有边界情况的完整稳定性形式化和并列处理细节，本次未查看实现；不能据此把推测当成程序行为。
5. **评价目标。** 攻击成功是相对该模型自身干净输出沿攻击方向发生等级偏移；恢复是防御输出回到该模型的干净等级，检测是识别污染来源，干净误报是无毒输入中误指诚实来源。恢复和攻击偏移均不自动等于相对设计金标准正确（pp.3、5）。

## 结果、对照与反例

| 模型，均为 8 个合成 CVE | 单源攻击等级偏移 | 污染条件下检测 | 防御后回到模型干净等级 | 论文报告的干净误报 |
|---|---:|---:|---:|---:|
| Llama 3 8B | 8/8 | 8/8 | 8/8 | 0/8 |
| Qwen2.5 7B | 7/8 | 7/8 | 7/8 | 0/8 |
| Mistral 7B | 4/8 | 7/8 | 8/8 | 0/8 |

来源：p.5 Table VII。攻击和防御分别列有不同 M4/M5 运行；每列分母是 8 个案例，不是 token、来源数量或独立真实漏洞。Mistral 的检测 7/8 与恢复 8/8 评价的是不同事件，不可把恢复 8/8 改写成“8 个成功攻击均被检出并纠正”。

- **干净三来源的零误报与四来源及以上的误报必须分开。** Table I 的干净设置为每例 3 条诚实来源；污染设置为 3 条诚实来源加 1 条毒来源（p.4 §V-C）。按作者规则，对干净的 3 条来源移除任一条只剩 2 条，达不到剩余至少 3 条的门槛，故弃判，表中每模型干净 `0/8` 与这个结构性弃判一致。这不是在四条及以上全为诚实来源的可检测条件下测得的 `0/8`；论文未给出该条件下的独立误报分母。也不能把三模型重复同一组 8 例当成 24 个独立真实负例。
- **作者的零误报表述与证明范围。** p.3 说干净 `≥3` 来源可由结构保证零误报，但紧接的论证只展示了恰好 3 条的情形；p.5 则将 FP=0 写为依赖 `≥4` 来源和诚实集合一致的结构性质。对 4 条干净来源，移除 1 条后已剩 3 条，数量门槛本身不再排除候选；是否满足唯一一致性还取决于稳定性判据。一个需要单独测试的诚实分歧情形是：4 条均诚实，只有移除其中一条后其余 3 条满足规则，其余留一子集不满足；若规则确实如此判定，就可能误指该诚实来源。**这是基于文字规则的条件性反例，不是已运行实现或观察到实际误报。** 论文这 8 个诚实集合均被作者称为内部一致，不能由此推出开放环境的零误报。
- **恢复不等于金标准正确。** 对 CVE-2099-0004 与 -0008，Table I 的设计金标准为 LOW，但 Llama 干净输出均为 MEDIUM；Table IV 的防御输出也为 MEDIUM。因此这两例计入恢复模型干净等级，不能据此说已恢复设计金标准（pp.3–4）。Mistral 的四个下调目标干净输出为 HIGH、设计共识为 CRITICAL，作者提醒这会影响向下偏移空间，不能把 4/8 简化为模型对攻击更鲁棒（p.5）。
- **真实漏检反例。** Qwen 在 CVE-2099-0002 上出现 CRITICAL→MEDIUM 两级偏移且防御漏检；作者解释为移除嫌疑来源后的剩余集合没有达到其一致性门槛（p.5）。正文没有充分形式化该门槛，本次不推断更一般的失效概率。
- **朴素影响归因会混淆诚实贡献。** Table V 中 CVE-2099-0004 的三条诚实来源与毒来源，逐一移除的影响均为 1 个等级；Table VI 在同一组保存结果上离线比较：绝对影响规则检测 8/8、恢复 4/8，方向规则检测/恢复各 6/8，内部一致规则检测/恢复各 8/8，三者均报告干净 0/8（p.4）。检测、恢复和误报分开，且此处干净对照仍有上述来源数限制。
- **来源数只在小型对照中有效。** Llama 的 4 个上调案例，2 条诚实来源时平均偏移 2.0 级、3 条时 1.5 级；4 个下调案例两种条件均为 1.0 级（p.4 Table III）。因此“增加诚实来源一定减弱所有攻击”有反例；前者污染输入总数为 3 条，按防御规则还会弃判。
- **评分器有效性。** 论文观察到 CVSS 分值集中及向量格式错误，因此以等级而非细粒度 CVSS 计算评价；非贪心复测仅针对 2 个 CVE、每例 5 个种子（p.4）。Appendix B 在 2 个真实 CVE 的自由映射试验中有 6/8 个 ATT&CK 技术概念不匹配，不应扩大为所有模型或所有 CTI 任务的错误率（p.6）。

## 对开题 A/B 的关系

以下以[现有证据地图中的 A/B 定位](../../../../docs/RAG安全证据地图_20261102.md)为准：A 关注长源实际分块、同一 query 共召回和逐块共同必要；B 关注固定表征四统计、离线 RF、低误报和最终删块后的 QA 效用。

- **A：直接的单源事实投毒近邻，但不是已证明的跨块协同攻击。** 重叠在于攻击者只控制一篇外部来源，意图让检索增强任务偏离干净判断，并有诚实来源与上下调对照。区别是本篇约 60 词的一篇 CTI 毒来源、按 CVE 限定检索和严重性等级任务；未展示单一长源经未知受害分块形成互补角色块、同一 query 共同召回，以及逐块/联合删除证明共同必要。不能以其单源有效性替代 A 的三项验证，也不能据此宣称多块场景安全。
- **B：来源级反事实删除与纠错的直接方法近邻。** 它已做跨来源比较、留一识别、选择唯一嫌疑来源和按剩余来源修正；“首次利用来源间互证或反事实删除净化不可信上下文”会与其重叠。但它不训练 B 所述固定表征/RF，不报告面向一般检索块的分类、正常多跳桥接块保留、删除后的开放域 QA 效用或四条及以上干净来源的可检测条件误报。它是有条件的参考/候选对照，不是 B 的低误报保证。
- **范围限制与待核。** 人工构造的 8 例、同作者来源、3 个 7–8B 模型及单源攻击限制外推；Appendix A 的真实 CVE 初探暴露答案泄漏和可能的模型先验，但没有完成真实 CVE 受控攻击验证。真实多源相关性、来源独立性、四源及以上诚实分歧、未知分块、同源多块协同、正常多跳和端到端开销均未在本文得到本次可据以外推的证据。代码制品核验及缺失日志见上节，论文结果仍未复现。
