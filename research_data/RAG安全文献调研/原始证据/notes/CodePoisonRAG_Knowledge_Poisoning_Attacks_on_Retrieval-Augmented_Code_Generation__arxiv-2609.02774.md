## 问题、威胁模型和载荷构造

论文研究检索增强代码生成（RACG）的上游知识投毒：先准备与预期编程任务对应的恶意代码资料，等待受害者摄入并在后续检索中使用。攻击者知道预期任务功能和选定 CWE，但不必知道最终自然语言查询的确切措辞；造毒时不能查询受害系统，也不知道或不能访问其部署知识库、检索器、重排器、生成器、提示模板或防御。攻击者能向可能被受害者采纳的公开代码源或数据集提交资料，不能控制受害者的模型和推理管线。攻击生效依赖受害者实际摄入这些上游资料（p4–5，式 4–6）。

预算为**每个预期任务至多一个污染 artifact**；实验却把与 85 个任务对应的 85 个 artifact 一起加入检索库，不能将每任务预算误写为整批实验只投一条。攻击目标同时要求：对应污染片段进入该查询最终生成上下文，且输出代码含攻击者选定的 CWE。论文没有在成功定义中给出对漏洞利用或功能正确性的独立动态证明（p4、p8–9）。

构造先选任务相符的良性函数和兼容 CWE，尽量保留接口、名称与功能相关结构；**Vulnerability Injection** 改造 source → passthrough → sink 污点链，嵌入所选缺陷；**Semantic Mislabeling** 仅在注释或文档中虚称已采取相应安全措施，不修复该污点链。p6–7 的例子分别说明路径校验被简单 `trim` 取代、限长写入变为不设界限的写入，以及代码未转义但注释声称已转义。流程图将上游准备与受害系统内的检索、重排、生成明确分开（p5–7）。

实验材料是**函数级代码片段**，不能由此推断真实长文档经过未知受害分块器后仍形成互补块。65 条 Java 片段为人工构造，20 条 C 片段由 LLM 辅助生成并检查；10 类 CWE 的类别样本量为 5 或 10。论文以 ReposVul 的 12,053 条 fixed-code 条目作良性检索池，再加入 85 个污染片段，投毒比例为 `85/(12053+85)≈0.700%`（p7–8）。这一批任务、载荷和同源语料构造方式会影响外推性。

## 实验设置、指标与分母

使用 `jina-embeddings-v3`、FAISS 精确余弦检索及 `jina-reranker-v2-base-multilingual`；最终上下文为 Top-3。生成器为 Qwen 3.5 9B、Code Llama 13B 和 DeepSeek-Coder-V2 16B；各实验条件处理同一批 85 个触发查询，不能当作 255 个独立任务。生成温度为 0，关闭内建推理模式（p8–11）。

- **RSR**：对应污染片段进入最终上下文的查询数 / 所有评估查询数；主实验每条件分母 85。
- **ASR**：对应污染片段进入最终上下文**且**输出被判含目标 CWE 的查询数 / 所有评估查询数；不是“进入检索后”的条件成功率（p8，式 7–8）。
- **TWR**：输出被判含目标 CWE 的查询数 / 所有评估查询数，不要求污染片段存在或被检索；无投毒消融因没有污染片段而使用 TWR（p8–9、p12）。
- 输出主要由 GLM-5.1 按预先给出的目标 CWE 和 sink 规则判定，关注主要代码块中的完整 source–passthrough–sink 链；缺链、错误语言、空桩等在其规则下归为未成功。附录 Table X 逐 CWE 指定模式，Fig. 5 给出完整判定提示；这些规则只供评审器使用，不展示给生成器（p9、p15–16）。判定器并非独立的漏洞可利用性证明。

## 与开题 A/B 的关系

对照 [开题研究内容](<../../../../partitions/section3_content.tex>) 和其中的威胁模型、两阶段防御设计（同文件第 23、28、30、227、238 行）：

- **A，同源多块攻击**：共同点是针对目标任务构造外部材料，关心检索进入和下游生成的联合结果；本论文的攻击构造期间还假定无法查询受害者。差异是本论文向上游贡献独立函数级材料，目标是生成指定 CWE 的代码；开题则替换唯一长源文档，研究未知分块后两种互补同源角色块的完整性、实际联合召回和固定背景下的各块必要性。本文无这些分块及缺一块实验，不能当作已验证该交集，也不能据此声称该交集在整个领域无人研究。本文有交叉编码器重排，而当前开题目标管线明确不配置额外重排器，比较时应分开配置。
- **B，检索上下文防御**：与开题共通的是恶意内容可通过检索影响生成，且表面安全注释未必可信。开题在生成前结合单块统计/语义、跨块关系和异源参照复核，并重视正常多跳证据保留；本文的 CodeGuarder 评测是向生成提示补充漏洞相关安全知识，并非对这些机制、误删、良性多跳保留或调用开销的直接评测。代码生成与自然语言问答的任务、材料和 CWE 指标不同，不能直接合并其效果。
