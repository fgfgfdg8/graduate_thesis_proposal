## 机制与评测

在Cocktail的14个数据集混合检索人工文本及其LLM生成的语义对应文本，比较13个检索器；生成文本语义保持依赖基准构造与检查，不能因此证明文本真实。查询和段落最大长度分别为32、512 token。正文指出，相关性监督的正负例在困惑度与词汇特异性等表面特征上存在差异，这些特征可能形成与LLM来源差异对齐的捷径；其线性化及对比学习解释属于论文的条件化机制分析，不证明每一种模型和语料都以此为唯一原因（p1–8，12）。

ΔNDSR@5按排名权重计算前五项的来源占比，取人工来源减LLM来源：负值表示偏向LLM文本，正值表示偏向人工文本。有符号平均值接近零可能来自正负抵消；它不是投毒检测率。训练时通过改变负样本采样减弱来源偏好；推理时用其他数据集中的配对人工/LLM文本估计差向量，再移除段落嵌入的相应分量。目标数据集所在语料组留出，其余11组各采样100对，共1,100对；这需要可用配对数据，且不是零成本或恶意识别（p7–8）。

## 主要结果和不可混用的统计口径

- Table 5的ANCE在5数据集上的**有符号均值**为−0.093→−0.009，论文给出残余10%；Table 18先对每个数据集取绝对值再平均，为0.093→0.013、残余14.0%。二者统计量不同，不能把10%称为平均绝对偏差残余（p8、27）。
- Table 17中ANCE在SciFact上由−0.025变为+0.095，偏好方向翻转且绝对偏差从0.025增至0.095。14数据集有符号均值为−0.106→−0.014；按印刷的逐项值复算，平均绝对偏差约0.1059→0.0414，残余约39.1%，不能用其13%的有符号均值比代替（p26）。
- Table 18的25个模型—数据集组合中，作者报告投影法平均残余绝对偏差为原来的51.2%，CDC为64.5%；投影法在16/25格更小，不意味着每个模型和数据集均优。更换Qwen3-32B生成文本后，作者重新用Qwen配对数据校准，25格中23格的绝对偏差下降，不能称Llama方向无需重校准即可迁移（p26–28）。
- Table 15比较的是训练时负采样，而非推理时投影：14数据集平均NDCG@5，in-batch-only为0.475，标准混合负采样为0.493，仅难负样本为0.487；个别数据集趋势不同。不能用这组数字断言投影后检索效用不下降（p25）。
- **原文统计未闭合**：Table 4的14个印刷值按绝对值再平均，in-batch-only、标准、仅难负样本分别约0.0411、0.0994、0.1093；Table 16把seed 42的对应值列为0.050、0.099、0.100。首尾差异超过逐项三位小数的舍入范围。仅凭论文不能判断表格、seed标记或记录哪处有误，不将数值冲突当作实现已复现错误（p7、25）。

## 对开题的影响

这是B的**检索表示及来源偏差方法近邻**：合法LLM生成文本也可能形成稳定方向，干净参考库来源不匹配时，表示残差可能混入正常来源差异。可在相同query级误报预算下，将合法机器生成文本作为单独干净层，并比较配对位移、方向投影与逐数据集偏差；来源方向不是已知恶意方向。

论文没有攻击者控制知识库、单源未知分块、同源互补块协同召回或恶意块判别，也未给攻击成功率、投毒检出率或合法多跳证据保留率；其正常检索来源偏好不能认作对开题A/B完整安全问题的直接覆盖。
