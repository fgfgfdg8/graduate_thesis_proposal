## 威胁模型与方法

SearchInject 针对检索增强搜索中的间接提示注入：攻击者针对已知 query family 控制发布页标题、正文与类 markup 元数据；攻击页在最终测试前固定，不针对防御器自适应。防御器可见 query、候选文本和检索器分数，在生成前处理原始 top-100。对每个候选计算 `z=[r,a,i,ar,ir]`：归一化相关性 `r`、搜索滥用特征 `a`、指令似然 `i` 及两个相关性交互项；class-balanced logistic score 高于阈值即隔离。候选按原排名保序，从原 top-100 继续补足至 10 篇；不重排幸存项，也不发起额外检索。

阈值 `0.973853` 在校准集上按经验 clean-candidate false-quarantine ≤0.5% 约束选取，校准误隔离率为 0.498%，检出率为 0.804。作者明确说明这不是新样本上的概率或风险保证。

## 全文核读要点

- 语料为 5,183 篇 SciFact 摘要；查询划分为 655 fitting、154 calibration、300 test。攻击载荷来自 BIPIA 的特定子集，9 类用于拟合、3 类校准、13 类测试。四种构造族（title stuffing、doorway、near duplicate、hidden metadata）均已在开发阶段出现；payload category 有留出，但测试不是未见构造族。源文档互斥未建立。
- 只测 BM25、LSA、归一化 BM25/LSA 混合检索，depth=100；不包含 Dense Passage Retrieval 或现代稠密编码器。主指标是被隔离的目标页是否仍进入前十上下文（Exposure@10），不是最终攻击成功率。
- 每个检索器有 300 个 query × 4 个构造族 = 1,200 个重复观测；作者按 300 个 query 单位报告解析置信界，并明确依赖 query 独立假设。Exposure@10：BM25 `.9408→.1583`、Hybrid `.9158→.1508`、LSA `.8450→.1375`，相对下降 83.2%–83.7%。
- 同一冻结阈值的测试集 clean-candidate false-quarantine 为 BM25 0.590%、Hybrid 0.620%、LSA 0.650%，均高于校准目标 0.5%；校准样本量未报，无法从汇总结果重建校准误差区间。clean NDCG@10 变化分别为 `-0.0018`、`-0.0013`、`-0.0013`；作者没有做等效性检验。
- 单特征比较不是同 FPR/同预算的组件消融：abuse-only 平均 Exposure@10 `.1436`，clean ΔNDCG `-0.1113`；instruction-only `.4169`、`-0.0071`；joint `.1489`、`-0.0014`。无 `[r,a,i]` 对 `[r,a,i,ar,ir]` 的匹配误隔离比较，故交互项收益未识别。连续重排的效用损失亦显著依赖检索器。
- 下游生成仅为探索性：104 个目标均进入未防御 hybrid top-5，隔离后 83 个上下文移除目标指令；但预设/事后判定下未防御组没有确认成功的 hijack，且每个 104-case cell 有 4 个未决判断。因此只能说明检索暴露变化，不能估算防御降低了攻击成功率。
- 复现边界：正文称有 31,500 query-level 行与 315,000 top-10 行的汇总运行记录，但精确重放需输入与切分哈希、目标清单、归一化参数、向量器/分词器、系数、原始分数与排名、软件版本，以及生成模型/提示/输出和标签；本版本未提供原始候选记录及训练产物。

## 对开题的定位影响

- **B 的直接方法近邻**：与开题的生成前风险筛选、基于干净样本选择隔离阈值及保留正常检索效用直接相邻；应列入前置比较。它采用检索相关性 + 搜索滥用/指令特征 + logistic quarantine/refill，不是开题拟议的四项检索统计 + 冻结 ModernBERT 表征 + 随机森林，再叠加跨块实体—命题关系筛查和至多一次 LLM 复核。
- **安全目标不同**：本文处理携带可执行指令的检索页面，关注其进入模型上下文；开题处理恶意/虚假事实投毒、来源证据与多块命题关系。文本块 quarantine 不是事实真伪或来源可信认证。
- **攻击侧仅邻接，不构成同源跨块协同攻击的直接先例**：本文控制已知查询下的页面构造和检索暴露；没有一份真实长源经受害方未知 chunker 后生成互补角色块、同 query 共召回、逐块/联合移除证明共同必要的实验。它约束的是宽泛的“通过操控检索准入把不可信页面送入 LLM”表述。
- **应吸收的评价教训**：校准集达标不等测试集 FPR 保证；须同时报告候选级与最终 query 级误删/OR 风险、正常多跳答案效用、refill 影响，以及相同 clean-FPR 下的特征消融。Exposure 不能替代端到端 hijack/poisoning success。
