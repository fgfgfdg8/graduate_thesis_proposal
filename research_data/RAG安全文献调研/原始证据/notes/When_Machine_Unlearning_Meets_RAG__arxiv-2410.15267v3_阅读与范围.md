## 2. 补读核查：问题定义与优化目标

**行为遗忘与模型知识删除（p1–3、p15）**。作者把目标定位为改变可观察输出：用外部检索知识中的保密约束，使服务拒绝给出目标内容，并尽量保持非目标任务表现；这种行为效果不能直接证明模型参数不再存有相关知识。p2 图 1 区分“RAG 纠正错误信息”“通过 RAG 保密”与理想化“删除目标知识”。表 I 中对抗恢复、灾难性遗忘及低开销的 Y/N 对照属于作者的概括，应结合实验条件理解，不是形式化安全证明。p15 VIII 总结版权、隐私和有害输出应用时也没有给出参数删除证明。

**五项准则（p5 III.D）**：有效性覆盖样本和概念遗忘；通用性涉及不同模型及扩展场景；无害性关注非目标效用；简便性关注部署与计算成本；鲁棒性关注越狱、提示注入等压力。它们是作者提出的评估维度，不能把“参数未修改”直接推演成所有正常查询均无误拒。

**优化式及其角色（p5 IV.B—p6 公式 1）**。作者将待遗忘概念记为 `C_i`，为其构造遗忘知识 `K_i`，形成集合 `UK`，与良性知识库 `BK` 一起参与检索。`G(C_i)` 产生相关问题，检索器 `Γ` 从 `UK ∪ BK` 返回上下文，固定参数的生成器 `A(·; θ)` 作答；优化目标是让目标问题上的 `Verify` 判断尽可能多地满足遗忘目标。原 L2 已概括每个知识项的检索相关部分 `P` 和保密约束 `Q` 的分工：这是围绕服务方已知目标构造并控制上下文。公式中的 `Verify` 是目标效果的判别概念，不应直接等同于开题 B 的检索后、生成前恶意块检测器。

**扩展的证据强度（p7 IV.D、p12–13 VI.A、图 8）**。作者讨论将同类 RAG 外挂扩展到多模态模型和基于 LLM 的 Agent；其中 Agent 的表述先是方法适用性论述，不能仅据 p7 算作完整 Agent 安全评测。多模态案例使用 DALL·E 3、两个目标概念及图 8 中相关同义表达做图像前后对比；展示是定性案例，不足以证明跨任务、跨模型或所有同义词都能稳定遗忘。音频扩展在 p13 被写作理论方向与未来研究，不是已完成的音频实证。

## 3. 补读核查：实验、指标和成本

**目标遗忘与成员推断（p9–10、表 IV）**。继承旧 L2 的指标定义：USR 由外部 GPT-4o 根据遗忘前后响应判断；ROUGE-L 衡量与参考答案的重叠；`TPR@1%FPR` 是针对目标样本/概念的成员推断评估点。表 IV 中，RAG 方法的概念遗忘 USR 对 GPT-4o、Gemini 和 Llama-2-7b-chat 分别为 `99.2%±1.0%`、`99.5%±0.8%`、`99.8%±0.3%`；Llama-2-7b-chat 的样本遗忘为 `100%±0%`。同表报告相应成员推断 TPR 分别为 `1.5%±0.2%`、`1.3%±0.4%`、`1.3%±0.3%` 和 `1.2%±0.2%`。这些是论文设置下的输出和攻击指标，不等于模型中目标信息被删除，也不保证其他威胁模型下无法恢复。

**有害主题实验（p9、p10 表 V）**。论文随机选 25 个主题、为每个主题生成 5 个相关问题形成遗忘集合，并为每个主题另造 10 个问答对用于训练；被评估的 Llama-2-7b-chat 在该训练设定后的遗忘集合上，文中称原始有害输出概率为 `91.2%`。表 V 对 RAG 方法报告有害输出概率 HOP `1.0%±0.8%`、USR `99.3%±0.6%`。这是一项经特定数据构建、模型微调和判定流程得到的结果，不等价于任意实际部署都满足地域合规。

**改写与跨模型（p9–11、表 VI–VII）**。作者用 GPT-4o 对测试提示作保持语义的改写。表 VI 中 RAG 方法改写后的 USR 为 GPT-4o `99.0%±1.3%`、Gemini `99.3%±1.0%`、Llama-2-7b-chat `97.1%±0.5%`；这是所选改写测试，不代表所有自适应攻击均有效抵御。表 VII 报告 GPT-4o mini 和 GPT-4.0 概念遗忘分别为 `99.3%±1.1%`、`99.6%±0.5%`；Llama-2-13b-chat 样本/概念为 `96.4%±0.7%` / `97.6%±1.6%`，Vicuna-7B 为 `98.1%±1.0%` / `98.6%±1.2%`，PaLM 2 的概念为 `100%±0.0%`、样本一栏为 N/A。作者将 PaLM 2 放入“open-source”表组，本笔记不把该分组当作已核实的模型开放性事实。

**时间口径（p11 V.E、p12 表 X–XI）**。表 IX 的测量从提出遗忘请求到完成处理，固定五个概念、使用 Llama-2-7b-chat：梯度上升 `4,752 s`、in-context unlearning `11 s`、µ-unlearning `3,177 s`、RAG 方法 `63 s`。因此，作者所说约 `75.4×` 是 `4752/63` 的构建阶段对比；in-context 在此更快，但该论文其他指标显示其效果较弱。这个 63 秒不是正常用户一次查询的在线延迟，也不是开题 B 的逐查询检测成本。

表 X 对 Llama-2 7B、13B、70B 报告 `63、61、63 s`；表 XI 对 5、10、15、20、25 个概念报告 `61、135、192、272、338 s`。作者给出约 `13.3N` 秒的经验近似；这些有限点没有给出可外推到任意规模、检索基础设施和 API 配额的复杂度保证。

## 5. 与开题 A/B 的交集与边界

**A：同源互补分布式投毒。** `P` 的相关性与 `Q` 的行为约束确实是不同功能角色；p6 的优化式又把“先检索到相关知识、再改变回答”放在同一框架，说明“检索角色 + 行为角色”的一般组合已有先例。但此处由服务方根据已知目标授权构造知识项并控制 RAG，不能等同于攻击者只改写单一外部长文档、由未知受害者分块、两个同源互补块必须联合召回才能导致目标回答。作者的保密目标也不自动证明跨块逻辑桥接、不同分块配置迁移或攻击者可控权限。p14 VII.D 另讨论从 RAG 知识库删除具体信息及其定位/效率困难；那是作者讨论的另一种遗忘对象，不是对 A 的投毒实验或对知识库所有副本均已清除的证明。

**B：检索后检测、校准及正常多跳证据保留。** 该文的 `Verify` / USR 聚焦目标回答是否达成遗忘，和 B 在生成前识别并处理可疑检索块的时点、对象与输出不同。成员推断的 `TPR@1%FPR` 不能充当干净 query 上最大块风险分数的分位阈值或误删保证；MMLU/ARC 的一般效用也不能替代正常多跳问题的跨块证据保留指标。p11–12 的遗忘请求处理耗时不能充当 B 的在线单查询额外延迟。需要对误拒、检索漏命中、相似正常主题、跨块溯源及不同检索配置分别实验，而不是把本论文的高 USR 扩展成 B 的验证结果。

**信任边界**：本论文中的约束由服务方授权维护，研究重点是约束是否能影响输出；A/B 关注不可信外部知识进入检索上下文后的完整性风险。二者可能使用表面相似的文本约束，但来源权限、目标和成功指标不同，应分开比较。
