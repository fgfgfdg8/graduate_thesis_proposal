## 2. 攻击对象、能力与不应混用的指标

- **对象。** p.3 §3 的攻击者面向目标问题和指定错误答案，将构造的毒文档注入外部知识语料，利用 retriever、可选 reranker 与生成器让系统回答预设错误。它是真正的 **RAG 知识库投毒**；这里的 prompt 是攻击者侧生成毒文本的方法组成，不等于直接篡改受害者系统提示词。该研究的实验单元是注入的文档/段落，未证明来自一篇既有真实长文档，也未研究目标未知分块器把同一长源切成两个互补实际块。
- **P2A 与 P3A 的权限。** p.3–5：P2A 为只用提示规则构造初稿的黑盒变体；文中用 GPT-4o 生成初稿（p.4），这不意味着拥有受害者 LLM 或检索器权重。P3A 在此基础上利用可访问的重排器及其参数进行字符级优化，是重排器白盒；原文威胁模型称检索器、生成器及良性语料仍未知。p.8 Table 7 是用一个**已知代理 reranker 的白盒能力**优化后迁移到另一目标 reranker，不能写成无需任何模型白盒的 P3A。论文未交代实际 API 费用、系统查询预算或真实部署入库成功率。
- **重排比较的重要前提。** p.3 §4 在送入 reranker 前把相同目标问题附加到**所有候选文档**进行归一；这是作者对已比攻击作实验的处理，不能泛称任意现成 reranker 本身都有同等防御能力。仅用干净域内数据微调 relevance reranker，也不等于训练了恶意块分类器。
- **三个指标。** p.5–6：Acc 和 ASR 均采用生成文本**第一句的子串匹配**；并非全文语义核验，且二者不应默认互为补集。文中 F1 是恶意文档在检索结果中所占比例和注入文档被召回比例的调和量，是**检索级 F1，不是恶意检测器 F1、良性保留率或问答 F1**。Table 2/8 的 F1 一列按 reranker 分组，与多列生成器 Acc/ASR 并排；不应当作每个生成器各自重新计算的检测分数。

## 4. 防御、误报和明确反例

1. **困惑度不是已验证的低误报检测器。** p.7 Figure 3 对照良性文档与 **P2A** 文档的 GPT-2 困惑度分布：NQ 平均值为 31.71 / 55.45，MS-MARCO 为 44.89 / 65.48；图示分布重叠，作者据此担忧单阈值检错权衡。图未给文档抽样分母、具体阈值、固定阈值的 FPR/TPR 或 ROC，不能导出“FPR 为多少”、对 P3A 有同样效果、或所有困惑度检测均无效。
2. **改写的是查询，不是对检索块逐一净化。** p.7 Table 5，在 NQ、MiniLM、Llama3-8B 下，P3A 的 ASR 从 **72.2% 降至 63.8%**，Acc 从 **10.4% 升至 14.2%**。该实验说明这一具体查询改写设置并未消除攻击；并无正常多跳证据保留率或最终误删率。
3. **高级防御有实际收益，不能只说失效。** p.8 Table 6 的 NQ 设置：P3A 的无防御 ASR **72.2%**，RobustRAG **69.2%**，TrustRAG **48.0%**；相应 Acc 为 **10.4%、15.6%、26.0%**。TrustRAG 相对无防御下降 **24.2 个百分点**，但剩余 ASR 仍非零。论文表称 100 个 query 的总响应时间分别为 **3.38、25.33、16.75 分钟**；这 100 是计时分母，表中未单列每个 ASR/Acc 的分母，不应直接把 100 当其分母，也不能推导 API 费用。模型部署、硬件及实现细节不足以把此计时当通用部署成本；未提供 clean-query 最终误删或正常多跳保留。
4. **无重排不是 P3A 每格最强。** p.7 Table 3，NQ / vanilla RAG / Llama3-8B：P3A **82.2%**，P2A **91.8%**，CorruptRAG-AS **85.8%**，CorruptRAG-AK **85.0%**。此处 P3A 曾在 MiniLM 上优化；不能将本文写成 P3A 无重排时总优于 P2A 或所有基线。p.14 Table 9 的 MS-MARCO / Llama3-8B 也有 P3A **74.6%** 低于 CorruptRAG-AK **88.4%**。
5. **作者对 Top-K 的一致性文字有表内反例。** p.16 B.7 说 P3A 一贯高于 P2A，但 Table 16 中 HotpotQA、K=6 时 P3A **54.0%** 低于 P2A **56.8%**；NQ、K=10 时 P3A **59.8%** 低于 P2A **62.8%**。该表固定 Np=5、Top-J=100、Contriever、MiniLM、Llama3-8B；不足以推出所有 K、所有配置的排序。
6. **迁移并非恒定无损。** p.8 Table 7，NQ / Llama3-8B：MiniLM 优化并在 MiniLM 测试 **72.2%**，换至 ELECTRA 测试 **64.4%**；ELECTRA 优化并在 ELECTRA 测试 **71.0%**，换至 MiniLM **61.8%**。但 HotpotQA 的 ELECTRA→MiniLM **70.6%** 也高于 ELECTRA→ELECTRA **68.0%**，因此不宜说所有迁移都下降。

## 5. 与开题 A/B 的逐项比较

| 项目 | 已证实重叠或冲突 | 与开题的边界、反例及建议 |
| --- | --- | --- |
| A：投毒并进入生成上下文 | 本文用目标问题/答案构造外部知识毒文档，检验检索—重排—生成的条件，Np=1 已有单篇预算结果（pp.3–8）。因此“单篇毒文档”“针对性目标答案”“检索后仍能影响生成”都不宜宽泛声称首创。 | 本文未证明**只能改一篇既有真实长源**、未知受害分块器的角色块完整性、同源块 ID 共召回、固定其他上下文的逐块与联合删除必要性。注入一篇文档和单源两块协同是不同预算与因果协议；前者不是后者的证据。 |
| A：切块和重排 | 本文的主要额外变量是候选文档经 reranker 的排序及检索器变化（pp.3、8、15–16）。 | 不能将既有综述中并列的 CRCP 分块机制自动归给 P3A：本文未报告未知受害 chunker 实验。开题目标系统本身不配置额外交叉编码重排器，应特别对照本文无重排 Table 3/9，不能直接套用主表。 |
| B：语义表征或相关性 | 良性训练 cross-encoder 在作者设置中可以抑制一些已有毒文档，而针对其相关性评分的 P3A 又能绕过部分抑制（pp.3、6–8）。这直接反驳“相关性高/语言连贯即可证明无毒”的宽结论。 | 本文没有训练开题的四统计 + 冻结查询—块语义表示 + 随机森林恶意分类器，也没有报告这套 B 方法的效果。开题虽使用重排序编码模型提取冻结表征，并不等于其主检索流程执行重排；该表征是否受 P3A 影响需对照实验。 |
| B：误报与正常多跳 | HotpotQA 是多跳基准，但本文结果主要评价**有攻击时**的 ASR/Acc；困惑度图只作分布展示。p.3 Table 1 的 benign NQ Acc 是问答准确率，不是文档或 query 误报率。 | 不把 PPL 图、HotpotQA 受攻击准确率或 retrieval F1 当 clean-query 最终误删率、桥接证据保留率。应独立统计干净查询统计分支告警、关系分支告警、最终误删，以及过滤后多跳必需证据和 QA 效用；统计分支阈值控制不自动控制关系触发或最终 LLM 决策。 |
| B：跨块和异源复核 | 文中检验的是重排、困惑度、查询改写及两种额外防御（pp.7–8）；未以来源 ID/偏移、跨块命题关系和异源参照证明恶意性。 | 来源不同不自动等于内容可信；正常同源远距块和桥接实体是误报反例。B 需另测无独立 anchor、冲突条件不兼容、Top-m 截断误丢桥接等情况。这里的实验建议是对开题的推论，不是论文已实现或已证明的结论。 |

**可执行的对照建议（本笔记推论，非论文结果）：** 按 Np=1 和 Np=5 分开复现 P2A/P3A，保留 no-rerank 与 rerank 两条管线，在相同 query、相同预算和相同最终上下文长度下报告首句指标及人工/语义补核；对 A 同时记录源 ID、实际块 ID、联合召回以及 full/A-only/B-only/neither，不能用单篇 ASR 替代四格必要性；对 B 在独立干净 query 上分别计算告警与最终误删，并用正常多跳必需证据保留率检验损失。公开制品尚不足以直接执行这一复现。
