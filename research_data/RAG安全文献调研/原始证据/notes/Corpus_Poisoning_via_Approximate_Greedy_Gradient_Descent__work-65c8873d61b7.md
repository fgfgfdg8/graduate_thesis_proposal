## 方法与威胁模型

主任务以训练查询集合估计查询分布，构造少量与查询集合相似的对抗段落，插入检索语料后观察其在未见查询上的检索命中；检索模型本身不因插入而重新训练（pp.3–4）。攻击需检索器梯度及插入语料的能力，不能概括成无需模型访问的纯黑盒攻击。另有针对已知目标问题的 PoisonedRAG 白盒生成扩展（pp.9、20），二者的目标和指标不可混同。

AGGD 对**每个词元位置**依据梯度分别选择候选，把各位置候选合并后按真实前向损失重新评价并贪心替换；若未改进，再向后搜索候选层级（pp.5–6）。它并非从所有位置的近似梯度中直接全局选出前 `n` 个候选。论文 Algorithm 1 将深度初始化为 `d=0`，候选区间却写为 `(d−1)k` 至 `dk`；正文按从第一层到第二层解释，索引约定或伪代码笔误尚待结合实现确认。

## 实验与反例

主实验默认对抗段落 30 词元、候选集 150、2,000 次替换迭代、Top-20；NQ 和 MS MARCO 用于训练及同域未见查询评测，另外五个数据集用于跨域测试，检索器为 Contriever、Contriever-MS、ANCE、DPR-mul、DPR-nq（pp.6–7）。主指标是**至少一条恶意段落进入 Top-k 的测试查询比例**，不是最终生成错误答案或目标答案的比例。Table 1 为四次随机运行的均值和标准差。

| 原文位置 | 报告结果 | 可支持的判断 |
|---|---|---|
| p.6 Table 1 | NQ 单段、Contriever 的检索 ASR 为 92.50±2.68%；同数据集 DPR-nq 为 2.19±0.98%。 | 攻击效果对检索器高度敏感；两格不是不同研究间可直接汇总的样本。 |
| p.6 Table 1 | MS MARCO／DPR-nq：AGGD 5.23±1.01%，HotFlip 5.81±2.01%。 | AGGD 并非在所有检索器和数据集格子上都更强；这些均值差异也不能自行推成统计显著。 |
| pp.14–15 Appendix B、Table 4 | 十条攻击段落通过对相似查询做 k-means 聚类、每簇生成一条；如 NQ／DPR-nq，AGGD 1.90±0.07%，HotFlip 2.19±0.25%。 | 这些段落对应多个查询簇，不能视作从一份真实长文经未知分块得到的互补同源块。 |
| p.9 Table 3；p.20 Appendix D | 对 100 个目标问题分别注入一条恶意文本，生成型 ASR 在 MS MARCO／Vicuna-13B 上为 AGGD 0.72、HotFlip 0.73；Vicuna-33B 为 0.67、0.69；NQ／LLaMA2-13B 为 0.94、0.95。 | 这是指定目标答案的生成攻击成功率，存在 HotFlip 略高的格子；不能说 AGGD 每格均更优。 |
| p.20 Table 9 | F1 以 Top-k 注入文本的 precision 与注入文本被检出的 recall 计算。 | 该 F1 是污染文本检索 F1，不是答案事实正确性的 F1。 |

**数据分母与原文冲突。** Table 8 列出 NQ 的 3,452 和 MS MARCO 的 6,980 个测试查询，这些是数据集统计，不能自动视作每个结果格的实际分母。p.7 称从语料抽取 10,000 段用于测试，但 Table 8 的 NFCorpus 全语料只有 3,633 段，文章未说明该情况下的处理；10,000 是段落数而非查询数。另 p.2 将 ANCE 在两个数据集的 AGGD 成功率写成 80.92% 和 65.68%，但 Table 1 对应 AGGD 为 80.92% 和 93.60%；65.68% 实际位于 NQ／HotFlip 格。保留这一文表冲突，以表格的具体行列为准引用，不擅自推测作者意图。

## 与开题的关系

**A：攻击方向。** 白盒梯度候选、真实损失重评、贪心词元替换，以及持久语料中的单段或按查询簇生成的多段投毒，均已有先例；这些宽泛机制不能单独作为新颖点。本文没有验证单一真实源文档经过未知受害者分块后生成两个同源角色块，也未证明同一查询下双块同时召回和逐块共同必要性；这一差异仍需通过可复现实验验证。

**B：防御方向。** 本文是检索阶段污染与测量基线，不提出检索后逐块过滤、来源治理或查询级误删校准。作者认为生成序列可能缺乏语义连贯而容易过滤（p.9），但这不是对特定防御器误删或漏检率的实测证明。建议分别记录检索命中、生成目标达成、干净查询效用与计算成本。
