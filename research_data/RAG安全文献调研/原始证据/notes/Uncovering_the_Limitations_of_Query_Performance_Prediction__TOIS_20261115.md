## 问题与方法

QPP预测某查询经检索系统处理后的相关性指标，实际使用时无须该查询的相关性标注；实验评价仍需相关性标注。文中预测NDCG、MAP、P@10、MRR@10等**检索相关性表现**，并非“证据为真/恶意”的后验概率，也不是删除必要证据的概率。NQC、UQC等使用检索结果或分数，是后检索特征；不能默认其门控成本为零，或把它们当成检索前即可获得的安全分数（pp.4–6、13）。

- 检索系统（pp.3–4）：BM25、DFree及各自的伪相关反馈查询扩展版本；SPLADE v2、ColBERTv2。论文把SPLADE称为dense hybrid，描述中使用稀疏词项扩展及语义表征，不能把它简单等同纯稠密双塔。
- 预测输入（pp.4–5）：NQC、UQC、WIG、QF；将四种LETOR词项匹配特征对检索结果汇总并按查询有效词数归一化；以及BERT双编码/交叉编码特征。多变量模型包括线性回归、随机森林和SVM。
- 数据（p.3 Table 1）：ROBUST 249、GOV2 149、WT10G 99、MS MARCO DL19/20 97个查询；各设置并非全部都有结果。Table 7的GOV2/SPLADE部分QPP相关性标为计算资源不足，表内另有未标原因的空格；均不可当作0。Table 10仍报告了GOV2/SPLADE的检索表现，不能把Table 7的缺值扩大为该检索器全部结果缺失。
- **两折划分（p.6，目视纠正此前文本提取歧义）**：原页下标分别为 `Q_A` 与 `Q_{\bar A}`，并非两个相同集合。作者称一折前者训练、后者测试，另一折反转，报告两测试折结果的平均值，并称训练方法使用相同查询划分。正文未给出可核实的查询ID划分、随机种子与完整调参过程；若表1的奇数个查询全部进入相应两折，就不可能严格等分，具体分配未核。该设计也不等于已验证跨数据集独立训练/测试迁移。

## 关键结果与具体边界

1. **特征与场景敏感（pp.7–10 Tables 3–9）**：Table 3中，ROBUST/BM25的L.BM25与NDCG Pearson r为0.459，而MS MARCO/BM25同项为0.149；同一特征换数据集表现变化。Table 5中ROBUST/BM25的L.BM25对NDCG、MAP、P@10、MRR@10分别为0.459、0.446、0.358、0.276，说明不同评价目标也会改变关联程度。部分表项显著、部分不显著，不能泛化为所有预测器必然失效。
2. **预测误差仍大（p.11 Tables 10–11）**：ROBUST/BM25平均NDCG为0.511；随机森林使用SOTA+LETOR特征时，MAE为0.167、RMSE为0.205、MedAE为0.144，表中R²为−1.504。MAE是跨查询平均绝对误差，不能将 `0.511 ± 0.167` 当作每条查询的误差界、标准差或置信区间。p.6对R²的文字定义与负表值存在问题，见下；这里仅转录作者报告值。
3. **约4%的对照口径未写清（p.12 Figure 4、p.13 Table 12）**：作者在图4讨论中称NDCG增幅约4%，未明确说明分母和对照。作为口径示例，Table 12的BM25+QE 0.5322相对BM25 0.5106约高4.23%，这是两个单系统的差距，**不能据此称门控比最强基线提升4%**。Table 12中UQC训练选择器为0.5325，相对较强基线0.5322绝对高0.0003、相对约0.056%，逐查询oracle为0.5393；表中三角标记仅表示数值高于两个单系统，并未标明这一差异显著。
4. **另一个训练选择器及直接比较（p.13 Table 12）**：BM25/SPLADE各为0.5106/0.4517，全特征SVM选择器0.5121，比BM25绝对高0.0015、相对约0.294%；作者称这一提升不显著。相应oracle为0.5476，不是系统实现结果。另一种直接比较两套预测值的尝试在其实验中始终选择同一配置；作者尝试其他归一化后问题仍存在，原因只提出推测。
