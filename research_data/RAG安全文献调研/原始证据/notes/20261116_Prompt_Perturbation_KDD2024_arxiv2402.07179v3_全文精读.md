## 攻击对象、访问条件与指标

1. **可控对象是输入查询/提示的前缀。** 论文讨论把受控扰动加到用户问题，使检索查询表示偏移，从原有可信语料里召回攻击者选定、对当前问题不正确的段落（pp.2–5）。其示例中的目标段落可以是关于另一个实体的正常事实；“对该查询错误”不等于该段落本身被伪造，也不等于攻击者修改、植入或控制了知识库文档。没有把多块同源文档投毒作为该文的实验设定。
2. **访问边界不可省略。** 作者说不必知道完整资料库，但明确需要目标段落与原始段落；GGPP 对用于嵌入的模型执行梯度优化（pp.3–5）。这是论文所用的模型内部/梯度访问设置；文中所述不足以把它改写为只靠受害者黑盒 API、零模型访问或已证明跨模型迁移的攻击。算法目标同时包括提升目标段落排名与排除原始正确段落；Table 2 对 top-1/top-10 的文字定义侧重目标段落出现的位置，不能擅自把表值改记为端到端定向错误答案 ASR 或额外补出联合事件计数。
3. **数据筛选会改变分母。** pp.6–7 的 Table 1：IMDB、Basketball Players、Books、Nobel Winners 各取前 1,000 条记录生成模板化问题与段落，构成四个检索库；GPT-J-6B、Mistral-7B、Qwen-7B 和 SFR-Embedding-Mistral 用于嵌入。作者先排除对原始查询未在 top-k 找到正确段落的情况，再评估 GGPP。例：IMDB/GPT-J-6B 的原始 top-10 命中率是 51.5%。Table 2 的百分比应理解在论文筛选后的实验条件下，**不能自行填入筛后查询总数**或把 1,000 直接当作所有模型的有效分母。
4. **结果口径示例。** p.8 Table 2，Mistral-7B/IMDB 的目标段落 top-1、top-10 为 30.6%、41.6%；GPT-J-6B/IMDB 为 68.4%、88.6%。这些是目标段落检索排名指标，不是生成答案成功率。Table 3 中同为 Mistral-7B/IMDB，GGPP top-10 41.6%，适配的 GCG 7.0%、UAT 3.2%，只支持该具体基线与设置的比较。Figure 7 初始化曲线只展示 Mistral-7B/Nobel 的单个查询，不能推出普遍的总搜索费用或所有查询的平均耗时。

## 防御、样本、上下文权限与误报

- **两个监督探针（pp.2、5–7）。** SATe 借鉴 SAT，读取模型多层注意力信息；ACT 用最后一层隐藏状态训练逻辑回归，识别带/不带 GGPP 扰动的查询。两者需要相应模型内部状态，不能假设仅凭文本 API 或只返回最终答案的检索服务就可部署。作者把 ACT 的表征动机与 MLP 激活联系起来，实际检测特征描述是末层隐藏状态；不要写成“只读取单个 MLP 神经元”或无监督规则。
- **论文报告的数据构造（pp.8–9）。** 每个数据集从前述实验随机选择 100 个查询及其 GGPP 前缀，同时为对应查询构造等长对照前缀：前者标 1、后者标 0，总计 200 条。正文说对照前缀从原段落关键 token 随机抽取，并称不影响原段落检索；按条目 60% 训练、40% 测试，10 次独立运行报告均值。文中没有明确说明成对查询是否按 query 身份分组到同一集合，也没有给出独立新来源、新攻击族或真实自然良性请求上的误报结果；不能据此断言实际一定发生泄漏，亦不能声称已证明 query-disjoint 泛化。
- **检测反例和参数口径（p.9 Table 4）。** Basketball/GPT-J-6B，ACT 的 AUROC/F1 为 87.9%/80.1%，SATe 为 98.6%/93.9%；ACT 并非所有配置都与 SATe 接近。表中对该模型列出的探针参数数目分别为 430,080 和 4,939,200；这些是论文所列探针规模，不是整个编码模型的参数、显存或总部署成本。另一配置 Mistral-7B/IMDB 的 ACT AUROC/F1 为 99.6%/96.9%，只适用于该对照数据和评测设置。
- **误报不能反推。** Table 4 报 AUROC、precision、recall、F1；未给独立干净查询的 query-level FPR、低误报阈值、混淆矩阵或查询级最终误删率。配对样本、10 次均值和阈值细节使其不能被当作指定低 FPR 下的检测率。没有依据补写混淆矩阵、事件数或分母；平衡的人工对照也不代表自然请求的部署先验。
- **效率范围（pp.9–10 Table 6）。** 作者在 Intel Xeon Gold 6242 CPU 上将两类探针训练和响应计时各运行 10 次并取均值。例如 Mistral-7B 项为 ACT 训练 4,438.3 ms、响应 2.4 ms，SATe 训练 182,004.1 ms、响应 58.5 ms。表中数值不能视为加载模型、抽取隐藏状态、完整检索、过滤和生成全部包含的端到端单查询延迟；无 GPU 时数、美元费用或显存统计可据此补写。
- **指令/权限范围（pp.5、12）。** 附录 A.5 的 Celebrity 是 300 条、直接操纵 LLM 事实输出的**非检索**实验；Table 8 的 GPT-J-6B 生成侧 ACT AUROC 94.5%、F1 92.4% 属于此设置，不是 RAG 检索侧投毒检出率。A.6 用一条让模型忽略无关信息的普通提示比较包含/不包含该指令的优化设置；Figure 17 的相关数据属于该事实输出实验。它未测试 system/developer/user/document 角色权限分离，也不能外推为所有指令防护必然失效。

## 与当前开题 A/B 的创新比较与反例

比较依据：[当前研究内容及方法](../../../../partitions/section3_content.tex) 的研究点一、二；以下是本次分析判断，不是论文已完成的对比实验。

- **A：攻击目标有近邻，主要机制与权限不同。** 共同点是利用检索表示空间改变目标材料进入上下文并诱发定向错误，因而不能笼统声称“检索空间定向操纵/让错误信息被召回”从未有人研究。区别是本篇操纵查询前缀、使用原始及目标段落和嵌入模型梯度；开题 A 修改单一源文档、经过目标摄入/未知分块后追求两个同源互补块联合召回，并以影子系统优化、黑盒访问目标。该文未构造或验证 A 的同源两块联合必要性、未知分块完整性和黑盒迁移，因此不是 A 已被证明完全撞车；也不能仅凭该文证明 A 整体新颖。A 应以逐块移除、联合召回及未见分块配置等实验支持其独特主张。
- **B：轻量激活特征＋监督分类有直接先例。** 该文 ACT 已在 2024 年使用末层隐藏状态及逻辑回归，对扰动查询分类；当前 B 使用冻结的基于 ModernBERT 的查询—块联合隐藏表示、统计特征、PCA 和随机森林，并增加跨块关系及异源参照。两者监督表示检测思路存在重叠，不能把“冻结模型提取隐藏表示＋轻量分类器”或一般“表示偏移可检测”单列为无人研究的创新。差别在检测单位、访问位置、证据结构及威胁对象；是否带来增益仍需同条件消融和基线比较。
- **对 B 的具体反例。** 仅有干净但与当前问题无关的其他实体段落被召回时，段落本身未必带有投毒痕迹；若正确证据已被排除在固定 Top-k 之外，单纯删除可疑候选不能从该候选集合中恢复缺失证据。这是由本篇攻击情形和固定候选假设得到的分析反例，不是已对 B 实测的失效结论。B 的异源参照也不能自动保证包含正确证据；应测试无参照/错误参照及正常多跳保留。
- **建议的公平边界。** 若日后比较，在相同可获取模型状态、同一干净查询/源文档隔离和相同查询级误报预算下，分别报已知/未见攻击、检出率、正常问答效用与包含特征抽取的端到端延迟；同时区分统计分支告警、跨块分支告警和最终误删。对 GGPP 查询扰动可作为跨威胁压力测试，不能把它混计为知识库文档投毒基准。
