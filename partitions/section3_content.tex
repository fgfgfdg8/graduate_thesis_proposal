\section{研究内容及方法}

\subsection{研究目标}

本研究面向RAG系统中“文档级摄入”与“块级检索”之间的粒度差，研究外部源文档经受害者侧分块后形成的跨块组合投毒风险及其防御方法。在攻击侧，现有单文档投毒方法要求单个文本承载完整攻击逻辑\cite{chang2025oneshot,zhang2026corruptrag}，多文档分布式投毒则假设攻击者向语料库注入多个独立文本\cite{zhang2026inceptionrag}。本研究考虑攻击者仅控制单个源文档的条件，使分块产生的两个同源文本块分别承载互补前提：任一单块均缺乏导出目标答案所需的完整依据，目标是在两块共同被检索时诱导模型输出指定答案。研究点一采用先构造组合载荷、再优化检索相关性的两步方法。

在防御侧，现有方法主要依赖单块统计异常\cite{kim2025gmtp}、集合聚类\cite{zhou2025trustrag,kim2025ragdefender}或多轮分组生成\cite{xiang2024certifiably}，在跨块组合投毒与正常多跳证据并存时面临检测与保留的权衡。研究点二结合单块检索统计特征与上下文跨块关系筛选待审文本，再对筛选出的待审集调用一次LLM与参照文本比较，移除判为投毒的文本块。两个研究点在统一的数据、索引与生成设置下开展评估，并集成为RAG投毒攻防联合测试系统，整体研究思路如\autoref{fig:framework}所示。

\subsection{研究点一：同源跨块投毒方法}

\subsubsection{威胁模型与问题形式化}

\textbf{威胁模型。}
\begin{enumerate}
  \item \textbf{目标RAG系统模型}：目标系统由外部知识库、文档分块器$\phi_v$、检索器$R_v$与生成模型$G_\omega$构成，其中$\omega$表示生成解码随机性。端到端生成过程表示为$\hat y=G_\omega(q,R_K(q;\phi_v(\mathcal D)))$，其中外部语料库$\mathcal D$经分块器切分为文本块集合$\phi_v(\mathcal D)$，检索器按相关性得分$s_v(q,\cdot)$降序返回前$K$个文本块$R_K(q)=\operatorname{TopK}(q;\phi_v(\mathcal D))$构成上下文，交由生成模型输出回答。攻击者仅能篡改单一可被系统重新摄入的外部源文档$d\in\mathcal D$，更新后语料库为$\mathcal D_{\mathrm{adv}}(x)=(\mathcal D\setminus\{d\})\cup\{D_{\mathrm{adv}}(x)\}$，参与检索的分块语料库记为$\mathcal C_v^{\phi_v}(x)=\phi_v(\mathcal D_{\mathrm{adv}}(x))$。以替换更新为基本设置，追加新文档作为辅助设置单独评价。
  \item \textbf{攻击者目标}：攻击者旨在通过篡改开放域语料库中的单一源文档，使目标RAG系统在经过摄入、分块与检索后，在处理目标查询时输出预设的错误目标答案$a^*$，且$a^*$与原始正确答案$y_{\mathrm{true}}$语义互斥。
  \item \textbf{攻击者能力与知识}：攻击者掌握目标查询$q$及其正确答案$y_{\mathrm{true}}$，仅能通过黑盒接口访问受害者系统，无法读取其内部检索得分$s_v$、模型梯度、分块边界或召回顺序。与前序工作\cite{nie2026crcp,chaudhari2026phantom}一致，攻击者可在本地搭建由影子分块器集合$\Phi_{\mathrm{shadow}}$、代理检索编码器$E_s$及其影子检索得分$s_s$和影子生成模型$G_{\mathrm{shadow}}$构成的影子系统，用于离线构造与筛选攻击载荷；受害者侧的实际检索排名与生成结果仅用于实验评估。本研究以$|\mathcal D_{\mathrm{adv}}|=1$的单一受控源文档作为攻击预算单位\cite{chang2025oneshot,zhang2026corruptrag}。
  \item \textbf{防御者目标}：防御者旨在在不显著降低干净查询准确率的前提下，识别并移除潜在投毒文本块，保障RAG系统对问题的准确回答率（特别是正常多跳问答推理的正确率），同时将在线防御延迟控制在给定预算内。
  \item \textbf{防御者能力与知识}：防御者部署于服务端检索阶段之后、生成阶段之前，可读取候选文本块的检索向量、词项表示及系统摄入时记录的文档来源标识$z_{\mathrm{doc}}(c)$与文本块在源文档中的起止词元偏移，在固定检索器与生成模型参数的前提下过滤检索上下文。
\end{enumerate}

\textbf{问题形式化。}遵循文献\cite{zou2025poisonedrag}的框架，定向RAG投毒需同时满足检索条件与生成条件：检索要求同一源文档切分出的两个完整角色块分别落入不同分块并共同进入Top-$K$；生成要求联合上下文命中目标答案，单块对照均不命中。设除载体文档$d$外的背景分块索引库为$\mathcal C_{-d}^\phi=\phi(\mathcal D\setminus\{d\})$，$D_{\mathrm{adv}}(x)$为候选状态$x$下的完整投毒源文档，在分块算子$\phi$下更新后的分块语料库为$\mathcal C_v^\phi(x)=\mathcal C_{-d}^\phi\cup\phi(D_{\mathrm{adv}}(x))$。对角色$j\in\{A,B\}$与文档分块策略$\phi$，当$\phi(D_{\mathrm{adv}}(x))$中存在完整包含核心载荷$\mathcal P_j$的分块窗口时，记角色完整性指示器$I_j(\phi)=1$并记对应主块为$c_j^{(\phi)}$；若多个窗口完整包含同一核心，主块取对应检索排序中最高者，并沿用该系统的并列分排序规则；否则记$I_j(\phi)=0$。定义单视图$\phi$下两核心分别完整落入不同块且共同进入Top-$K$的\textbf{联合召回事件}$Z_\phi(x)$为：
\begin{equation}
  Z_\phi(x)=\mathbb I\Big[I_A(\phi)=1\;\land\;I_B(\phi)=1\;\land\;c_A^{(\phi)}\neq c_B^{(\phi)}\;\land\;\big\{c_A^{(\phi)},c_B^{(\phi)}\big\}\subseteq R_K\big(q;\mathcal C_v^\phi(x)\big)\Big],
  \label{eq:attack_corpus}
\end{equation}
其中$R_K(q;\mathcal C_v^\phi(x))=\operatorname{TopK}(q;\mathcal C_v^\phi(x))$为Top-$K$检索集合；当任一角色核心被切分截断（$I_A(\phi)=0$或$I_B(\phi)=0$）时，$Z_\phi(x)=0$。

设语义答案判定器为$J(q,y_{\mathrm{ref}},\hat y)\in\{0,1\}$，在受害者分块配置分布$\Pi_v$与解码随机性$\omega$下，端到端目标答案$a^*$生成概率$F(x)$定义为：
\begin{equation}
  F(x)=\Pr_{\phi_v\sim\Pi_v,\,\omega}\Big[J\big(q,a^*,G_\omega(q,R_K(q;\mathcal C_v^{\phi_v}(x)))\big)=1\Big].
  \label{eq:attack_generation}
\end{equation}
攻击者的理论优化问题可形式化为：
\begin{equation}
  \max_{x\in\mathcal X}\ F(x),
  \label{eq:attack_ideal}
\end{equation}
其中$\mathcal X$限定对单一源文档$d$的编辑且满足跨块布局结构约束。由于受害者侧的分块边界$\phi_v$与内部检索得分对黑盒攻击者不可见，攻击者在本地借助影子系统离线求解。

本研究令两个同源文本块$c_A$和$c_B$分别承担互补推理角色：$c_A$承载抽象规则定义，$c_B$承载查询实体的实例归属绑定\cite{zhang2026inceptionrag}。为比较单块与双块的目标生成效果，从除载体文档外的影子背景库$\mathcal C_{-d}^s$中取前$K-2$个高分干净块固定为有序序列$B_0=[d_{(1)},\dots,d_{(K-2)}]$，并设置与角色块长度及主题匹配的干净中性替代块$N_A,N_B$，按固定槽位构造四组均包含$K$个文本块的对比上下文：
\begin{equation}
  C_{00}=[B_0,N_A,N_B],\qquad
  C_{10}=[B_0,c_A,N_B],\qquad
  C_{01}=[B_0,N_A,c_B],\qquad
  C_{11}=[B_0,c_A,c_B].
  \label{eq:attack_composition}
\end{equation}
对$u,v\in\{0,1\}$，记上下文$C_{uv}$触发目标答案的语义判定结果为$Y_{uv}=J(q,a^*,G_{\mathrm{shadow}}(q,C_{uv}))\in\{0,1\}$，确定性解码下要求单块不命中、双块命中攻击者目标答案$a^*$的\textbf{组合生成判据}为：
\begin{equation}
  \mathcal V_{\mathrm{comp}}(x)=\mathbb I\big[Y_{11}=1\;\land\;Y_{10}=0\;\land\;Y_{01}=0\;\land\;Y_{00}=0\big].
  \label{eq:gen_gate}
\end{equation}
在全文重切分后的端到端评估中，同时统计自然Top-$K$上下文$R_K(q;\mathcal C_v^{\phi_v}(x))$的目标答案$a^*$命中率及单块消融表现。在实际求解中，由于源文档编辑是离散的、Top-$K$检索选择不连续且受害者系统为黑盒，直接优化式\eqref{eq:attack_ideal}的端到端概率面向无梯度的组合搜索难题。本研究因此采用两步策略：首先利用影子生成模型在固定背景下检验并筛选满足$\mathcal V_{\mathrm{comp}}(x)=1$的双块核心载荷与背景句；随后在影子分块视图分布$\Pi_\Phi$上以连续可微的检索损失优化外围触发器，其代理优化目标为：
\begin{equation}
  \max_{x\in\mathcal X}\ \mathbb E_{\phi\sim\Pi_\Phi}\big[Z_\phi(x)\big]-\lambda_{\mathrm{ppl}}\mathcal L_{\mathrm{ppl}}(x),\qquad
  \text{s.t.}\quad \mathcal V_{\mathrm{comp}}(x)=1,\;\mathcal M_{\mathrm{lex}}(x)=1.
  \label{eq:attack_objective}
\end{equation}
直接在逻辑正文上执行词元替换容易破坏跨块推理链\cite{liu2024autodan}，因此阶段一固定核心载荷与背景句，阶段二仅优化背景句自然句边界处的外围检索触发器，并在组装完整文档后经真实重切分检验$Z_\phi(x)$与$\mathcal V_{\mathrm{comp}}(x)$，整体流程如\autoref{fig:attack_framework}所示。

\subsubsection{阶段一：双块载荷构造}

\textbf{1) 规则块、实例块与背景句设计。}每个植入段落$P_j$依次拼接前置背景句$\mathcal S_j^{\mathrm{pre}}$、核心载荷$\mathcal P_j$和后置背景句$\mathcal S_j^{\mathrm{post}}$：
\begin{equation}
  P_j=\mathcal S_j^{\mathrm{pre}}\oplus\mathcal P_j\oplus\mathcal S_j^{\mathrm{post}},\qquad j\in\{A,B\},
  \label{eq:payload_layout}
\end{equation}
其中$\oplus$表示文本拼接。两类核心载荷分别承担规则映射与实体绑定的分工：
\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item \textbf{核心载荷$\mathcal P_A$（规则块）}：定义符合源文档领域语境的分类标准或属性映射规则，声明早期记录隐含的原答案$y_{\mathrm{true}}$已按分类代号重新核定，用于改变模型对原答案的采信，同时文本限定在规则层面，与查询实体解耦。
  \item \textbf{核心载荷$\mathcal P_B$（实例块）}：陈述查询主体在档案记录中对应的分类代号，建立查询实体与分类代号的绑定关系，使生成模型必须在同时读取$\mathcal P_A$与$\mathcal P_B$时结合规则与实例导出目标答案$a^*$。
  \item \textbf{背景句$\mathcal S_j^{\mathrm{pre}},\mathcal S_j^{\mathrm{post}}$}：由$2\sim 3$句与插入段落前后文主题衔接的句子构成，置于核心载荷两侧以降低窗口边界直接截断核心载荷的概率，并在自然句边界处提供阶段二检索触发器的插入位置。
\end{itemize}

\textbf{2) 载荷插入位置预选与分块验证。}为保证组装后两个载荷角色落入不同分块且核心内容完整，将干净源文档$D$按自然段解析为$\{p_1,\dots,p_M\}$，记第$k$段末尾的累积词元偏移为$t_k$，全文总长为$t_M$；影子分块配置集$\Phi_{\mathrm{shadow}}$的最大窗口容量为$K_{\max}=\max_{\phi\in\Phi_{\mathrm{shadow}}}K_{\mathrm{size}}(\phi)$。给定间距系数$\gamma\ge 1.0$与单段前置背景句及核心长度预估上界$L_{\mathrm{est}}\ge 0$，以式\eqref{eq:slot_anchor}作为候选插入段落的启发式预选准则：
\begin{equation}
\begin{aligned}
  (k_A,k_B)&=\arg\min_{(i,j)\in\mathcal F_{\mathrm{slot}}}\Big(\big|t_i-\rho_A\,t_M\big|+\big|t_j-\rho_B\,t_M\big|\Big),\\
  \mathcal F_{\mathrm{slot}}&=\Big\{(i,j):1\le i<j\le M,\;t_j-t_i\ge\gamma K_{\max}+L_{\mathrm{est}},\;\operatorname{start}_{D_{\mathrm{adv}}}(\mathcal P_B)-\operatorname{end}_{D_{\mathrm{adv}}}(\mathcal P_A)\ge\gamma K_{\max}\Big\},
\end{aligned}
  \label{eq:slot_anchor}
\end{equation}
其中$\rho_A=0.33,\rho_B=0.66$为目标相对分位点。式\eqref{eq:slot_anchor}用于预筛满足物理间距的可行插入点，防止单分块窗口同时覆盖两段载荷。在选定插入位置后，将生成段落组装为临时载体文档$D_{\mathrm{adv}}$，并经影子分块器实际切分验证，确保在影子视图下两个角色均保持完整且分离（$I_A(\phi)=1\land I_B(\phi)=1\land c_A^{(\phi)}\neq c_B^{(\phi)}$）。

\textbf{3) 反馈驱动的“提出—检验—修订”循环。}系统采用反馈驱动的循环生成两块核心载荷。初始时由查询$q$、参考答案$y_{\mathrm{true}}$、目标答案$a^*$及源文档语境提出初始载荷与背景句$(\mathcal P_A,\mathcal P_B,\mathcal S_A,\mathcal S_B)$。组装进源文档并由影子分块器真实切分后，提取实际角色块构造四组对比上下文$C_{00},C_{10},C_{01},C_{11}$，依式\eqref{eq:gen_gate}检验$\mathcal V_{\mathrm{comp}}(x)$。当检验未通过时，按失败原因针对性修订：
\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item 若$Y_{10}=1$或$Y_{01}=1$（单块命中），表明单块泄露了独立推导目标答案的信息，则修订删除对应块中的泄露信息；
  \item 若$Y_{11}=0$（双块不命中），表明规则与实例未能协同生效，则澄清$\mathcal P_A$中的规则表述及$\mathcal P_A,\mathcal P_B$之间的代号对应关系；
  \item 若影子分块出现核心截断（$I_j(\phi)=0$），则调整段落插入位置$(k_A,k_B)$或微调背景句长度。
\end{itemize}
该循环至多执行$T_{\mathrm{gen}}$轮；仅当候选状态在实际重切分后通过全部对照检验（$\mathcal V_{\mathrm{comp}}(x)=1$）时才固定载荷与位置并输出至阶段二；若达到$T_{\mathrm{gen}}$轮仍未通过，或最后一次修订未经检验，则不输出未验证状态。

\subsubsection{阶段二：分块感知的检索触发器优化}

\textbf{1) 双侧触发器布局。}在保持核心载荷不变的前提下，于核心载荷前后背景句的自然句边界处各放置一个长度为$L_{\mathrm{trig}}$的触发器词元序列$\mathbf t_j=(t_{j,1},\dots,t_{j,L_{\mathrm{trig}}})$，共$R$个副本（文中设$R=2$）：
\begin{equation}
  P_j(\mathbf t_j)=s_{j,1}^{\mathrm{pre}}\oplus\mathbf t_j^{(1)}\oplus s_{j,2}^{\mathrm{pre}}\oplus\mathcal P_j\oplus s_{j,1}^{\mathrm{post}}\oplus\mathbf t_j^{(2)}\oplus s_{j,2}^{\mathrm{post}}.
  \label{eq:trigger_layout}
\end{equation}
由于前后两个触发器副本被中间的核心载荷$\mathcal P_j$隔开，当三者与中间背景句的总包络跨度不超过分块容量$K_{\mathrm{size}}$时，任何完整包含核心载荷$\mathcal P_j$的分块窗口必至少完整包含其中一个触发器副本。设影子分块视图集合为$\Phi_{\mathrm{shadow}}$，令$\Phi^+=\{\phi\in\Phi_{\mathrm{shadow}}:I_A(\phi)=1\land I_B(\phi)=1\land c_A^{(\phi)}\neq c_B^{(\phi)}\}$为两核心载荷均完整落入不同分块的影子视图集合。当$\Phi^+=\emptyset$时中止该候选的触发器优化；当$\Phi^+\neq\emptyset$时，包络条件确保对任意$\phi\in\Phi^+$，完整核心所在的主块必保留至少一个完整触发器副本。

\textbf{2) 跨视图检索损失与梯度累积。}以干净背景第$K-1$名得分$\tau_q=s(q,d_{(K-1)})$作为检索优化的参考阈值。在$\Phi^+$中任取参考视图$\phi_0\in\Phi^+$，角色$j$在视图集合$\Phi^+$上的跨视图检索损失定义为：
\begin{equation}
\begin{aligned}
  \mathcal L_{\mathrm{rob}}(\mathbf t_j)&=
  \frac{1}{|\Phi^+|}\sum_{\phi\in\Phi^+}\Big[
  \ell_{\mathrm{ret}}\big(c_j^{(\phi)}(\mathbf t_j)\big)
  +\lambda_{\mathrm{var}}\big|s\big(q,c_j^{(\phi_0)}(\mathbf t_j)\big)-s\big(q,c_j^{(\phi)}(\mathbf t_j)\big)\big|\Big],\\
  \ell_{\mathrm{ret}}(c)&=\operatorname{softplus}\!\left(\frac{\tau_q+\delta-s(q,c)}{T}\right),
\end{aligned}
  \label{eq:chunk_rob_loss}
\end{equation}
其中$\delta>0$为得分裕度，$T>0$为平滑温度，$\lambda_{\mathrm{var}}\ge 0$为跨视图得分波动权重。$\ell_{\mathrm{ret}}$惩罚相对参考阈值的得分不足，跨视图项抑制不同分块配置下的得分差异。
触发器$\mathbf t_j$在主块中包含$R$个副本，且同时存在于多个有效视图$\phi\in\Phi^+$中。反向传播时，损失函数通过影子稠密编码器$E_s$计算触发器各位置词元嵌入的梯度，并将各副本与各视图的梯度贡献累加：
\begin{equation}
  \mathbf g_i=\nabla_{e_{t_i}}\mathcal L_{\mathrm{rob}}(\mathbf t_j)=\frac{1}{|\Phi^+|}\sum_{\phi\in\Phi^+}\sum_{r=1}^R \nabla_{e_{t_{j,i}^{(r)}}}\mathcal L_{\mathrm{rob}}\big(c_j^{(\phi)}(\mathbf t_j)\big).
  \label{eq:grad_accum}
\end{equation}
反向传播经过完整的Transformer编码器以获取准确的一阶梯度方向。参考阈值$\tau_q$仅作为引导触发器优化的软性基准；在实际检索中，更新源文档的其他分块与背景语料共同竞争Top-$K$，优化达标不替代最终的联合召回检验。

\textbf{3) 检索与流畅度联合目标及词法约束。}为约束触发器的语言可读性，截取每个触发器副本及其前后相邻句构成的局部文本窗口$W_j^{(r)}=s_{j,1}^{(r)}\oplus\mathbf t_j^{(r)}\oplus s_{j,2}^{(r)}$，利用冻结的本地因果语言模型计算局部负对数似然（NLL）作为流畅度损失：
\begin{equation}
  \mathcal L_{\mathrm{ppl}}(\mathbf t_j)=-\frac{1}{R}\sum_{r=1}^R \frac{1}{|W_j^{(r)}|}\sum_{m=1}^{|W_j^{(r)}|} \log P_{\mathrm{LM}}\big(w_m^{(r)}\mid w_{<m}^{(r)}\big),
  \label{eq:local_ppl}
\end{equation}
即先对局部窗口内的词元取平均，再对各副本取平均。候选更新按综合评分函数进行比较：
\begin{equation}
  \mathcal L=\sum_{j\in\{A,B\}}\big[\mathcal L_{\mathrm{rob}}(\mathbf t_j)+\lambda_{\mathrm{ppl}}\mathcal L_{\mathrm{ppl}}(\mathbf t_j)\big],
  \label{eq:total_attack_loss}
\end{equation}
其中$\lambda_{\mathrm{ppl}}\ge 0$为平衡超参数。梯度用于快速筛选检索端有利的候选词元，冻结语言模型则执行前向计算提供NLL评分。

为避免无意义搜索并保证隐蔽性，触发器词元从受限候选池中选取。利用Doc2Query\cite{nogueira2019document}根据载荷段落生成候选伪查询文本，经影子编码器$E_s$的分词器转换为候选词元集合$\mathcal V_{\mathrm{cand}}\leftarrow\operatorname{Tokens}_{E_s}(\operatorname{Doc2Query}(P_A,P_B))$，以保证词元编号与检索编码器一致并缩小搜索范围。同时采用词法检查器$\mathcal M_{\mathrm{lex}}(\mathbf t;q,a^*,y_{\mathrm{true}})\in\{0,1\}$对触发器施加硬约束：
\begin{enumerate}[label=(\alph*),leftmargin=2.2em,itemsep=0pt]
  \item 每个词元均为完整ASCII英文词元，且相邻位置词元满足$t_i\neq t_{i+1}$；
  \item 序列$\mathbf t$与查询$q$的最长公共连续词组长度小于2；
  \item 序列不含属于$a^*$或$y_{\mathrm{true}}$的词元，避免触发器直接泄露答案。
\end{enumerate}

\textbf{4) 交替优化与真实重切分检验。}求解步骤如算法\ref{alg:attack}所示。在每轮优化中，选择当前检索损失较大的角色$j^\star=\arg\max_{j\in\{A,B\}}\mathcal L_{\mathrm{rob}}(\mathbf t_j)$执行坐标更新。对每个位置$i$，在满足词法约束且$v\in\mathcal V_{\mathrm{cand}}$的候选词元上，按一阶线性近似排序筛选前$B_{\mathrm{cand}}$个替换候选：
\begin{equation}
  \Delta_{i,v}=-\mathbf g_i^\top(e_v-e_{t_i}).
  \label{eq:first_order}
\end{equation}
将候选词元写回段落并组装为完整载体文档$D_{\mathrm{adv}}$，在固定视图集$\Phi^+$上实际切分并定位真实角色块，批量前向计算总损失式\eqref{eq:total_attack_loss}，贪婪采纳使总损失严格下降的最优替换$(i^\star, v^\star)$。若达到最大步数$T_{\mathrm{ret}}$或无合法替换能严格降低总损失，则中止优化。

优化结束后，将最终触发器组装为源文档$D_{\mathrm{adv}}(x)$，在参考视图$\phi_0$上执行真实分块与检索，检验是否同时满足联合召回$Z_{\phi_0}(x)=1$与组合生成验证$\mathcal V_{\mathrm{comp}}(x)=1$；同时可在多视图上分别统计跨分块成功率。

\begin{algorithm}[htbp]
  \small
  \caption{Cross-Chunk Payload Construction}
  \label{alg:attack}
  \KwIn{query $q$, answers $y_{\mathrm{true}},a^*$, carrier document $D$, clean Top-$K$ chunks $\{d_{(1)},\dots,d_{(K)}\}$ with $\tau_q=s(q,d_{(K-1)})$, shadow chunkers $\Phi_{\mathrm{shadow}}$, shadow generator $G_{\mathrm{shadow}}$, shadow encoder $E_s$}
  \KwOut{poisoned source document $D_{\mathrm{adv}}(x)$ or $\varnothing$}
  \tcp{Stage 1: Construct paired payloads}
  $(\mathcal P_A,\mathcal P_B,\mathcal S_A,\mathcal S_B)\leftarrow\operatorname{PROPOSE}(q,y_{\mathrm{true}},a^*,D;G_{\mathrm{shadow}})$\;
  \For{$r\leftarrow1$ \KwTo $T_{\mathrm{gen}}$}{
    \lIf{$\mathcal F_{\mathrm{slot}}=\emptyset$}{\Return{$\varnothing$}}
    Select $(k_A,k_B)\in\mathcal F_{\mathrm{slot}}$ on $D$ satisfying Eq.~\eqref{eq:slot_anchor}\;
    $D_{\mathrm{cand}}\leftarrow\operatorname{ASSEMBLE}(D, k_A, P_A, k_B, P_B)$;\quad Extract chunks $\{c_A,c_B\}$ by chunking $D_{\mathrm{cand}}$\;

    \lIf{$\mathcal V_{\mathrm{comp}}(x)=1$ \textnormal{in Eq.~\eqref{eq:gen_gate}}}{\textbf{break}}

  }
  \lIf{$\mathcal V_{\mathrm{comp}}(x)=0$}{\Return{$\varnothing$}}
  \tcp{Stage 2: Optimize retrieval triggers}
  $\mathcal V_{\mathrm{cand}}\leftarrow\operatorname{Tokens}_{E_s}(\operatorname{Doc2Query}(P_A,P_B))$; \tcp{Tokens from doc-generated queries}

  \lIf{$\Phi^+=\emptyset$}{\Return{$\varnothing$}}
  \For{$t\leftarrow1$ \KwTo $T_{\mathrm{ret}}$}{
    $j^\star\leftarrow\arg\max_{j\in\{A,B\}}\mathcal L_{\mathrm{rob}}(\mathbf t_j)$;\quad Compute $\mathbf g_i=\nabla_{e_{t_i}}\mathcal L_{\mathrm{rob}}(\mathbf t_{j^\star})$ via Eq.~\eqref{eq:grad_accum}\;
    $\mathcal B\leftarrow\operatorname{TOP}_{B_{\mathrm{cand}}}\big\{(i,v):v\in\mathcal V_{\mathrm{cand}},\ \Delta_{i,v}=-\mathbf g_i^\top(e_v-e_{t_i}),\ \mathcal M_{\mathrm{lex}}(\mathbf t_{j^\star}[i\to v];q,a^*,y_{\mathrm{true}})=1\big\}$\;

  \lIf{$Z_{\phi_0}(x)=1\land\mathcal V_{\mathrm{comp}}(x)=1$}{\Return{$D_{\mathrm{adv}}(x)$}} \lElse{\Return{$\varnothing$}}
\end{algorithm}

\subsection{研究点二：检索上下文投毒检测方法}

\subsubsection{研究内容与问题形式化}

跨块组合投毒可能使单块统计特征接近正常文本，而检索操纵、单文档投毒与多块组合投毒又分别作用于单块表征、候选集合分布与跨块推理关系。本研究因此同时考察单块检索特征与跨块关系，目标是在多类投毒攻击下降低攻击成功率，保留正常多跳问答所需的桥接证据，并控制在线推理延迟。

防御机制部署在服务端检索阶段之后、生成阶段之前，防御者可读取查询$q$、Top-$K$候选文本块$\mathcal C_q=\{c_1,\dots,c_K\}$、各块的稠密向量$z_i$与BM25稀疏向量$v_i$，以及系统摄入时记录的来源标识$z_{\mathrm{doc}}(c_i)$与文本块在源文档中的起止词元偏移。来源标识以系统元数据为准，文本内容中声称的来源仅作为普通文本处理。设$\mathcal A$为攻击方法族，$\mathcal Q_{\mathrm{clean}}$为干净查询集，$\pi$为防御策略，$\pi(\mathcal C_q)$为其输出的过滤后上下文，则防御目标可表示为：
\begin{equation}
\begin{aligned}
  \pi^*=\arg\min_{\pi}\ &\max_{a\in\mathcal A}\ \mathrm{ASR}_a(\pi)\\
  \text{s.t.}\quad &\mathrm{ACC}_{\mathrm{clean}}(\pi)\ge\mathrm{ACC}_{\mathrm{clean}}(\mathrm{id})-\epsilon_{\mathrm{acc}},\qquad
  \mathrm{BR}(\pi)\ge\beta_{\mathrm{br}},\qquad
  \mathbb E[T(\pi)]\le T_{\max},
\end{aligned}
  \label{eq:defense_objective}
\end{equation}
\addtocounter{equation}{-1}\refstepcounter{equation}\label{eq:latency_decomp}
其中$\mathrm{ASR}_a(\pi)$为攻击$a$下经防御后的攻击成功率，$\mathrm{ACC}_{\mathrm{clean}}(\pi)$与$\mathrm{ACC}_{\mathrm{clean}}(\mathrm{id})$分别为干净查询集在启用防御策略$\pi$与无防御基线$\mathrm{id}$下的回答准确率，$\epsilon_{\mathrm{acc}}$为允许的准确率损失，$\mathrm{BR}(\pi)$为正常多跳问答中桥接证据的保留率，$\beta_{\mathrm{br}}$为其下限，$T(\pi)$为单查询的端到端防御延迟，$T_{\max}$为延迟预算。

本研究先依据统计特征和跨块关系筛选候选块，仅在待审集非空（$\mathcal S_{\mathrm{judge}}\neq\emptyset$）时调用判别模型复核待审文本并移除判为投毒的块。两阶段级联架构使绝大多数正常候选在轻量统计和规则层直接通过，将耗时较高的语言模型判别限制在可疑子集，以满足式\eqref{eq:defense_objective}中的在线推理延迟预算$T_{\max}$。整体流程如\autoref{fig:defense_framework}所示。

\subsubsection{检索统计特征与查询级阈值校准}

检索优化可能改变文本的稠密向量与词项分布\cite{mahalanobis1936generalized,lee2018simple}，本研究据此构造单块统计特征。

防御可分为\textbf{离线阶段}和\textbf{在线阶段}。\textbf{离线阶段}按独立查询与源文档将干净开发数据划分为互不相交的\textbf{特征拟合集$\mathcal D_{\mathrm{fit}}$}与\textbf{查询级校准集$\mathcal D_{\mathrm{cal}}$}，分别用于学习评分函数和设定阈值：在$\mathcal D_{\mathrm{fit}}$上预计算稠密嵌入均值$\mu$、Ledoit-Wolf线性收缩协方差矩阵特征分解$\Sigma_\beta=(1-\beta)S+\beta\frac{\operatorname{tr}(S)}{d}I_d=V\operatorname{diag}(\tilde\lambda_1,\dots,\tilde\lambda_d)V^\top$（特征值降序排列$\tilde\lambda_1\ge\dots\ge\tilde\lambda_d>0$）\cite{ledoit2004well}，并对干净语料的BM25词项矩阵\cite{robertson2009probabilistic}执行截断奇异值分解\cite{deerwester1990indexing}提取前$r_{\mathrm{svd}}$维主子空间正交基$V_{\mathrm{svd}}$，以获得良性参照基准。

而在\textbf{在线阶段}，对所防御的RAG系统中的正数稳定项超参数$\epsilon>0$，分别对每个候选文本块$c_i\in\mathcal C_q$计算四项统计特征：
\begin{subequations}\label{eq:dynamics_features}
\begin{enumerate}[label=\arabic*.,leftmargin=1.8em,itemsep=2pt]
  \item \textbf{尾谱马氏距离平方$s_{\mathrm{tail}}(z_i)$}：以低方差尾谱方向$m>r_0$上的特征值倒数加权投影平方和度量候选向量相对干净中心$\mu$的尾谱偏离：
  \begin{equation}
    s_{\mathrm{tail}}(z_i)=\sum_{m=r_0+1}^{d}\frac{\big[(z_i-\mu)^\top V_{:,m}\big]^2}{\tilde\lambda_m}.
    \label{eq:feat_tail}
  \end{equation}
  \item \textbf{词项子空间残差比$\tau_{\mathrm{svd}}(c_i)$}：计算候选块BM25向量$v_i$投影至干净主子空间$V_{\mathrm{svd}}$后在正交补空间上的能量占比：
  \begin{equation}
    \tau_{\mathrm{svd}}(c_i)=1-\frac{\|v_i^\top V_{\mathrm{svd}}\|_2^2}{\|v_i\|_2^2+\epsilon}.
    \label{eq:feat_svd}
  \end{equation}
  \item \textbf{查询方向的正交/平行分量比$\rho_{\mathrm{tan}}(c_i;\mathcal C_q)$}：设归一化查询向量为$\hat x$，Top-$K$候选集合$\mathcal C_q$单位向量的几何中位数为$\hat c_{\mathrm{pool}}$。将块向量相对集合中心的位移$\Delta u_i=\hat z_i-\hat c_{\mathrm{pool}}$分解为沿查询方向的平行分量$t_i=\hat x^\top\Delta u_i$与正交分量$o_i=\|\Delta u_i-t_i\hat x\|_2$，计算二者之比：
  \begin{equation}
    \rho_{\mathrm{tan}}(c_i;\mathcal C_q)=\frac{o_i}{|t_i|+\epsilon}.
    \label{eq:feat_tan}
  \end{equation}
  \item \textbf{首尾子窗余弦距离$d_{\mathrm{intra}}(c_i)$}：将文本块$c_i$按词元序列均分为前后两个子窗$c_i^{(1)}$与$c_i^{(2)}$，以两子窗编码向量的余弦距离度量前后子窗的表示差异：
  \begin{equation}
    d_{\mathrm{intra}}(c_i)=1-\cos\big(f(c_i^{(1)}),f(c_i^{(2)})\big).
    \label{eq:feat_intra}
  \end{equation}
\end{enumerate}
\end{subequations}

\textbf{特征标准化与逻辑回归融合。}四项统计特征的物理量纲与数值尺度各异，在融合前先以拟合集$\mathcal D_{\mathrm{fit}}$上计算的各维均值$\mu_{f,r}$与标准差$\sigma_{f,r}$（$r\in\{1,2,3,4\}$）进行逐维标准化：$\tilde f_{i,r}=(f_{i,r}-\mu_{f,r})/\max(\sigma_{f,r},\epsilon)$，构成标准化特征向量$\tilde{\mathbf f}_i=(\tilde f_{i,1},\tilde f_{i,2},\tilde f_{i,3},\tilde f_{i,4})^\top$。考虑到特征维度低、在线推理开销小且线性权重具备直接可解释性，采用逻辑回归模型融合上述特征。在$\mathcal D_{\mathrm{fit}}$上，以原始干净文本块作为正常类样本（$y_i=0$），在干净块的自然句边界处施加随机词元替换或插入扰动构造样本作为异常类样本（$y_i=1$），通过最小化二元交叉熵损失学习截距$b$与权重向量$\mathbf w$：
\begin{equation}
  \min_{\mathbf w,b}\ -\frac{1}{N}\sum_{i=1}^N \Big[y_i\log p_i + (1-y_i)\log(1-p_i)\Big],\qquad p_i=\sigma(A_i)=\frac{1}{1+e^{-A_i}},
  \label{eq:lr_fusion}
\end{equation}
其中单块线性风险评分为$A(q,c_i)=b+\mathbf w^\top\tilde{\mathbf f}_i$。合成扰动仅用于引导模型识别文本在统计表征子空间上的异常偏离方向，输出概率$p_i$不解释为真实世界的投毒后验概率；后续校准与筛选直接使用与$p_i$严格单调等价的连续风险评分$A(q,c_i)$。拟合完成后固定评分器参数$(\mathbf w,b)$与标准化统计量$(\boldsymbol\mu_f,\boldsymbol\sigma_f)$。

\textbf{查询级阈值校准与分级筛选。}为将假阳性严格控制在查询级别，在独立于拟合集的干净校准集$\mathcal D_{\mathrm{cal}}$（包含$n$条独立查询$\{q_1,\dots,q_n\}$）上固定已拟合评分器，计算每条查询的Top-$K$候选块最大风险值$M_j=\max_{1\le i\le K}A(q_j,c_{j,i})$，按升序排列得到顺序统计量$M_{(1)}\le M_{(2)}\le\dots\le M_{(n)}$。查询最大值统计量确保了阈值直接控制单次查询中发生任意良性块误报的边际概率。在查询级统计假阳性率$\alpha\in(0,1)$的约束下，当校准查询与新查询可交换时\cite{vovk2005algorithmic,angelopoulos2023conformal}，分位数阈值$\tau_\alpha$满足如下边际假阳性率上界：
\begin{equation}
  \tau_\alpha=M_{\left(\lceil(n+1)(1-\alpha)\rceil\right)}\;(M_{(n+1)}=+\infty),\quad
  \Pr_{\mathcal D_{\mathrm{cal}},q_{\mathrm{new}}}\!\big(\exists i:A(q_{\mathrm{new}},c_{\mathrm{new},i})>\tau_\alpha\big)=\Pr_{\mathcal D_{\mathrm{cal}},q_{\mathrm{new}}}\!\big(M_{\mathrm{new}}>\tau_\alpha\big)\le\alpha.
  \label{eq:quantile_calib}
\end{equation}
设定两级目标假阳性率$\alpha_{\mathrm{high}}<\alpha_{\mathrm{low}}$，按式\eqref{eq:quantile_calib}校准得到高阈值$\tau_{\mathrm{high}}=\tau_{\alpha_{\mathrm{high}}}$与低阈值$\tau_{\mathrm{low}}=\tau_{\alpha_{\mathrm{low}}}$（满足$\tau_{\mathrm{high}}\ge\tau_{\mathrm{low}}$）：
\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item 若$A(q,c_i)>\tau_{\mathrm{high}}$，表明该块呈现极其显著的统计异常，直接予以剔除；
  \item 所有$A(q,c_i)\le\tau_{\mathrm{high}}$的文本块进入存活集合$\mathcal C_{\mathrm{surv}}$并继续接受跨块关系检查；其中处于不确定风险区间的文本块（$A(q,c_i)>\tau_{\mathrm{low}}$）同步加入待审集$\mathcal S_{\mathrm{judge}}$。
\end{itemize}

\subsubsection{跨块关系检查与LLM复核}

\textbf{1) 跨块关系检查。}在组合式投毒下，单块风险值可能满足$A(q,c_i)\le\tau_{\mathrm{low}}$\cite{zheng2025grada,zhou2025trustrag}。本研究在统计筛选后保留的候选块集合$\mathcal C_{\mathrm{surv}}$上构建上下文实体—命题有向多重图$\mathcal G_q=(\mathcal V_q,\mathcal E_q)$：
\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item \textbf{节点集$\mathcal V_q$}：采用spaCy\cite{honnibal2020spacy}执行词性标注、命名实体识别与名词短语提取，结合正则表达式匹配技术代号与分类编号，汇总各保留块$c_i\in\mathcal C_{\mathrm{surv}}$中的实体与属性节点构成$\mathcal V_q=\bigcup_{c_i\in\mathcal C_{\mathrm{surv}}}\mathcal E(c_i)$。
  \item \textbf{有向多重边集$\mathcal E_q$}：采用Stanford OpenIE\cite{angeli2015leveraging}抽取文本块中的主语—关系—宾语三元组$(u,r,v)$，结合依存句法与否定词规则判定极性$\mathrm{pol}\in\{+1,-1\}$，构成命题有向边$e=(u,v,r,\mathrm{pol})\in\mathcal E_q$，并记录所属块$\mathrm{chunk}(e)=c_i$与源文档标识$\mathrm{doc}(e)=z_{\mathrm{doc}}(c_i)$。
\end{itemize}

对$\mathcal C_{\mathrm{surv}}$中满足$i<j$的文本块对$(c_i,c_j)$，比较同一主语、关系及时间/条件下的命题，定义三项成对检查指标：
\begin{subequations}\label{eq:struct_evidence}
\begin{align}
  \Phi_{\mathrm{prov}}(c_i,c_j)&=\mathbb I\Big[z_{\mathrm{doc}}(c_i)=z_{\mathrm{doc}}(c_j)\;\land\;\operatorname{gap}(c_i,c_j)\ge\tau_{\mathrm{spacer}}\Big], \label{eq:phi_prov}\\
  \Phi_{\mathrm{bridge}}(c_i,c_j)&=\mathbb I\Big[\exists u\in\big(\mathcal E(c_i)\cap\mathcal E(c_j)\big)\setminus\mathcal E(q):\mathrm{DF}(u)\le\tau_{\mathrm{df}}\Big], \label{eq:phi_bridge}\\
  \Phi_{\mathrm{conflict}}(c_i,c_j)&=\begin{aligned}[t]
    \mathbb I\Big[\exists e_1\in\mathcal E_q(c_i),\,e_2\in\mathcal E_q(c_j):\;&(u_1=u_2\land r_1=r_2)\\
    &\land\big((v_1=v_2\land\mathrm{pol}_1\neq\mathrm{pol}_2)\lor(\mathrm{pol}_1=\mathrm{pol}_2=+1\land v_1\perp v_2)\big)\Big],
  \end{aligned} \label{eq:phi_conflict}
\end{align}
\end{subequations}
其中$\operatorname{gap}(c_i,c_j)$为同源两块在源文档中的词元跨度间隔；$\mathrm{DF}(u)$为实体$u$在全语料库中的文档频率\cite{zhang2026inceptionrag}；$v_1\perp v_2$表示单值属性关系下的互斥宾语取值。由于正常长文档多跳问答同样可能召回同源远距段落或包含桥接实体\cite{yin2026rade}，因此任一结构指标的触发仅作为待复核线索，系统将满足$\Phi_{\mathrm{prov}}\lor\Phi_{\mathrm{bridge}}\lor\Phi_{\mathrm{conflict}}=1$的文本块对$(c_i,c_j)$加入待审集$\mathcal S_{\mathrm{judge}}$，由后续判别模型进行细粒度语义核验，而不做硬性误杀。

\textbf{2) 参照文本选择与LLM判别复核。}当$\mathcal S_{\mathrm{judge}}\neq\emptyset$时，从来源标识不同于待审块的存活文本块中选取检索得分最高的块作为参照文本$c_{\mathrm{anchor}}$：
\begin{equation}
  c_{\mathrm{anchor}}=\begin{cases}
    \arg\max_{c\in\mathcal C_{\mathrm{clean\_cand}}} s(q,c), & \mathcal C_{\mathrm{clean\_cand}}\neq\emptyset,\\
    \varnothing, & \mathcal C_{\mathrm{clean\_cand}}=\emptyset,
  \end{cases}
  \label{eq:anchor}
\end{equation}
其中$\mathcal C_{\mathrm{clean\_cand}}=\{c\in\mathcal C_{\mathrm{surv}}\setminus\mathcal S_{\mathrm{judge}}:z_{\mathrm{doc}}(c)\notin z_{\mathrm{doc}}(\mathcal S_{\mathrm{judge}})\}$。当$\mathcal C_{\mathrm{clean\_cand}}=\emptyset$时令$c_{\mathrm{anchor}}=\varnothing$。系统将查询$q$、参照文本$c_{\mathrm{anchor}}$、待审集合$\mathcal S_{\mathrm{judge}}$以及命题图$\mathcal G_q$中提取的成对可疑关系一并组织为结构化提示词，调用本地判别语言模型$\mathcal M$\cite{zhang2025traceback,chiang2023judging}执行一次联合判别。

判别模型按文本块输出是否存在误导性陈述及其证据判定：
\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item \textbf{命题与表述检查}：提取每个待审块的主谓宾命题，识别是否存在“声称早期记录或原答案失效、按新代号重新认定”的虚假勘误表述，或伪造系统控制指令等直接误导内容；
  \item \textbf{跨块关系核验}：对触发同源远距或桥接实体的块对，核实规则块与实例块之间是否存在协同伪造推导链路；
  \item \textbf{事实一致性比对}：在参照文本$c_{\mathrm{anchor}}$可用时，比对各待审命题与参照事实的一致性。
\end{itemize}
在此过程中，同源性、稀有桥接实体或与单一参照不一致仅构成送审线索，不单独作为删除依据；当判别模型无法明确支持投毒判定时保留该块，以防止误删正常多跳桥接证据。判别模型最终输出确认的投毒文本块集合$\mathcal U\subseteq\mathcal S_{\mathrm{judge}}$。

\textbf{3) 上下文重构与生成调用。}从存活块集合中剔除确认的投毒块$\mathcal U$，恢复生成模型的输入上下文：
\begin{equation}
  \mathcal C^*=\operatorname{TOP}_m(\mathcal C_{\mathrm{surv}}\setminus\mathcal U),
  \label{eq:context_filter}
\end{equation}
其中$\operatorname{TOP}_m$表示沿原始检索排名截取至多$m$个文本块，若剩余有效块数不足$m$则完整保留$\mathcal C_{\mathrm{surv}}\setminus\mathcal U$。重构后的安全上下文$\mathcal C^*$输入生成器生成最终答案$\hat y=G_\omega(q,\mathcal C^*)$。完整防御流程如算法\ref{alg:defense}所示。

\begin{algorithm}[htbp]
  \small
  \caption{Context Representation Analysis for RAG Defense}
  \label{alg:defense}
  \KwIn{query $q$, retrieved Top-$K$ chunks $\mathcal C_q=\{c_1,\dots,c_K\}$, fitted parameters $(\mathbf w,b)$, normalization stats $(\boldsymbol\mu_f,\boldsymbol\sigma_f)$, calibrated thresholds $\tau_{\mathrm{low}},\tau_{\mathrm{high}},\tau_{\mathrm{spacer}},\tau_{\mathrm{df}}$, judge model $\mathcal M$, target context size $m$}
  \KwOut{filtered context $\mathcal C^*$}
  $\mathcal C_{\mathrm{surv}}\leftarrow\emptyset$;\quad $\mathcal S_{\mathrm{judge}}\leftarrow\emptyset$\;
  \tcp{Stage 1a: Statistical screening}
  \ForEach{$c_i\in\mathcal C_q$}{
    $\tilde{\mathbf f}_i\leftarrow(f(c_i)-\boldsymbol\mu_f)/\max(\boldsymbol\sigma_f,\epsilon)$;\quad $A(q,c_i)\leftarrow b+\mathbf w^\top\tilde{\mathbf f}_i$\;
    \If{$A(q,c_i)\le\tau_{\mathrm{high}}$}{
      $\mathcal C_{\mathrm{surv}}\leftarrow\mathcal C_{\mathrm{surv}}\cup\{c_i\}$\;
      \lIf{$A(q,c_i)>\tau_{\mathrm{low}}$}{$\mathcal S_{\mathrm{judge}}\leftarrow\mathcal S_{\mathrm{judge}}\cup\{c_i\}$}
    }
  }
  \tcp{Stage 1b: Check cross-chunk relations}
  Construct entity--proposition multigraph $\mathcal G_q=(\mathcal V_q,\mathcal E_q)$ on $\mathcal C_{\mathrm{surv}}$\;
  \ForEach{$(c_i,c_j)\in\mathcal C_{\mathrm{surv}}\times\mathcal C_{\mathrm{surv}}$ \textnormal{with} $i<j$}{
    \lIf{$\Phi_{\mathrm{prov}}(c_i,c_j)\lor\Phi_{\mathrm{bridge}}(c_i,c_j)\lor\Phi_{\mathrm{conflict}}(c_i,c_j)$}{$\mathcal S_{\mathrm{judge}}\leftarrow\mathcal S_{\mathrm{judge}}\cup\{c_i,c_j\}$}
  }
  \lIf{$\mathcal S_{\mathrm{judge}}=\emptyset$}{\Return{$\operatorname{TOP}_m(\mathcal C_{\mathrm{surv}})$}}
  \tcp{Stage 2: LLM review}
  Select reference text $c_{\mathrm{anchor}}$ from $\mathcal C_{\mathrm{clean\_cand}}$ via Eq.~\eqref{eq:anchor}\;
  $\mathcal U\leftarrow\operatorname{JUDGE}_{\mathcal M}(q,c_{\mathrm{anchor}},\mathcal S_{\mathrm{judge}},\mathcal G_q)$\;
  $\mathcal C^*\leftarrow\operatorname{TOP}_m(\mathcal C_{\mathrm{surv}}\setminus\mathcal U)$\;
  \Return{$\mathcal C^*$}\;
\end{algorithm}

\subsection{原型应用系统}

为统一配置和比较攻防实验，本研究拟设计并实现RAG投毒攻防联合测试系统，将攻击与防御接入相同的知识库、检索器和生成器配置。系统前端用于实验配置与结果展示，后端负责载荷构造、上下文过滤与指标统计，主要模块划分如下。

\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item 攻击测试模块：对应研究点一，执行单源载荷构造、受害者侧分块、联合召回与组合生成测试。
  \item 防御测试模块：对应研究点二，执行统计筛选、跨块关系检查与LLM复核，并支持与基线方法的统一比较。
  \item 日志记录模块：记录来源标识、块偏移、检索排名、过滤决策与最终回答，按独立查询统计安全与效用指标。
  \item 可视化模块：展示源文档与文本块的对应关系、联合召回情况、过滤结果及防御前后的上下文变化。
  \item 数据库模块：保存数据划分、索引配置、载荷版本、运行记录与评测结果，为实验复现提供数据支持。
\end{itemize}

系统结构如\autoref{fig:system_design}所示。攻击与防御共用统一的数据版本和评价接口，方法之间的比较可对应到具体查询、检索上下文与过滤结果。
