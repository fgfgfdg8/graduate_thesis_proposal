\section{研究内容及方法}

\subsection{研究目标}

本研究面向RAG知识库投毒问题，分析外部文档经过分块、检索和上下文组织后对生成结果的影响。研究点一拟建立基于多文本分块协同的组合式投毒攻击框架，在单一源文档控制下设计互补的语义内容，通过分块感知构造和预算约束搜索实现多文本块联合召回，并区分检索成功与组合式生成效果。研究点二拟建立RAGShield防御方案，综合检索上下文的局部表征、跨块关系和生成影响，审查可疑文本组合，选择兼顾证据完整性与安全性的生成上下文。两个研究点将在统一实验环境中比较攻击成功率、正常问答效用与计算开销，整体研究思路如\autoref{fig:framework}所示。

\subsection{威胁模型}

本研究考虑知识库接收外部文档的RAG场景。攻击者向正常知识库写入一个源文档$D_{\mathrm{adv}}$，该文档与正常文档经过相同的解析、分块和索引流程。系统根据用户查询检索文本块，并将选定证据提供给生成模型。攻击目标是使指定查询产生攻击者设定的错误答案。

攻击者的写入权限限于$D_{\mathrm{adv}}$，可以修改其中的文本、段落顺序和局部布局。实际检索单元由受害者侧分块器产生，分块器、检索器、正常语料和生成模型参数保持不变。攻击者在给定预算内获得查询反馈，基准设置返回检索文本及排名，有分数接口时同时记录相关性分数，生成接口返回回答文本。搜索依赖这些可观测反馈，不使用受害者检索器梯度。分块规则已知与部分已知分别作为两种实验条件，后者采用有限组估计配置开展搜索，再在实际系统返回的文本块上确认联合召回，在独立配置上测试迁移效果。

防御者在检索后访问查询、候选文本块、检索分数和可用的向量表示。由系统记录的源文档标识与块偏移用于判断同源关系，文档正文中自称的来源不作为可信标识。防御者可调整上下文中的证据组成，并在限定预算内执行诊断生成。基本方案面向仅返回文本的生成接口，重排序器内部表征、检索器梯度和答案概率作为具有相应访问权限时的附加信号。防御决策不使用真实答案、攻击目标或测试集投毒标签，相关标签仅用于离线评价。

\subsubsection{研究内容与问题定义}

单一攻击文档进入知识库后，其内容会被系统转换为多个检索单元。不同单元能否保留预设的信息角色，既取决于源文档的组织方式，也取决于系统分块边界。本研究拟将互补前提组织在同一源文档中，研究分块后文本之间的联合召回与组合式生成效果。攻击构造、检索反馈和生成反馈共同参与载荷搜索，使文档内容的修改直接依据其进入受害者系统后的表现。

设$q\in Q$为目标查询，$x=D_{\mathrm{adv}}$为攻击源文档，$\phi$为受害者侧分块函数，正常知识库产生的文本块集合记为$\mathcal{C}_{\phi}$。攻击文档产生的文本块及其检索结果定义为

\begin{equation}
  C_{\phi}(x)=\phi(x),\qquad
  R_K(q,x;\phi)=\operatorname*{TopK}_{c\in\mathcal{C}_{\phi}\cup C_{\phi}(x)}s_r(q,c),
  \label{eq:chunktrojan_chunking}
\end{equation}

其中$s_r(q,c)=f_r(q,c)$为检索器返回的相关性评分，$K$为检索结果数量。向量相似度的具体形式随检索器确定。改变分块配置时，正常语料与攻击文档均采用该配置构建检索单元。

依据预设语义角色，从$C_{\phi}(x)$中识别两个不同的实际文本块$c_A$和$c_B$。例如，一个文本块说明实体之间的对应关系，另一个文本块说明相关实体的属性，两者合并后形成针对目标查询的回答依据。角色识别由文本内容和块偏移确定，在观察生成结果之前完成。两块均来自$x$，各自承载完整的局部前提，其联合内容提供目标推理所需的关系。若分块使两类前提落入同一块，或某一前提被截断而无法识别，则将该候选记为角色构造失败。

定义目标文本块的联合召回事件及其统计指标为

\begin{equation}
  I_{\mathrm{co}}(q)=\mathbf{1}[c_A\in R_K(q,x;\phi)\land c_B\in R_K(q,x;\phi)],\qquad
  \mathrm{CoRecall}@K=\frac{1}{|Q|}\sum_{q\in Q}I_{\mathrm{co}}(q).
  \label{eq:corecall}
\end{equation}

其中固定一次评价的文档和分块配置后，简记为$I_{\mathrm{co}}(q)$。CoRecall@$K$用于衡量两个目标文本块共同进入检索结果的比例，是攻击检索层的核心指标。目标块排名作为辅助分析量记录。角色构造失败或任一目标块未被召回时，联合召回事件取值为零。

设生成模型为$f_g$，查询$q$的目标答案集合为$Y_q^*$，其中包含预先确定的等价答案表达。对三种受控上下文分别定义

\begin{align}
  H_A(q)&=\mathbf{1}[f_g(q,\{c_A\})\in Y_q^*],\qquad
  H_B(q)=\mathbf{1}[f_g(q,\{c_B\})\in Y_q^*],\notag\\
  H_{AB}(q)&=\mathbf{1}[f_g(q,\{c_A,c_B\})\in Y_q^*],\qquad
  H_{\mathrm{comp}}(q)=H_{AB}(q)(1-H_A(q))(1-H_B(q)).
  \label{eq:composition_success}
\end{align}

其中$H_{\mathrm{comp}}$刻画联合上下文命中目标、两个单块上下文均未命中目标的组合式攻击效果。实际攻击成功率则在完整检索上下文$R_K$上统计，保留正常证据的竞争作用。受控组合实验用于分析机制，完整上下文实验用于评价端到端攻击效果。

\subsubsection{分块感知载荷构造与优化目标}

载荷构造拟采用语义前提与布局联合设计。首先围绕目标查询确定两类互补角色，将相应实体、关系及属性组织为简短段落，再将所有段落写入同一个源文档。局部表述尽量明确指代对象，减少关键前提横跨句子边界的情况。候选修改包括前提改写、查询相关表述调整、段落顺序改变和局部长度调整，修改结果均重新经过分块器。

对于部分已知的分块规则，构建有限配置集合$\widehat\Phi$，覆盖块长、重叠长度和起始偏移的变化。每次评价重新识别$c_A$与$c_B$，记录角色是否保留、是否分离及是否共同被检索。角色识别使用统一规则处理各配置，避免根据生成是否成功事后选择目标块。角色有效性和联合召回随配置变化的程度，用于衡量载荷的边界敏感性。

设$s_A=s_r(q,c_A)$、$s_B=s_r(q,c_B)$，当前索引中第$K$个检索位置的评分为$\tau_K$。联合检索奖励拟采用两个目标块中较弱一方的检索效用，例如

\begin{equation}
  J_{\mathrm{ret}}(x;q,\phi)
  =\min\left\{g(s_A-\tau_K),\ g(s_B-\tau_K)\right\},
  \label{eq:joint_retrieval_reward}
\end{equation}

其中$g$为单调的平滑映射，用于区分候选距离检索边界的程度。只有排名反馈时，使用对应的排名效用。最终评价仍按照实际Top-$K$结果计算$I_{\mathrm{co}}$，同时将全部攻击文本块加入候选索引，以反映同源块之间的竞争。

将角色满足条件、联合检索和生成验证纳入同一个源文档优化问题：

\begin{equation}
\begin{aligned}
  x^*=\arg\max_{x\in\mathcal{X}}\quad
  &\mathbb{E}_{q\in Q_{\mathrm{opt}},\,\phi\in\widehat\Phi}
  \left[\lambda_rJ_{\mathrm{ret}}(x;q,\phi)
  +\lambda_cH_{\mathrm{comp}}(q)
  +\lambda_eH_{\mathrm{full}}(q)\right]\\
  &-\lambda_bP_{\mathrm{bound}}(x)-\lambda_p\Omega(x),
  \label{eq:chunktrojan_objective}
\end{aligned}
\end{equation}

其中$\mathcal{X}$为单一源文档的离散候选空间，$Q_{\mathrm{opt}}$为优化查询集，$H_{\mathrm{full}}(q)$表示完整检索上下文是否命中目标答案。$P_{\mathrm{bound}}$汇总不同分块配置下的角色失效和联合召回波动，$\Omega$表示文档长度与修改代价。各权重通过验证集比较确定。检索调用与生成调用的成本分别记账，并以预算约束控制。上述目标作为后续实现与实验比较的统一定义。

\subsubsection{离散候选搜索与分级评价}

直接枚举载荷修改并逐一调用生成模型，难以适应较大的候选空间。本研究拟利用历史检索与生成反馈建立代理模型，在离散候选中选择后续评价对象。候选表示由文本内容、段落布局和角色分布共同构成，使代理模型能够区分内容相近但分块行为不同的源文档。

图高斯过程作为主要候选实现。设有限候选池为$\mathcal{X}_N$，候选表示为$z_x$，依据表示相近程度构建对称非负稀疏邻接矩阵$W$，并形成图拉普拉斯矩阵$L_G$。以图扩散核表达候选之间的关联：

\begin{equation}
  L_G=\operatorname{diag}(W\mathbf{1})-W,\qquad
  K_G=\exp(-\beta L_G).
  \label{eq:payload_graph_kernel}
\end{equation}

其中$\beta>0$控制图上信息传播范围。该核用于利用已评价候选的奖励预测未评价候选的表现。其适用性通过奖励预测误差和等预算搜索结果检验，并与普通核代理、随机搜索及局部搜索比较。

候选评价分为两个层级。低成本评价执行分块、角色识别和检索，主要检查联合召回及边界稳定性。高成本评价进一步执行单块、联合块和完整上下文生成，判断组合效果与端到端目标命中。历史记录同时保留评价层级、奖励分量和实际调用成本，分别建模不同层级的观测。通过在同一候选上获得两级反馈，估计检索信号对完整攻击效果的预测能力。

设$\ell$为评价层级，$\mu_t^H(x)$为代理对高成本目标的预测均值，$\sigma_t^H(x)$为相应不确定性。下一次候选与评价层级选择表示为

\begin{equation}
  (x_{t+1},\ell_{t+1})=
  \arg\max_{x\in\mathcal{X}_N,\,\ell\in\{L,H\}}
  \frac{\mathcal{A}_t(x,\ell;\mu_t^H,\sigma_t^H)}{\widehat c_t(x,\ell)}.
  \label{eq:payload_acquisition}
\end{equation}

其中$\mathcal{A}_t$估计该次观测对高成本目标改进或不确定性降低的价值，$\widehat c_t$为预计调用成本。拟比较分级筛选与多保真度代理两类实现，并保留随机探索预算，防止低成本信号过早排除有价值候选。最终候选按相同高成本验证协议比较，低成本奖励用于搜索调度。

\begin{algorithm}[htbp]
  \small
  \caption{ChunkTrojan Payload Optimization}
  \label{alg:chunktrojan}
  \KwIn{optimization queries $Q_{\mathrm{opt}}$; chunkers $\widehat\Phi$; retriever $f_r$; generator $f_g$; target sets $Y_q^*$; initial source $x_0$; budgets $B_r,B_g$}
  \KwOut{validated source $x^*$ or $\bot$; evaluation history $\mathcal{H}$}
  Initialize a finite source-level candidate pool, $\mathcal{H}\leftarrow\emptyset$, and validated set $\mathcal{V}\leftarrow\emptyset$\;
  Build candidate representations and initialize fidelity-aware surrogates\;
  \While{the remaining budgets permit another scheduled evaluation}{
    Select candidate $x$ and fidelity $\ell$ using acquisition value per cost\;
    Apply each scheduled chunker to the entire source $x$\;
    Identify distinct same-source chunks $c_A,c_B$ using fixed role rules\;
    \eIf{role constraints hold}{
      Evaluate joint retrieval in the index containing all chunks of $x$\;
      Record retrieval utility and boundary sensitivity\;
      \If{$\ell=H$ and the remaining generation budget covers the full protocol}{
        Evaluate $A$, $B$, $AB$, and the full retrieved context\;
        Record composition reward, end-to-end reward, and validation status\;
        Add the fully evaluated source to $\mathcal{V}$\;
      }
    }{
      Record role failure with its realized evaluation cost\;
    }
    Store the candidate, fidelity, observed rewards, and actual costs in $\mathcal{H}$\;
    Update the surrogates and remaining budgets\;
    Propose source-level edits and refresh the pool while retaining evaluated nodes\;
  }
  \eIf{$\mathcal{V}\neq\emptyset$}{
    \Return{the best source in $\mathcal{V}$ under the common validation protocol, and $\mathcal{H}$}\;
  }{
    \Return{$\bot$ and $\mathcal{H}$}\;
  }
\end{algorithm}

算法\ref{alg:chunktrojan}给出了拟采用的搜索流程。每次候选评价均从完整源文档重新分块，文本块仅作为评价对象。最终输出附带角色有效性、联合召回和生成验证记录，便于区分候选奖励提高与攻击条件满足。

设$B_r$为实际执行的查询与分块配置下的检索评价次数，$B_g$为生成调用总次数，则主要计算成本记为

\begin{equation}
  T_{\mathrm{attack}}=
  O\!\left(B_r(T_{\mathrm{chunk}}+T_{\mathrm{enc}}+T_{\mathrm{ret}})
  +B_gT_{\mathrm{gen}}+T_{\mathrm{sur}}\right).
  \label{eq:attack_cost}
\end{equation}

其中各项分别表示分块、编码、检索、生成及代理更新成本。分块扫描与源文档长度有关，$C$个文本块的$d$维向量存储量为$O(Cd)$，编码与Top-$K$搜索时间由模型和索引实现决定。对$N$个候选构建稠密图核、对$t$条观测执行朴素精确高斯过程更新，分别可能产生$O(N^3)$和$O(t^3)$的线性代数开销。实现时拟通过稀疏图、候选池规模控制及缓存减少开销，并统计代理计算是否抵消生成调用的节省。

\subsubsection{实验设计与评价方法}

实验拟采用自然问题数据集（Natural Questions，NQ）、MS MARCO和多跳问答数据集HotpotQA，覆盖事实查询与多段证据推理\cite{kwiatkowski-etal-2019-natural,bajaj2018msmarcohumangenerated,yang-etal-2018-hotpotqa}。此外，SafeRAG从RAG安全评测角度对银噪声、上下文冲突、软广告和拒绝服务等攻击任务进行系统组织，并在多个RAG组件上提供统一评测，可作为通用问答数据集之外的安全评测补充\cite{liang2025saferag}。检索器优先选用Izacard等\cite{izacard2022unsupervised}提出的Contriever及其监督微调版本Contriever-MS，并根据资源条件扩展至Xiong等\cite{xiong2021approximate}提出的ANCE等公开模型。首先在不含重排序器的配置中分析分块和联合召回，再加入重排序、混合检索等设置检验适用范围。对含重排序的系统分别报告初步召回和最终入选上下文中的联合保留率。

攻击比较包括正常知识库、未经优化的单源载荷、仅优化单块相关性的载荷和完整ChunkTrojan。选取单文档投毒、分块感知投毒和多文本组合投毒作为外部基线，在同一评测环境中明确各自的源文档数、注入长度和查询预算。通过移除边界评价、改用随机搜索、关闭分级评价等消融，分析各部分对攻击效果与调用成本的作用。

检索层记录正常证据召回率、攻击源召回率、CoRecall@$K$及目标块排名。攻击源召回率统计至少一个攻击块被检索的查询比例，用于区分单源出现与目标块共同出现。生成层记录目标答案命中率、攻击成功率（Attack Success Rate，ASR）和组合式攻击成功率。生成组合实验比较$A$、$B$和$A+B$，并加入$A+R$与$B+R$，其中$R$为长度和检索相关性相近、但不承担目标组合角色的无关文本块。保持提示、解码配置和位置规则一致，以区分特定组合与上下文数量变化的影响。组合式成功与更强的非加性解释分开报告，后者依据匹配对照结果分析。

数据按独立查询划分优化集、验证集和测试集，载荷选择与超参数调整在测试前完成。同一查询的多次构造、多个分块设置及重复生成均归入该查询，以查询为单位汇总结果并计算区间。对于查询特定的在线攻击，另设已知目标查询的攻击协议，固定调参结果并逐次记录在线搜索成本，与未参与优化查询上的迁移实验分开报告。

\subsection{研究点二：基于检索上下文表征分析的检索增强生成安全防御方法}

\subsubsection{研究内容与防御目标}

多个文本块联合支持某一回答时，单块异常程度与其实际作用可能不一致。正常多跳问答中的桥接证据同样具有较强的组合影响。本研究拟从检索上下文的表征与依赖关系出发，研究局部风险筛查、候选组合审查和证据选择相衔接的防御方法。局部与结构分析用于组织审查对象，生成干预用于估计组合影响，语义支持和任务效用用于约束最终处理。

给定查询$q$，设初始生成上下文为$R=R_K(q)$，可用候选池为$P=R_{K'}(q)$，其中$K'\geq K$。每个文本块记录文本、检索分数、表示$z_i$及可用的来源标识，查询表示记为$z_q$。防御输出修复后的上下文$R^*\subseteq P$、最终回答$y^*=f_g(q,R^*)$及文本块处理记录。候选池中的后备文本同样需要审查，候选池大小受检索和计算预算约束。

防御目标是在抑制目标错误回答的同时保留正常证据，重点评价普通投毒、同源组合投毒和正常多跳问答。以下流程为拟验证的方法草稿，先建立可解释评分基线，再比较不同特征组合与决策方式，具体分类器、训练方式和参数根据验证结果确定。

\subsubsection{局部表征与候选组合构建}

局部分析拟计算文本与查询的相关性、语义片段删减后的检索分数变化，以及文本表述与查询要求的一致性。检索分数对少量内容高度敏感，可作为局部风险线索。具有模型访问权限时，补充高影响词元的语言合理性或重排序器内部表征。各信号参照正常验证数据标定为可比较的分数，形成局部风险$L_i$，基本实现不要求这些附加信号全部可用。

结构分析结合文本块相似关系、实体关联、同源分布与上下文整体分布。拟统计相似文本集中程度、跨块实体关系是否冲突、某一来源占据的上下文比例，以及检索分数与语义一致性之间的偏离。由此形成文本块关系特征$F_i^{\mathrm{rel}}$和上下文分布特征$F^{\mathrm{ctx}}$。来源集中和语义相近用于描述集合结构，其含义通过正常同源检索与正常多跳样本校准。

候选组合族$\mathcal{S}$由三类对象共同构成：局部或结构风险较高的文本，同源或共享实体关系的文本组合，以及预留预算内抽样得到的低风险组合。优先检查规模较小的组合，再根据剩余预算扩展。后一类抽样使表面正常的文本也能进入审查范围。候选数量与组合大小设定上限，并单独评价候选构建对真实攻击组合的覆盖率。

\subsubsection{组合影响审查与正常证据保护}

组合影响审查首先基于初始上下文生成内部候选回答$y_0$，随后比较移除单块和移除组合后的变化。定义$v_q(y_0;C)$为上下文$C$对候选回答的支持程度。有概率接口时，可采用候选回答的长度归一化对数概率；仅有文本接口时，采用固定解码或重复生成下关键答案与语义表达的一致性统计。同一次比较使用相同的评分口径，候选回答仅在系统内部用于诊断。

对候选组合$S\subseteq R$定义

\begin{equation}
  \Delta(S)=v_q(y_0;R)-v_q(y_0;R\setminus S),\qquad
  I(S)=\Delta(S)-\sum_{c_i\in S}\Delta(\{c_i\}).
  \label{eq:ragshield_influence}
\end{equation}

其中$\Delta(S)$反映移除组合后候选回答支持程度的变化，$I(S)$反映组合移除与逐块移除之间的差异。该差异可能为正或负，拟结合两侧偏离及其在正常任务中的分布开展分析。对高优先级组合补充等长度、相近相关性的替换对照，控制文本数量和位置变化。评分刻画给定干预条件下的回答依赖，用于组织风险证据。

正常分布按查询类型、组合大小和上下文长度分组估计，分别覆盖单跳与多跳任务。对有较大组合影响的文本，进一步检查其是否提供查询所需的实体关系，关键前提是否相互矛盾，以及其他来源能否提供一致支持。缺少独立来源支持时，将其作为不确定性保留在审查结果中。组合风险可统一表示为

\begin{equation}
  \rho_S=F_{\mathrm{risk}}\!\left(
  \{L_i,F_i^{\mathrm{rel}}\}_{c_i\in S},\ F^{\mathrm{ctx}},\
  \widetilde\Delta(S),\ \widetilde I(S),\ E(S)\right),
  \label{eq:ragshield_risk}
\end{equation}

其中$\widetilde\Delta$与$\widetilde I$为经正常样本校准的影响特征，$E(S)$汇总语义支持、矛盾关系及来源信息。$F_{\mathrm{risk}}$先采用分位数标定与加权评分实现，再与密度分析、语义一致性判别或轻量分类器比较。正常多跳证据的保留率和误报率共同约束风险阈值，使正常桥接信息在审查和修复后仍有机会进入生成上下文。

\subsubsection{风险约束下的上下文修复}

上下文修复在有限候选集合中比较保留、移除和替换方案。根据组合风险生成若干候选上下文$\mathcal{U}$，每个候选保留原始检索位置记录，并满足相同的上下文长度预算。对高风险组合，优先比较打断可疑依赖且保留其他证据的修改；对语义支持明确的桥接文本，增加其保留优先级。后备文本经局部和关系分析后进入候选，最终选中的修复上下文再执行一次组合复查。

拟采用以下目标组织候选选择：

\begin{equation}
\begin{aligned}
  R^*=\arg\max_{C\in\mathcal{U}}\quad
  &U_{\mathrm{rel}}(q,C)+\eta U_{\mathrm{cover}}(q,C)
  +\xi U_{\mathrm{support}}(q,C)\\
  &-\lambda\max_{S\in\mathcal{S}:S\subseteq C}\rho_S
  -\kappa D(C,R)-\nu U_{\mathrm{unc}}(C),\\
  \text{s.t.}\quad &|C|\leq K,\qquad \operatorname{len}(C)\leq L_{\mathrm{ctx}}.
  \label{eq:ragshield_selection}
\end{aligned}
\end{equation}

其中$U_{\mathrm{rel}}$表示查询相关性，$U_{\mathrm{cover}}$表示所需实体关系的覆盖程度，$U_{\mathrm{support}}$表示经审查的证据支持程度，$D(C,R)$为移除与替换代价，$U_{\mathrm{unc}}(C)$汇总待审查组合的覆盖不足和证据不确定性，$L_{\mathrm{ctx}}$为上下文长度预算。风险项只对已审查的组合计算，空集合的最大值按零处理，未审查状态由不确定性项记录。候选选择拟采用预算约束下的贪心修改或有限子集采样，权重在验证集上比较。输出前检查预定的最低审查覆盖要求。复查后若风险、审查覆盖或证据覆盖条件未满足，系统返回带证据不足提示的回答，并将该情形计入回答覆盖率与拒答率。

\begin{algorithm}[htbp]
  \small
  \caption{RAGShield Context Audit and Repair}
  \label{alg:ragshield}
  \KwIn{query $q$; candidate pool $P$; initial context $R$; generator $f_g$; clean calibration data $\mathcal{D}_{\mathrm{cal}}$; audit budget $B_a$; context limits}
  \KwOut{answer $y^*$; repaired context $R^*$; audit log $\mathcal{L}$}
  Compute local, relational, and context-distribution features\;
  Construct a bounded group family using risk, provenance, semantic links, and exploration\;
  Generate an internal provisional answer $y_0$\;
  \ForEach{scheduled group $S$ within the audit budget}{
    Evaluate single-chunk and group removals with a common support score\;
    Add matched replacement controls when the remaining budget permits\;
    Calibrate influence features against matched clean-query strata\;
    Assess semantic support, contradictions, and available source evidence\;
    Estimate group risk $\rho_S$ and record coverage and uncertainty\;
  }
  Build a bounded family of keep, remove, and replace contexts\;
  Screen replacement chunks and preserve supported bridge evidence\;
  Select $R^*$ by relevance, coverage, support, risk, uncertainty, and modification cost\;
  Re-audit new combinations using a reserved part of $B_a$\;
  \eIf{$R^*$ satisfies the calibrated risk, audit-coverage, and evidence-coverage criteria}{
    Generate $y^*\leftarrow f_g(q,R^*)$\;
  }{
    Return an evidence-insufficiency response as $y^*$\;
  }
  Store decisions, unaudited groups, and actual costs in $\mathcal{L}$\;
  \Return{$y^*,R^*,\mathcal{L}$}\;
\end{algorithm}

\autoref{fig:ragshield_pipeline}与算法\ref{alg:ragshield}给出了防御各环节的输入输出关系。局部风险和上下文结构决定审查顺序，组合干预提供回答依赖特征，证据支持约束修复决策，修复后复查处理新形成的组合。审查与复查共用预算，并预留最终生成所需调用。对于$K'$个$d$维文本表示，完整成对相似度计算为$O(K'^2d)$，影响审查的额外开销随实际生成或评分调用次数增长。通过限制组合规模、缓存重复干预和按风险分配预算控制成本。

\subsubsection{实验设计与方案完善}

防御实验拟设置普通投毒、组合投毒、知晓防御规则的自适应投毒，以及未投毒的正常多跳问答四类条件。攻击集同时覆盖公开攻击与ChunkTrojan，正常集保留同源多块、重复证据和关键桥接证据等情形。校准集与测试集按查询及来源划分，避免将同一源文档的相邻块分配到不同集合而造成信息泄漏。

实验比较无防御、仅局部筛查、局部与结构筛查、加入组合影响审查，以及完整上下文修复。对候选组合覆盖、随机探索、双侧影响校准、匹配替换、桥接证据保护和修复后复查分别开展消融。外部基线覆盖文本过滤、上下文聚合和文档隔离，统一报告其模型访问条件与额外调用次数。

主要指标包括防御后的ASR、正常检索召回率、答案精确匹配率（Exact Match，EM）、词元级$F_1$分数、误报率（False Positive Rate，FPR）、桥接证据保留率、回答覆盖率和延迟。其中，$F_1$分数为词元级精确率与召回率的调和平均值。误报率分别按文本块与查询统计，拒答样本纳入整体效用评价。通过上述结果确定各特征的独立作用、预算分配方式及最终评分方案，形成兼顾风险抑制与证据利用的防御方法。

\subsection{原型应用系统}

本研究拟设计并实现RAG投毒攻防联合测试系统，将两个研究点接入相同的知识库、检索器和生成器配置。系统以论文实验验证为目标，前端用于配置实验与展示结果，后端执行载荷搜索、上下文审查和指标统计。主要功能划分如下。

\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item 攻击测试模块管理单一源文档的构造与注入，执行分块、联合检索和生成验证，记录载荷版本、评价层级及调用成本。
  \item 防御测试模块提取上下文特征，组织候选组合与干预实验，生成修复上下文，并支持基线和消融配置的统一比较。
  \item 日志审计模块记录源文档标识、块偏移、检索排名、组合干预、证据处理与最终回答，按独立查询计算安全和效用指标。
  \item 可视化模块展示源文档到文本块的对应关系、联合召回情况、组合影响及修复前后的证据变化，同时呈现攻击效果与开销对比。
  \item 数据库模块保存数据划分、索引配置、载荷版本、运行日志与评测结果，为实验复现和审计查询提供数据支持。
\end{itemize}

系统结构如\autoref{fig:system_design}所示。攻击与防御使用统一的数据版本和评价接口，实验配置、随机种子、阈值来源及生成参数随结果保存。系统同时支持正常、投毒和防御后对照运行，使方法比较能够回溯到具体查询、检索上下文和处理决策。
