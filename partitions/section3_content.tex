\section{研究内容及方法}

\subsection{研究目标}

本研究面向RAG系统中“文档级摄入”与“块级检索”之间的粒度差，研究外部源文档经受害者侧分块后形成的跨块组合投毒风险及其防御方法。在攻击侧，现有单文档投毒方法要求单个文本承载完整攻击逻辑\cite{chang2025oneshot,zhang2026corruptrag}，多文档分布式投毒则假设攻击者向语料库注入多个独立文本\cite{zhang2026inceptionrag}。本研究考虑攻击者仅控制单个源文档的条件，使分块产生的两个同源文本块分别承载互补前提：任一单块均缺乏导出目标答案所需的完整依据，目标是在两块共同被检索时诱导模型输出指定答案。研究点一采用先构造组合载荷、再优化检索相关性的两步方法。

在防御侧，现有方法主要依赖单块统计异常\cite{kim2025gmtp}、集合聚类\cite{zhou2025trustrag,kim2025ragdefender}或多轮分组生成\cite{xiang2024certifiably}，在跨块组合投毒与正常多跳证据并存时面临检测与保留的权衡。研究点二结合单块检索统计特征与上下文跨块关系筛选待审文本，再对筛选出的待审集调用一次LLM与参照文本比较，移除判为投毒的文本块。两个研究点在统一的数据、索引与生成设置下开展评估，并集成为RAG投毒攻防联合测试系统，整体研究思路如\autoref{fig:framework}所示。

\subsection{研究点一：同源跨块投毒方法}

\subsubsection{威胁模型与问题形式化}

\textbf{威胁模型。}
\begin{enumerate}
  \item \textbf{目标RAG系统模型}：目标系统由外部知识库、文档分块器$\phi_v$、检索器$R_v$与生成模型$G_\omega$构成，其中$\omega$表示生成解码随机性。系统定期摄入外部源文档，经受害者侧分块器切分为固定容量的文本块并编码入库；用户提交查询$q$后，检索器按相关性得分$s_v(q,\cdot)$降序返回前$K$个文本块构成上下文$R_K(q)$，交由生成模型输出回答。攻击者仅能篡改\textbf{单一}可被系统重新摄入的外部源文档$d\in\mathcal D$，以替换更新为基本设置，追加新文档作为辅助设置单独评价。\todo{增加目标RAG系统的符号化表示公式}
  \item \textbf{攻击者目标}：攻击者旨在通过篡改开放域语料库中的单一源文档，使目标RAG系统在经过摄取、分块、向量化等管线后，在处理目标查询时输出预设的错误答案。
  \item \textbf{攻击者能力与知识}：攻击者掌握目标查询$q$及其原始正确答案$y_{\mathrm{true}}$，旨在诱导系统输出预设的错误目标答案$a^*$，且$a^*$与$y_{\mathrm{true}}$语义互斥。攻击者仅能通过黑盒接口访问受害者系统，无法读取其内部检索得分$s_v$、模型梯度、分块边界或召回顺序。与前序工作\cite{nie2026crcp,chaudhari2026phantom}一致，攻击者可在本地搭建由影子分块器集合$\Phi_{\mathrm{shadow}}$、代理检索编码器$E_s$及其影子检索得分$s_s$和影子生成模型$G_{\mathrm{shadow}}$构成的影子系统，用于离线构造与筛选攻击载荷；受害者侧的实际检索排名与生成结果仅用于实验评估。本研究以$|\mathcal D_{\mathrm{adv}}|=1$的单一受控源文档作为攻击预算单位\cite{chang2025oneshot,zhang2026corruptrag}。
  \item \textbf{防御者目标}：防御者旨在在不显著降低干净查询的语义准确率的前提下，识别并移除潜在投毒文本块，保障RAG系统对问题的准确回答率，尤其是需要多跳推理的问题的正确率，同时需要保持开销可控。
  \item \textbf{防御者能力与知识}：防御者将防御机制部署于服务端检索阶段之后、生成阶段之前，防御机制可读取候选文本块的检索向量、词项表示及系统摄入时记录的文档来源标识$z_{\mathrm{doc}}(c)$与文本块在源文档中的起止词元偏移，在固定检索器与生成模型参数的前提下过滤检索上下文。
\end{enumerate}

\textbf{问题形式化。}遵循文献\cite{zou2025poisonedrag}的框架，定向RAG投毒需同时满足检索条件与生成条件。\todo{在这里要把检索条件和生成条件先定义清楚，不要先定义一大堆无关静要的东西}设除载体文档$d$外的背景分块索引库为$\mathcal C_{-d}^\phi=\phi(\mathcal D\setminus\{d\})$，$D_{\mathrm{adv}}(x)$为候选状态$x$下的完整投毒源文档，在分块算子$\phi$下更新后的分块语料库为$\mathcal C_v^\phi(x)=\mathcal C_{-d}^\phi\cup\phi(D_{\mathrm{adv}}(x))$。对角色$j\in\{A,B\}$与文档分块策略$\phi$，当$\phi(D_{\mathrm{adv}}(x))$中存在完整包含核心载荷$\mathcal P_j$的分块窗口时，记角色完整性指示器$I_j(\phi)=1$并记对应主块为$c_j^{(\phi)}$；若多个窗口完整包含同一核心，主块取对应检索排序中最高者，并沿用该系统的并列分排序规则；否则记$I_j(\phi)=0$。定义单视图$\phi$下两核心分别完整落入不同块且共同进入Top-$K$的\textbf{联合召回事件}$Z_\phi(x)$为：
\begin{equation}
  Z_\phi(x)=\mathbb I\Big[I_A(\phi)=1\;\land\;I_B(\phi)=1\;\land\;c_A^{(\phi)}\neq c_B^{(\phi)}\;\land\;\big\{c_A^{(\phi)},c_B^{(\phi)}\big\}\subseteq R_K\big(q;\mathcal C_v^\phi(x)\big)\Big],
  \label{eq:attack_corpus}
\end{equation}
其中$R_K(q;\mathcal C_v^\phi(x))=\operatorname{TopK}(q;\mathcal C_v^\phi(x))$为Top-$K$检索集合；当任一角色核心被切分截断（$I_A(\phi)=0$或$I_B(\phi)=0$）时，$Z_\phi(x)=0$。

\todo{这个定义作为投毒攻击的最终目标未讲清楚，应当argmax进行定义}设语义答案判定器为$J(q,y_{\mathrm{ref}},\hat y)\in\{0,1\}$，在受害者分块配置分布$\Pi_v$与解码随机性$\omega$下，端到端目标答案$a^*$生成概率$F(x)$定义为：
\begin{equation}
  F(x)=\Pr_{\phi_v\sim\Pi_v,\,\omega}\Big[J\big(q,a^*,G_\omega(q,R_K(q;\mathcal C_v^{\phi_v}(x)))\big)=1\Big].
  \label{eq:attack_generation}
\end{equation}

本研究考虑两个同源文本块$c_A$和$c_B$分别承担互补推理角色的情形，$c_A$承载抽象规则定义，$c_B$承载查询实体的实例归属绑定\cite{zhang2026inceptionrag}。为比较单块与双块的目标生成效果，从除载体文档外的影子背景库$\mathcal C_{-d}^s$中取前$K-2$个高分干净块固定为有序序列$B_0=[d_{(1)},\dots,d_{(K-2)}]$，并设置与角色块长度及主题匹配的干净中性替代块$N_A,N_B$，按固定槽位构造四组词元长度恒为$K$的对比上下文：
\begin{equation}
  C_{00}=[B_0,N_A,N_B],\qquad
  C_{10}=[B_0,c_A,N_B],\qquad
  C_{01}=[B_0,N_A,c_B],\qquad
  C_{11}=[B_0,c_A,c_B].
  \label{eq:attack_composition}
\end{equation}
对$u,v\in\{0,1\}$，记上下文$C_{uv}$触发目标答案的语义判定结果为$Y_{uv}=J(q,a^*,G_{\mathrm{shadow}}(q,C_{uv}))\in\{0,1\}$，确定性解码下要求单块不命中、双块命中攻击者目标答案$a^*$的\textbf{组合生成判据}为：
\begin{equation}
  \mathcal V_{\mathrm{comp}}(x)=\mathbb I\big[Y_{11}=1\;\land\;Y_{10}=0\;\land\;Y_{01}=0\;\land\;Y_{00}=0\big].
  \label{eq:gen_gate}
\end{equation}
在全文重切分后的端到端评估中，同时统计自然Top-$K$上下文$R_K(q;\mathcal C_v^{\phi_v}(x))$的目标答案$a^*$命中率及单块消融表现。\todo{这里要讲清楚为什么需要这个代理优化目标，给出例如原问题建模求解困难这样的真实、站得住脚的理由，进行自然推导获得这个结论，而不是突兀地直接丢出来}在流畅度权重$\lambda_{\mathrm{ppl}}\ge 0$时，单源跨块投毒构造在影子分块视图分布$\Pi_\Phi$下的代理优化目标为：
\begin{equation}
  \max_{x\in\mathcal X}\ \mathbb E_{\phi\sim\Pi_\Phi}\big[Z_\phi(x)\big]-\lambda_{\mathrm{ppl}}\mathcal L_{\mathrm{ppl}}(x),\qquad
  \text{s.t.}\quad \mathcal V_{\mathrm{comp}}(x)=1,\;\mathcal M_{\mathrm{lex}}(x)=1.
  \label{eq:attack_objective}
\end{equation}
由于直接在逻辑正文上执行基于梯度的离散词元替换\cite{ebrahimi-etal-2018-hotflip,zou2023universal}可能破坏跨块推理关系\cite{liu2024autodan}，载荷构造分为两步：阶段一在相同背景$B_0$下构造并筛选满足$\mathcal V_{\mathrm{comp}}(x)=1$的双块核心载荷与前后背景句；阶段二保持核心载荷与背景句不变，仅在背景句的自然句边界处优化定长检索触发器，并在组装完整文档后经重切分检验$Z_\phi(x)$与$\mathcal V_{\mathrm{comp}}(x)$，整体流程如\autoref{fig:attack_framework}所示。

\subsubsection{阶段一：双块载荷构造}

\textbf{1) 规则块、实例块与背景句构造。}每个植入段落$P_j$依次拼接前置背景句$\mathcal S_j^{\mathrm{pre}}$、核心载荷$\mathcal P_j$和后置背景句$\mathcal S_j^{\mathrm{post}}$：
\begin{equation}
  P_j=\mathcal S_j^{\mathrm{pre}}\oplus\mathcal P_j\oplus\mathcal S_j^{\mathrm{post}},\qquad j\in\{A,B\},
  \label{eq:payload_layout}
\end{equation}

\todo{这里最重要的核心载荷迭代构造算法没有说清楚，不要只甩定义，要说清楚如何进行迭代，例如遗传、组合迭代等，可以参照D:\\学在东南\\毕业论文\\开题\\硕论开题报告\\docs\\RAG安全文献攻防技术手段总结报告.md中的有关载荷构造方法，结合本研究的性质，参考并构造一个最合适的迭代方法，在这里进行说明}
其中$\oplus$表示文本拼接。各部分内容如下：
\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item \textbf{核心载荷$\mathcal P_A$}：作为规则块，定义符合源文档领域语境的分类标准或属性映射规则，并以勘误陈述指出早期记录隐含的原答案$y_{\mathrm{true}}$已按分类代号重新核定，用于影响模型对$y_{\mathrm{true}}$的采信，同时将文本内容限定在规则层，与查询实体保持分离。
  \item \textbf{核心载荷$\mathcal P_B$}：作为实例块，陈述查询主体在档案记录中对应的分类代号，建立查询实体与分类代号之间的关联，使生成模型在同时读取$\mathcal P_A$与$\mathcal P_B$时结合规则与实例导出目标答案$a^*$。
  \item \textbf{背景句$\mathcal S_j^{\mathrm{pre}},\mathcal S_j^{\mathrm{post}}$}：由$2\sim 3$句与插入段落前后文主题衔接的句子构成，置于核心载荷$\mathcal P_j$两侧以减少窗口边界直接截断核心载荷的情况，并在自然句边界处提供阶段二检索触发器的插入位置。
\end{itemize}

\textbf{2) 载荷插入位置与分布式性质保证。}将干净源文档$D$按自然段解析为$\{p_1,\dots,p_M\}$，记第$k$段末尾的累积词元偏移为$t_k$，全文总长为$t_M$；影子分块配置集$\Phi_{\mathrm{shadow}}$的最大窗口容量为$K_{\max}=\max_{\phi\in\Phi_{\mathrm{shadow}}}K_{\mathrm{size}}(\phi)$。\todo{这里需要解释为什么需要这样的分布式性质，以及它如何帮助实现攻击目标；如果“给定”没有充分的理由，就不要直接“给定”，而是给出详细的阐释说明后再确定参数这么设置的必要性，宁可不设也不要多设}给定间距系数$\gamma\ge 1.0$与单段前置背景句及核心长度预估上界$L_{\mathrm{est}}\ge 0$，先按$t_j-t_i\ge\gamma K_{\max}+L_{\mathrm{est}}$预选段落对，生成候选段落$P_A,P_B$并组装为$D_{\mathrm{adv}}$后，再核对两核心载荷的实际词元跨度间距，构成可行位置集合$\mathcal F_{\mathrm{slot}}$：
\begin{equation}
\begin{aligned}
  (k_A,k_B)&=\arg\min_{(i,j)\in\mathcal F_{\mathrm{slot}}}\Big(\big|t_i-\rho_A\,t_M\big|+\big|t_j-\rho_B\,t_M\big|\Big),\\
  \mathcal F_{\mathrm{slot}}&=\Big\{(i,j):1\le i<j\le M,\;t_j-t_i\ge\gamma K_{\max}+L_{\mathrm{est}},\;\operatorname{start}_{D_{\mathrm{adv}}}(\mathcal P_B)-\operatorname{end}_{D_{\mathrm{adv}}}(\mathcal P_A)\ge\gamma K_{\max}\Big\},
\end{aligned}
  \label{eq:slot_anchor}
\end{equation}
其中$\rho_A=0.33,\rho_B=0.66$为目标相对分位点。由于容量$K_{\mathrm{size}}\le K_{\max}$的单个分块窗口至多覆盖连续$K_{\max}$个词元，式\eqref{eq:slot_anchor}保证了同一分块窗口不会同时完整包含$\mathcal P_A$与$\mathcal P_B$，以维持载荷的分布式隐蔽性质。

\textbf{3) 组合效果检验。}按式\eqref{eq:attack_composition}构造四组对比上下文$C_{00},C_{10},C_{01},C_{11}$，并按式\eqref{eq:gen_gate}的判据$\mathcal V_{\mathrm{comp}}(x)$检验候选载荷。当$\mathcal V_{\mathrm{comp}}(x)=0$时，按分项结果修正载荷：若$Y_{10}=1$或$Y_{01}=1$，则删除对应块中可独立导出目标答案的信息；若$Y_{11}=0$，则明确$\mathcal P_A$中的规则表述及$\mathcal P_A,\mathcal P_B$之间的代号对应关系，并重新检查式\eqref{eq:slot_anchor}的位置约束。若达到最大迭代步数$T_{\mathrm{gen}}$仍未满足$\mathcal V_{\mathrm{comp}}(x)=1$，则丢弃该候选；通过检验后固定$(\mathcal P_A,\mathcal P_B)$与背景句$(\mathcal S_A,\mathcal S_B)$，进入阶段二。

\subsubsection{阶段二：分块感知的检索触发器优化}

\textbf{1) 双侧触发器布局。}在保持核心载荷不变的前提下，于核心载荷前后背景句的自然句边界处各放置一个长度为$L_{\mathrm{trig}}$的触发器词元序列$\mathbf t_j=(t_{j,1},\dots,t_{j,L_{\mathrm{trig}}})$，共$R$个副本：
\begin{equation}
  P_j(\mathbf t_j)=s_{j,1}^{\mathrm{pre}}\oplus\mathbf t_j^{(1)}\oplus s_{j,2}^{\mathrm{pre}}\oplus\mathcal P_j\oplus s_{j,1}^{\mathrm{post}}\oplus\mathbf t_j^{(2)}\oplus s_{j,2}^{\mathrm{post}}.
  \label{eq:trigger_layout}
\end{equation}
由于前后两个触发器副本被中间的核心载荷$\mathcal P_j$隔开，当三者与中间背景句的总包络跨度不超过分块容量$K_{\mathrm{size}}$时，任何完整包含核心载荷$\mathcal P_j$的分块窗口必至少完整包含其中一个触发器副本。设影子分块视图集合为$\Phi_{\mathrm{shadow}}=\{\phi_m\}_{m=1}^M$，单视图配置$\phi_m=(K_{\mathrm{size},m},O_m,\xi_m)$包含窗口容量$K_{\mathrm{size},m}$、重叠词元数$O_m$与切分起始相位$\xi_m$。记角色段$j$中核心载荷$\mathcal P_j$、第$r$个触发器副本及二者之间背景句构成的包络词元长度为$n^{(r)}>0$；当$I_j(\phi)=1$时，主块$c_j^{(\phi)}$保留的该包络词元长度记为$n^{(r)}(\phi)$。\todo{这里定义了村后权重和截断量，但是截断量后续并没有说明到底该怎么用、有什么意义，如果非必要则删去；另外也没有说明存活权重的作用及后文为什么会用到这个量}定义视图$\phi$下的\textbf{存活权重}$w_j(\phi)$与布局评价所用的\textbf{截断量}$h_p(w)$为：
\begin{equation}
  w_j(\phi)=\begin{cases}
    \max_{r\in\{1,\dots,R\}}\dfrac{n^{(r)}(\phi)}{n^{(r)}}\in[0,1], & I_j(\phi)=1,\\
    0, & I_j(\phi)=0,
  \end{cases}\qquad
  h_p(w)=1-w^p\quad(p>1),
  \label{eq:survival_weight}
\end{equation}
其中平均截断量$\frac{1}{M}\sum_{\phi\in\Phi_{\mathrm{shadow}}}h_p(w_j(\phi))$用于在进入词元搜索前比较并筛选插入布局。

\textbf{2) 跨视图检索损失。}\todo{定义了两个损失但是没有说明怎么用这两个损失函数指导载荷优化，需要补上这段缺失的逻辑，例如如何利用这些损失函数计算检索器的梯度并获取下一轮触发器的候选词元}以影子干净背景第$K-1$名得分$\tau_q=s(q,d_{(K-1)})$作为检索优化的参考阈值。令$\Phi^+=\{\phi\in\Phi_{\mathrm{shadow}}:I_A(\phi)=1\land I_B(\phi)=1\land c_A^{(\phi)}\neq c_B^{(\phi)}\}$为两个核心载荷角色均完整落入不同分块的影子视图集合；当$\Phi^+=\emptyset$时不执行该候选的触发器优化，当$\Phi^+\neq\emptyset$时任取参考视图$\phi_0\in\Phi^+$，在$\Phi^+$上定义角色$j$的检索损失$\mathcal L_{\mathrm{rob}}(\mathbf t_j)$：
\begin{equation}
\begin{aligned}
  \mathcal L_{\mathrm{rob}}(\mathbf t_j)&=
  \frac{1}{|\Phi^+|}\sum_{\phi\in\Phi^+}\Big[
  w_j(\phi)\,\ell_{\mathrm{ret}}\big(c_j^{(\phi)}(\mathbf t_j)\big)
  +\lambda_{\mathrm{var}}\big|s\big(q,c_j^{(\phi_0)}(\mathbf t_j)\big)-s\big(q,c_j^{(\phi)}(\mathbf t_j)\big)\big|\Big],\\
  \ell_{\mathrm{ret}}(c)&=\operatorname{softplus}\!\left(\frac{\tau_q+\delta-s(q,c)}{T}\right),
\end{aligned}
  \label{eq:chunk_rob_loss}
\end{equation}
其中$\delta>0$为得分裕度，$T>0$为平滑温度，$\lambda_{\mathrm{var}}\ge 0$为跨视图得分波动权重。

\textbf{3) 局部流畅度与词法约束。}\todo{这里也是只说了概念性的东西而没有量化，建议也改为损失函数，与第2）节合并}为提高投毒攻击的隐蔽性，需要约束触发器的语言可读性\cite{alon2023detecting,jain2023baseline}。这一步截取每个触发器副本及其前后相邻句构成的局部文本窗口$W_j^{(r)}=s_{j,1}^{(r)}\oplus\mathbf t_j^{(r)}\oplus s_{j,2}^{(r)}$，利用冻结的本地因果语言模型计算平均负对数似然作为局部流畅度损失$\mathcal L_{\mathrm{ppl}}(\mathbf t_j)$。采用Doc2Query\cite{nogueira2019document}生成的候选序列初始化$\mathbf t=(t_1,\dots,t_{L_{\mathrm{trig}}})$，并使用词法检查器$\mathcal M_{\mathrm{lex}}(\mathbf t;q,a^*,y_{\mathrm{true}})\in\{0,1\}$，要求序列满足：
\begin{enumerate}[label=(\alph*),leftmargin=2.2em,itemsep=0pt]
  \item 每个词元均为完整ASCII英文词元，且相邻位置词元满足$t_i\neq t_{i+1}$；
  \item 序列$\mathbf t$与查询$q$的最长公共连续词组长度小于2；
  \item 序列不含属于$a^*$或$y_{\mathrm{true}}$的词元，避免触发器直接包含答案词元。
\end{enumerate}

\textbf{4) 交替优化与重切分检查。}\todo{这里需要详细说明前述插入位置、损失函数等如何进行利用，以及如何实现交替优化和重切分检查的详细步骤，例如利用损失函数进行梯度计算和候选词元选择，而非仅进行定义。同时需要注意与伪代码逻辑保持一致，确保前后逻辑紧密耦合而非松散罗列。}求解步骤如算法\ref{alg:attack}所示。每轮迭代选择当前检索损失较大的角色块$j^\star=\arg\max_{j\in\{A,B\}}\mathcal L_{\mathrm{rob}}(\mathbf t_j)$，计算触发器各位置词元嵌入梯度，在满足$\mathcal M_{\mathrm{lex}}(\mathbf t_{j^\star}[i\to v];q,a^*,y_{\mathrm{true}})=1$的候选词元上按一阶内积筛选前$B_{\mathrm{cand}}$个替换项\cite{ebrahimi-etal-2018-hotflip,zou2023universal}：
\begin{equation}
  \mathbf g_i=\nabla_{e_{t_i}}\mathcal L_{\mathrm{rob}}(\mathbf t_{j^\star}),\qquad
  \Delta_{i,v}=-\mathbf g_i^\top(e_v-e_{t_i}),
  \label{eq:first_order}
\end{equation}
随后在$\Phi^+$上批量计算$\mathcal L_{\mathrm{rob}}+\lambda_{\mathrm{ppl}}\mathcal L_{\mathrm{ppl}}$，采纳使总损失严格下降的最优替换。迭代结束后将$P_A(\mathbf t_A),P_B(\mathbf t_B)$写入位置$(k_A,k_B)$组装完整文档$D_{\mathrm{adv}}(x)$，在参考视图$\phi_0$上重切分并提取角色块，检验$Z_{\phi_0}(x)=1\land\mathcal V_{\mathrm{comp}}(x)=1$。

\begin{algorithm}[htbp]
  \small
  \caption{Cross-Chunk Payload Construction}
  \label{alg:attack}
  \KwIn{query $q$, answers $y_{\mathrm{true}},a^*$, carrier document $D$, clean Top-$K$ chunks $\{d_{(1)},\dots,d_{(K)}\}$ with $\tau_q=s(q,d_{(K-1)})$, shadow chunkers $\Phi_{\mathrm{shadow}}$, shadow generator $G_{\mathrm{shadow}}$}
  \KwOut{poisoned source document $D_{\mathrm{adv}}(x)$ or $\varnothing$}
  \tcp{Stage 1: Construct paired payloads}

  }

  \tcp{Stage 2: Optimize retrieval triggers}

  \lIf{$\Phi^+=\emptyset$}{\Return{$\varnothing$}}
  \For{$t\leftarrow1$ \KwTo $T_{\mathrm{ret}}$}{

\subsection{研究点二：检索上下文投毒检测方法}

\subsubsection{研究内容与问题形式化}

跨块组合投毒可能使单块统计特征接近正常文本，而检索操纵、单文档投毒与多块组合投毒又分别作用于单块表征、候选集合分布与跨块推理关系。本研究因此同时考察单块检索特征与跨块关系，目标是在多类投毒攻击下降低攻击成功率，保留正常多跳问答所需的桥接证据，并控制在线推理延迟。

防御机制部署在服务端检索阶段之后、生成阶段之前，防御者可读取查询$q$、Top-$K$候选文本块$\mathcal C_q=\{c_1,\dots,c_K\}$、各块的稠密向量$z_i$与BM25稀疏向量$v_i$，以及系统摄入时记录的来源标识$z_{\mathrm{doc}}(c_i)$与文本块在源文档中的起止词元偏移。来源标识以系统元数据为准，文本内容中声称的来源仅作为普通文本处理。设$\mathcal A$为攻击方法族，$\mathcal Q_{\mathrm{clean}}$为干净查询集，$\pi$为防御策略，$\pi(\mathcal C_q)$为其输出的过滤后上下文，则防御目标可表示为：
\begin{equation}
\begin{aligned}
  \pi^*=\arg\min_{\pi}\ &\max_{a\in\mathcal A}\ \mathrm{ASR}_a(\pi)\\
  \text{s.t.}\quad &\mathrm{ACC}_{\mathrm{clean}}(\pi)\ge\mathrm{ACC}_{\mathrm{clean}}(\mathrm{id})-\epsilon_{\mathrm{acc}},\qquad
  \mathrm{BR}(\pi)\ge\beta_{\mathrm{br}},\qquad
  \mathbb E[T(\pi)]\le T_{\max},
\end{aligned}
  \label{eq:defense_objective}
\end{equation}
其中$\mathrm{ASR}_a(\pi)$为攻击$a$下经防御后的攻击成功率，$\mathrm{ACC}_{\mathrm{clean}}(\pi)$与$\mathrm{ACC}_{\mathrm{clean}}(\mathrm{id})$分别为干净查询集在启用防御策略$\pi$与无防御基线$\mathrm{id}$下的回答准确率，$\epsilon_{\mathrm{acc}}$为允许的准确率损失，$\mathrm{BR}(\pi)$为正常多跳问答中桥接证据的保留率，$\beta_{\mathrm{br}}$为其下限，$T(\pi)$为单查询的端到端防御延迟，$T_{\max}$为延迟预算。

本研究先依据统计特征和跨块关系筛选候选块，仅在待审触发事件$E_{\mathrm{esc}}(q)=\{\mathcal S_{\mathrm{judge}}(q)\neq\emptyset\}$发生时使用LLM检查待审文本并移除判为投毒的块。

\subsubsection{检索统计特征与查询级阈值校准}

检索优化可能改变文本的稠密向量与词项分布\cite{mahalanobis1936generalized,lee2018simple}，本研究据此构造单块统计特征。

防御可分为\textbf{离线阶段}和\textbf{在线阶段}。\textbf{离线阶段}按独立查询与源文档将干净开发数据划分为互不相交的\textbf{特征拟合集$\mathcal D_{\mathrm{fit}}$}与\textbf{查询级校准集$\mathcal D_{\mathrm{cal}}$}，分别用于学习评分函数和设定阈值：在$\mathcal D_{\mathrm{fit}}$上预计算稠密嵌入均值$\mu$、Ledoit-Wolf线性收缩协方差矩阵特征分解$\Sigma_\beta=(1-\beta)S+\beta\frac{\operatorname{tr}(S)}{d}I_d=V\operatorname{diag}(\tilde\lambda_1,\dots,\tilde\lambda_d)V^\top$（特征值降序排列$\tilde\lambda_1\ge\dots\ge\tilde\lambda_d>0$）\cite{ledoit2004well}，并对干净语料的BM25词项矩阵\cite{robertson2009probabilistic}执行截断奇异值分解\cite{deerwester1990indexing}提取前$r_{\mathrm{svd}}$维主子空间正交基$V_{\mathrm{svd}}$，以获得良性参照基准。

而在\textbf{在线阶段}，对所防御的RAG系统中的正数稳定项超参数$\epsilon>0$，分别对每个候选文本块$c_i\in\mathcal C_q$计算四项统计特征：
\begin{subequations}\label{eq:dynamics_features}
\begin{enumerate}[label=\arabic*.,leftmargin=1.8em,itemsep=2pt]
  \item \textbf{尾谱马氏距离平方$s_{\mathrm{tail}}(z_i)$}：以低方差尾谱方向$m>r_0$上的特征值倒数加权投影平方和度量候选向量相对干净中心$\mu$的尾谱偏离：
  \begin{equation}
    s_{\mathrm{tail}}(z_i)=\sum_{m=r_0+1}^{d}\frac{\big[(z_i-\mu)^\top V_{:,m}\big]^2}{\tilde\lambda_m}.
    \label{eq:feat_tail}
  \end{equation}
  \item \textbf{词项子空间残差比$\tau_{\mathrm{svd}}(c_i)$}：计算候选块BM25向量$v_i$投影至干净主子空间$V_{\mathrm{svd}}$后在正交补空间上的能量占比：
  \begin{equation}
    \tau_{\mathrm{svd}}(c_i)=1-\frac{\|v_i^\top V_{\mathrm{svd}}\|_2^2}{\|v_i\|_2^2+\epsilon}.
    \label{eq:feat_svd}
  \end{equation}
  \item \textbf{查询方向的正交/平行分量比$\rho_{\mathrm{tan}}(c_i;\mathcal C_q)$}：设归一化查询向量为$\hat x$，Top-$K$候选集合$\mathcal C_q$单位向量的几何中位数为$\hat c_{\mathrm{pool}}$。将块向量相对集合中心的位移$\Delta u_i=\hat z_i-\hat c_{\mathrm{pool}}$分解为沿查询方向的平行分量$t_i=\hat x^\top\Delta u_i$与正交分量$o_i=\|\Delta u_i-t_i\hat x\|_2$，计算二者之比：
  \begin{equation}
    \rho_{\mathrm{tan}}(c_i;\mathcal C_q)=\frac{o_i}{|t_i|+\epsilon}.
    \label{eq:feat_tan}
  \end{equation}
  \item \textbf{首尾子窗余弦距离$d_{\mathrm{intra}}(c_i)$}：将文本块$c_i$按词元序列均分为前后两个子窗$c_i^{(1)}$与$c_i^{(2)}$，以两子窗编码向量的余弦距离度量前后子窗的表示差异：
  \begin{equation}
    d_{\mathrm{intra}}(c_i)=1-\cos\big(f(c_i^{(1)}),f(c_i^{(2)})\big).
    \label{eq:feat_intra}
  \end{equation}
\end{enumerate}
\end{subequations}

\todo{这里说明白上面一大堆定义的统计特征值该怎么融合和计算，而不是一笔带过，如果选择逻辑回归则简短说明理由，如果选择其它的拟合方法则也要说明理由，并给出最后获得的风险值计算公式。}记拟合集$\mathcal D_{\mathrm{fit}}$在第$r\in\{1,2,3,4\}$维特征上的均值与标准差为$\mu_{f,r},\sigma_{f,r}$，逐维标准化为$\tilde f_{i,r}=(f_{i,r}-\mu_{f,r})/\max(\sigma_{f,r},\epsilon)$以构成$\tilde{\mathbf f}_i$。在$\mathcal D_{\mathrm{fit}}$干净块上施加随机边界词元替换构造扰动负样本，训练逻辑回归得到权重$\mathbf w$，计算单块统计风险值$A(q,c_i)=\mathbf w^\top\tilde{\mathbf f}_i$。

\textbf{查询级阈值校准。}\todo{说明如何校准风险值的阈值}以每个查询作为一个校准单元，允许同一查询内的候选块的风险值得分相关。在校准集$\mathcal D_{\mathrm{cal}}$的$n$条干净查询$\{q_1,\dots,q_n\}$上分别计算候选集合最大风险值$M_j=\max_{1\le i\le K}A(q_j,c_{j,i})$，按升序排列为$M_{(1)}\le M_{(2)}\le\dots\le M_{(n)}$。

在查询级统计假阳性率$\alpha\in(0,1)$的约束下，当校准查询与新查询可交换时\cite{vovk2005algorithmic,angelopoulos2023conformal}，阈值$\tau_\alpha$满足如下边际假阳性率上界：
\begin{equation}
  \tau_\alpha=M_{\left(\lceil(n+1)(1-\alpha)\rceil\right)}\;(M_{(n+1)}=+\infty),\quad
  \Pr_{\mathcal D_{\mathrm{cal}},q_{\mathrm{new}}}\!\big(\exists i:A(q_{\mathrm{new}},c_{\mathrm{new},i})>\tau_\alpha\big)=\Pr_{\mathcal D_{\mathrm{cal}},q_{\mathrm{new}}}\!\big(M_{\mathrm{new}}>\tau_\alpha\big)\le\alpha.
  \label{eq:quantile_calib}
\end{equation}
设定两级假阳性率阈值$\alpha_{\mathrm{high}}<\alpha_{\mathrm{low}}$，按式\eqref{eq:quantile_calib}确定高阈值$\tau_{\mathrm{high}}=\tau_{\alpha_{\mathrm{high}}}$与低阈值$\tau_{\mathrm{low}}=\tau_{\alpha_{\mathrm{low}}}$：当$A(q,c_i)>\tau_{\mathrm{high}}$时直接剔除；所有$A(q,c_i)\le\tau_{\mathrm{high}}$的块进入保留集合$\mathcal C_{\mathrm{surv}}$并继续接受跨块关系检查，其中满足$A(q,c_i)>\tau_{\mathrm{low}}$的块同时加入待审集$\mathcal S_{\mathrm{judge}}$。

\subsubsection{跨块关系检查与LLM复核}

\textbf{1) 跨块关系检查。}在组合式投毒下，单块风险值可能满足$A(q,c_i)\le\tau_{\mathrm{low}}$\cite{zheng2025grada,zhou2025trustrag}。本研究在统计筛选后保留的候选块集合$\mathcal C_{\mathrm{surv}}$上构建上下文实体—命题有向多重图$\mathcal G_q=(\mathcal V_q,\mathcal E_q)$：
\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item \textbf{节点集$\mathcal V_q$}：采用spaCy\cite{honnibal2020spacy}执行词性标注、命名实体识别与名词短语提取，结合正则表达式匹配技术代号与分类编号，汇总各保留块$c_i\in\mathcal C_{\mathrm{surv}}$中的实体与属性节点构成$\mathcal V_q=\bigcup_{c_i\in\mathcal C_{\mathrm{surv}}}\mathcal E(c_i)$。
  \item \textbf{有向多重边集$\mathcal E_q$}：采用Stanford OpenIE\cite{angeli2015leveraging}抽取文本块中的主语—关系—宾语三元组$(u,r,v)$，结合依存句法与否定词规则判定极性$\mathrm{pol}\in\{+1,-1\}$，构成命题有向边$e=(u,v,r,\mathrm{pol})\in\mathcal E_q$，并记录所属块$\mathrm{chunk}(e)=c_i$与源文档标识$\mathrm{doc}(e)=z_{\mathrm{doc}}(c_i)$。
\end{itemize}

对$\mathcal C_{\mathrm{surv}}$中满足$i<j$的文本块对$(c_i,c_j)$，比较同一主语、关系及时间/条件下的命题，定义三项成对检查指标：
\begin{subequations}\label{eq:struct_evidence}
\begin{align}
  \Phi_{\mathrm{prov}}(c_i,c_j)&=\mathbb I\Big[z_{\mathrm{doc}}(c_i)=z_{\mathrm{doc}}(c_j)\;\land\;\operatorname{gap}(c_i,c_j)\ge\tau_{\mathrm{spacer}}\Big], \label{eq:phi_prov}\\
  \Phi_{\mathrm{bridge}}(c_i,c_j)&=\mathbb I\Big[\exists u\in\big(\mathcal E(c_i)\cap\mathcal E(c_j)\big)\setminus\mathcal E(q):\mathrm{DF}(u)\le\tau_{\mathrm{df}}\Big], \label{eq:phi_bridge}\\
  \Phi_{\mathrm{conflict}}(c_i,c_j)&=\begin{aligned}[t]
    \mathbb I\Big[\exists e_1\in\mathcal E_q(c_i),\,e_2\in\mathcal E_q(c_j):\;&(u_1=u_2\land r_1=r_2)\\
    &\land\big((v_1=v_2\land\mathrm{pol}_1\neq\mathrm{pol}_2)\lor(\mathrm{pol}_1=\mathrm{pol}_2=+1\land v_1\perp v_2)\big)\Big],
  \end{aligned} \label{eq:phi_conflict}
\end{align}
\end{subequations}
其中$\operatorname{gap}(c_i,c_j)$为同源两块在源文档中的词元跨度间隔；$\mathrm{DF}(u)$为实体$u$在全语料库中的文档频率\cite{zhang2026inceptionrag}；$v_1\perp v_2$表示单值属性关系下的互斥宾语取值。由于正常长文档多跳问答同样可能召回同源远距段落或包含桥接实体\cite{yin2026rade}，满足任一指标时，将该对中的两个文本块$c_i,c_j$加入待审集$\mathcal S_{\mathrm{judge}}$。

\begin{equation}

\end{equation}

\textbf{2) 参照文本选择与LLM检查。}当$\mathcal S_{\mathrm{judge}}\neq\emptyset$时，从来源标识不同于待审块的保留块集合$\mathcal C_{\mathrm{clean\_cand}}=\{c\in\mathcal C_{\mathrm{surv}}\setminus\mathcal S_{\mathrm{judge}}:z_{\mathrm{doc}}(c)\notin z_{\mathrm{doc}}(\mathcal S_{\mathrm{judge}})\}$中选取检索得分最高的文本块作为参照文本$c_{\mathrm{anchor}}$：
\begin{equation}
  c_{\mathrm{anchor}}=\begin{cases}
    \arg\max_{c\in\mathcal C_{\mathrm{clean\_cand}}} s(q,c), & \mathcal C_{\mathrm{clean\_cand}}\neq\emptyset,\\
    \varnothing, & \mathcal C_{\mathrm{clean\_cand}}=\emptyset.
  \end{cases}
  \label{eq:anchor}
\end{equation}
当$\mathcal C_{\mathrm{clean\_cand}}=\emptyset$时，直接检查待审文本自身的命题与跨块关系。系统将查询$q$、参照文本$c_{\mathrm{anchor}}$、待审集$\mathcal S_{\mathrm{judge}}$及触发的成对指标组织为结构化提示词，调用一次本地结构化判别模型$\mathcal M$\cite{zhang2025traceback,chiang2023judging}执行以下三项检查：
\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item \textbf{命题与表述检查}：提取每个待审块的主—谓—宾命题，检查是否存在“直接声明原答案后，宣称其已失效或按新标准重分类”的勘误表述或伪造的系统指令等直接的误导性内容；
  \item \textbf{跨块关系检查}：对触发$\Phi_{\mathrm{prov}}$或$\Phi_{\mathrm{bridge}}$的成对文本块，检查规则块定义的分类代号与实例块中的查询主体绑定关系；
  \item \textbf{参照证据比较}：与参照文本$c_{\mathrm{anchor}}$比对事实一致性，输出模型判为投毒的文本块集合$\mathcal U\subseteq\mathcal S_{\mathrm{judge}}$并从$\mathcal C_{\mathrm{surv}}$中移除，按原始检索排名保留前$m$个文本块输入生成模型。
\end{itemize}

完整流程如算法\ref{alg:defense}所示。

\begin{algorithm}[htbp]
  \small
  \caption{Context Representation Analysis for RAG Defense}
  \label{alg:defense}
  \KwIn{query $q$, retrieved Top-$K$ chunks $\mathcal C_q=\{c_1,\dots,c_K\}$, calibrated thresholds $\tau_{\mathrm{low}},\tau_{\mathrm{high}},\tau_{\mathrm{spacer}},\tau_{\mathrm{df}}$, model $\mathcal M$, target context size $m$}
  \KwOut{filtered context $\mathcal C^*$}
  $\mathcal C_{\mathrm{surv}}\leftarrow\emptyset$;\quad $\mathcal S_{\mathrm{judge}}\leftarrow\emptyset$\;
  \tcp{Stage 1a: Statistical screening}
  \ForEach{$c_i\in\mathcal C_q$}{
    Compute anomaly score $A(q,c_i)=\mathbf w^\top\tilde{\mathbf f}_i$ from Eq.~\eqref{eq:dynamics_features}\;
    \If{$A(q,c_i)\le\tau_{\mathrm{high}}$}{
      $\mathcal C_{\mathrm{surv}}\leftarrow\mathcal C_{\mathrm{surv}}\cup\{c_i\}$\;
      \lIf{$A(q,c_i)>\tau_{\mathrm{low}}$}{$\mathcal S_{\mathrm{judge}}\leftarrow\mathcal S_{\mathrm{judge}}\cup\{c_i\}$}
    }
  }
  \tcp{Stage 1b: Check cross-chunk relations}
  Construct entity--proposition multigraph $\mathcal G_q=(\mathcal V_q,\mathcal E_q)$ on $\mathcal C_{\mathrm{surv}}$\;
  \ForEach{$(c_i,c_j)\in\mathcal C_{\mathrm{surv}}\times\mathcal C_{\mathrm{surv}}$ \textnormal{with} $i<j$}{
    \lIf{$\Phi_{\mathrm{prov}}(c_i,c_j)\lor\Phi_{\mathrm{bridge}}(c_i,c_j)\lor\Phi_{\mathrm{conflict}}(c_i,c_j)$}{$\mathcal S_{\mathrm{judge}}\leftarrow\mathcal S_{\mathrm{judge}}\cup\{c_i,c_j\}$}
  }
  \lIf{$\mathcal S_{\mathrm{judge}}=\emptyset$}{\Return{$\operatorname{TOP}_m(\mathcal C_{\mathrm{surv}})$}}
  \tcp{Stage 2: LLM review}
  Select reference text $c_{\mathrm{anchor}}$ from $\mathcal C_{\mathrm{surv}}\setminus\mathcal S_{\mathrm{judge}}$ via Eq.~\eqref{eq:anchor}\;
  $\mathcal U\leftarrow\operatorname{JUDGE}_{\mathcal M}(q,c_{\mathrm{anchor}},\mathcal S_{\mathrm{judge}},\mathcal G_q)$\;
  $\mathcal C^*\leftarrow\operatorname{TOP}_m(\mathcal C_{\mathrm{surv}}\setminus\mathcal U)$\;
  \Return{$\mathcal C^*$}\;
\end{algorithm}

\subsection{原型应用系统}

为统一配置和比较攻防实验，本研究拟设计并实现RAG投毒攻防联合测试系统，将攻击与防御接入相同的知识库、检索器和生成器配置。系统前端用于实验配置与结果展示，后端负责载荷构造、上下文过滤与指标统计，主要模块划分如下。

\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item 攻击测试模块：对应研究点一，执行单源载荷构造、受害者侧分块、联合召回与组合生成测试。
  \item 防御测试模块：对应研究点二，执行统计筛选、跨块关系检查与LLM复核，并支持与基线方法的统一比较。
  \item 日志记录模块：记录来源标识、块偏移、检索排名、过滤决策与最终回答，按独立查询统计安全与效用指标。
  \item 可视化模块：展示源文档与文本块的对应关系、联合召回情况、过滤结果及防御前后的上下文变化。
  \item 数据库模块：保存数据划分、索引配置、载荷版本、运行记录与评测结果，为实验复现提供数据支持。
\end{itemize}
