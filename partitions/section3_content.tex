\section{研究内容及方法}

\subsection{研究目标}

本研究面向RAG系统中“文档级摄入”与“块级检索”之间的粒度差，研究外部源文档经受害者侧分块后形成的组合式投毒风险及其防御方法。在攻击侧，现有单文档投毒方法要求单个文本承载完整攻击逻辑\cite{chang2025oneshot,zhang2026corruptrag}，分布式投毒方法则允许攻击者向语料库注入多个独立文本\cite{zhang2026inceptionrag}；本研究在攻击者仅控制一个源文档的条件下，使分块产生的两个同源文本块分别承载互补前提，实现“单块证据不足、双块协同导出”，即任一单块均缺乏导出目标答案所需的完整依据，两块共同进入检索上下文后即可诱导生成模型输出攻击者设定的答案。在防御侧，现有方法主要依赖单块的统计异常\cite{kim2025gmtp}、集合聚类\cite{zhou2025trustrag,kim2025ragdefender}或多轮隔离生成\cite{xiang2024certifiably}，难以在组合式投毒下保持稳定的检测能力，同时兼顾正常多跳证据的保留；本研究从检索统计特征与上下文结构证据出发，在多类投毒攻击下降低攻击成功率，并将结构化判别集中在可疑的检索上下文上。研究点一提出“生成可行性先行、检索可达性后置”的两阶段解耦载荷构造方法，研究点二以研究点一揭示的跨块组合风险为核心检测对象，提出统计—结构初筛与结构化判别模型审查相级联的防御方法。两个研究点在统一的数据、索引与生成协议下相互检验，并集成为RAG投毒攻防联合测试系统，整体研究思路如\autoref{fig:framework}所示。

\subsection{研究点一：基于同源多文本块协同的分布式投毒攻击框架}

\subsubsection{威胁模型与问题形式化}

\textbf{威胁模型。}本研究遵循以下威胁模型：
\begin{enumerate}
  \item \textbf{目标RAG系统模型}：目标系统由外部知识库、文档分块器$\phi_v$、检索器$R_v$与生成模型$G_\omega$构成，其中$\omega$表示生成解码随机性。系统定期摄入外部源文档，经受害者侧分块器切分为固定容量的文本块并编码入库；用户提交查询$q$后，检索器按相关性得分$s_v(q,\cdot)$降序返回前$K$个文本块构成上下文$R_K(q)$，交由生成模型输出回答。攻击者仅能篡改\textbf{单一}可被系统重新摄入的外部源文档$d\in\mathcal D$，以替换更新为基本设置，追加新文档作为辅助设置单独评价。
  \item \textbf{攻击者能力与知识}：攻击者掌握目标查询$q$及其原始正确答案$y_{\mathrm{true}}$，旨在诱导系统输出预设的错误目标答案$a^*$，且$a^*$与$y_{\mathrm{true}}$语义互斥。攻击者仅能通过黑盒接口访问受害者系统，无法读取其内部检索得分$s_v$、模型梯度、分块边界或召回顺序。与前序工作\cite{nie2026crcp,chaudhari2026phantom}一致，攻击者可在本地搭建由影子分块器集合$\Phi_{\mathrm{shadow}}$、代理检索编码器$E_s$及其影子检索得分$s_s$和影子生成模型$G_{\mathrm{shadow}}$构成的影子系统，用于离线构造与筛选攻击载荷；受害者侧的实际检索排名与生成结果仅用于最终实验评估记录。本研究以$|\mathcal D_{\mathrm{adv}}|=1$的单一受控源文档作为攻击预算单位，同一源文档被切分出的多个文本块均源自该唯一文档\cite{chang2025oneshot,zhang2026corruptrag}。
  \item \textbf{防御者能力与知识}：防御者部署于服务端检索之后、生成之前，可读取候选文本块的检索向量、词项表示及系统摄入时记录的文档来源标识$z_{\mathrm{doc}}(c)$与块内起止偏移，在固定检索器与生成模型参数的前提下审查并净化检索上下文。
\end{enumerate}

\textbf{问题形式化。}遵循文献\cite{zou2025poisonedrag}的框架，成功的定向投毒需同时满足检索条件与生成条件。设除载体文档$d$外的背景分块索引库为$\mathcal C_{-d}^\phi=\phi(\mathcal D\setminus\{d\})$，$D_{\mathrm{adv}}(x)$为候选状态$x$下的完整投毒源文档，在分块算子$\phi$下更新后的分块语料库为$\mathcal C_v^\phi(x)=\mathcal C_{-d}^\phi\cup\phi(D_{\mathrm{adv}}(x))$。对角色$j\in\{A,B\}$与分块视图$\phi$，定义角色完整性指示器$I_j(\phi)\in\{0,1\}$与主块映射$c_j^{(\phi)}$：当$\phi(D_{\mathrm{adv}}(x))$中存在完整包含核心载荷$\mathcal P_j$的分块窗口时，记$I_j(\phi)=1$并记对应主块为$c_j^{(\phi)}$；否则记$I_j(\phi)=0$。定义单视图$\phi$下兼顾双角色完整存活、跨块分离与Top-$K$共同召回的\textbf{有效联合召回事件}$Z_\phi(x)$为：
\begin{equation}
  Z_\phi(x)=\mathbb I\Big[I_A(\phi)=1\;\land\;I_B(\phi)=1\;\land\;c_A^{(\phi)}\neq c_B^{(\phi)}\;\land\;\big\{c_A^{(\phi)},c_B^{(\phi)}\big\}\subseteq R_K\big(q;\mathcal C_v^\phi(x)\big)\Big],
  \label{eq:attack_corpus}
\end{equation}
其中$R_K(q;\mathcal C_v^\phi(x))=\operatorname{TopK}(q;\mathcal C_v^\phi(x))$为Top-$K$检索集合。设语义答案判定器为$J(q,y_{\mathrm{ref}},\hat y)\in\{0,1\}$，对给定受害者分块算子$\phi_v$，解码随机性$\omega$下的条件目标生成概率定义为$F(x\mid\phi_v)=\Pr_\omega[J(q,a^*,G_\omega(q,R_K(q;\mathcal C_v^{\phi_v}(x))))=1\mid\phi_v]$；当在具有预设概率分布$\Pi_v$的受害者分块配置集合上评估时，端到端目标生成概率$F(x)$定义为：
\begin{equation}
  F(x)=\mathbb E_{\phi_v\sim\Pi_v}\big[F(x\mid\phi_v)\big]=\Pr_{\phi_v\sim\Pi_v,\,\omega}\Big[J\big(q,a^*,G_\omega(q,R_K(q;\mathcal C_v^{\phi_v}(x)))\big)=1\Big].
  \label{eq:attack_generation}
\end{equation}
本研究令两个同源文本块分别承担互补推理角色：$c_A$承载抽象规则定义，$c_B$承载查询实体的实例归属绑定\cite{zhang2026inceptionrag}。为严格区分“单块挤占干净竞争证据席位导致的答案翻转”与“双块互补前提语义合成导致的答案翻转”，固定影子背景库$\mathcal C_{-d}^s$上的前$K-2$个高分干净块为有序序列$B_0=[d_{(1)},\dots,d_{(K-2)}]$，并预先固定与角色块长度及主题匹配的干净中性替代块$N_A,N_B$，按固定槽位顺序构造四组容量恒为$K$的受控对比上下文：
\begin{equation}
  C_{00}=[B_0,N_A,N_B],\qquad
  C_{10}=[B_0,c_A,N_B],\qquad
  C_{01}=[B_0,N_A,c_B],\qquad
  C_{11}=[B_0,c_A,c_B].
  \label{eq:attack_composition}
\end{equation}
对$u,v\in\{0,1\}$，记受控上下文$C_{uv}$触发目标答案的语义判定结果为$Y_{uv}=J(q,a^*,G_{\mathrm{shadow}}(q,C_{uv}))\in\{0,1\}$，确定性解码下的\textbf{受控组合生成判据}定义为$\mathcal V_{\mathrm{comp}}(x)=\mathbb I[Y_{11}=1\land Y_{10}=0\land Y_{01}=0\land Y_{00}=0]$。在全文重切分后的端到端评估中，同时独立统计自然Top-$K$上下文$R_K(q;\mathcal C_v^{\phi_v}(x))$的目标命中率及单块消融表现。针对由离散分块与生成解码构成的端到端目标$F(x)$，给定正则权重$\lambda_{\mathrm{ppl}}\ge 0$，本研究将单源跨块协同投毒构造形式化为影子分块视图分布$\Pi_\Phi$下的受限代理优化问题：
\begin{equation}
  \max_{x\in\mathcal X}\ \mathbb E_{\phi\sim\Pi_\Phi}\big[Z_\phi(x)\big]-\lambda_{\mathrm{ppl}}\mathcal L_{\mathrm{ppl}}(x),\qquad
  \text{s.t.}\quad \mathcal V_{\mathrm{comp}}(x)=1,\;\mathcal M_{\mathrm{lex}}(x)=1.
  \label{eq:attack_objective}
\end{equation}
由于直接在逻辑正文上执行基于梯度的离散词元替换\cite{ebrahimi-etal-2018-hotflip,zou2023universal}会破坏跨块推理链的语法连贯性与逻辑闭环\cite{liu2024autodan}，本研究提出\textbf{“受控组合验证先行、分块感知检索优化后置”的两阶段解耦求解策略}：阶段一在相同背景$B_0$的等容量受控上下文中构造并冻结满足$\mathcal V_{\mathrm{comp}}(x)=1$的双块核心载荷与外围语义垫片；阶段二在冻结核心载荷的前提下，仅在外围语义垫片的自然句边界处优化定长检索触发器，并在组装完整文档后经重切分重新复核$Z_\phi(x)$与$\mathcal V_{\mathrm{comp}}(x)$，整体框架如\autoref{fig:attack_framework}所示。

\subsubsection{阶段一：受控竞争上下文下的双块载荷与语义垫片构造}

\textbf{1) 两步段落槽位锚定与跨块几何隔离。}为使两个互补核心载荷在切分后分别落入不同文本块，将干净源文档$D$按自然段解析为$\{p_1,\dots,p_M\}$，记第$k$段末尾的累积词元偏移为$t_k$，全文总长为$t_M$；影子分块配置集$\Phi_{\mathrm{shadow}}$覆盖的最大窗口容量为$K_{\max}=\max_{\phi\in\Phi_{\mathrm{shadow}}}K_{\mathrm{size}}(\phi)$。槽位选择融合段落预筛与组装后跨度复核：给定安全隔离系数$\gamma\ge 1.0$与预估单段前置垫片及核心跨度上界$L_{\mathrm{est}}\ge 0$，候选段落对$(i,j)$须同时满足源文档段落间距预筛条件$t_j-t_i\ge\gamma K_{\max}+L_{\mathrm{est}}$，以及植入角色段$P_A,P_B$组装为$D_{\mathrm{adv}}$后的核心载荷实际跨度间距约束，由此构成可行槽位集$\mathcal F_{\mathrm{slot}}$：
\begin{equation}
\begin{aligned}
  (k_A,k_B)&=\arg\min_{(i,j)\in\mathcal F_{\mathrm{slot}}}\Big(\big|t_i-\rho_A\,t_M\big|+\big|t_j-\rho_B\,t_M\big|\Big),\\
  \mathcal F_{\mathrm{slot}}&=\Big\{(i,j):1\le i<j\le M,\;t_j-t_i\ge\gamma K_{\max}+L_{\mathrm{est}},\;\operatorname{start}_{D_{\mathrm{adv}}}(\mathcal P_B)-\operatorname{end}_{D_{\mathrm{adv}}}(\mathcal P_A)\ge\gamma K_{\max}\Big\},
\end{aligned}
  \label{eq:slot_anchor}
\end{equation}
其中$\rho_A=0.33,\rho_B=0.66$为目标相对分位点。由于容量$K_{\mathrm{size}}\le K_{\max}$的单个分块窗口至多覆盖连续$K_{\max}$个词元，式\eqref{eq:slot_anchor}保证任一分块窗口均无法同时完整包含$\mathcal P_A$与$\mathcal P_B$，从几何上确保双角色块的跨块分离。

\textbf{2) 规则—实例角色解耦与防切块语义垫片封装。}每个植入段落$P_j$采用“前置语义垫片$\mathcal S_j^{\mathrm{pre}}$ + 核心逻辑载荷$\mathcal P_j$ + 后置语义垫片$\mathcal S_j^{\mathrm{post}}$”的三段式嵌套结构：
\begin{equation}
  P_j=\mathcal S_j^{\mathrm{pre}}\oplus\mathcal P_j\oplus\mathcal S_j^{\mathrm{post}},\qquad j\in\{A,B\},
  \label{eq:payload_layout}
\end{equation}
其中$\oplus$表示文本拼接。各组件的具体构造机理如下：
\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item \textbf{核心载荷$\mathcal P_A$}：作为规则注入块，定义一套符合源文档领域语境的分类标准或属性映射准则，并以百科勘误的客观口吻指出早期记录隐含的原始答案$y_{\mathrm{true}}$已在新标准下按分类代号重新核定，从而降低生成模型对$y_{\mathrm{true}}$的先验采信度，同时将文本内容限定在抽象规则层，与具体查询实体保持分离。
  \item \textbf{核心载荷$\mathcal P_B$}：作为实例桥接块，陈述目标查询主体在权威档案记录中对应的特定规则代号，建立查询实体与规则代号之间的实例关联，使生成模型在同时读取$\mathcal P_A$与$\mathcal P_B$时通过三段论推理导出目标答案$a^*$。
  \item \textbf{外围语义垫片$\mathcal S_j^{\mathrm{pre}},\mathcal S_j^{\mathrm{post}}$}：由$2\sim 3$句与槽位$p_{k_j}$前后文主题衔接的自然背景句构成，一方面充当缓冲带以降低分块滑动窗口截断中间核心载荷$\mathcal P_j$的概率，另一方面在自然句边界处为阶段二的检索触发器提供合法插槽。
\end{itemize}

\textbf{3) 受控竞争上下文下的组合可行性检验与双块共召回条件。}从除载体文档外的影子背景检索库$\mathcal C_{-d}^s$中提取查询$q$按影子得分降序排列的Top-$K$干净文本块$C_{\mathrm{clean}}^{-d}(q)=\{d_{(1)},\dots,d_{(K)}\}$，取前$K-2$个高分块固定为共同背景$B_0=[d_{(1)},\dots,d_{(K-2)}]$，结合中性替代块$N_A,N_B$按式\eqref{eq:attack_composition}构造四组等容量受控上下文$C_{00},C_{10},C_{01},C_{11}$。在检索排名条件方面，要使两个独立的同源角色块$c_A^{(\phi)},c_B^{(\phi)}$同时挤入容量为$K$的检索结果并占据两个名额，排在较弱角色块之前的干净背景块至多只能有$K-2$个；记背景检索结果中第$K-1$名干净块的得分为竞争阈值$\tau_q=s(q,d_{(K-1)})$，则双块共同进入Top-$K$等价于较弱角色块的检索得分突破$\tau_q$：
\begin{equation}
  \big\{c_A^{(\phi)},c_B^{(\phi)}\big\}\subseteq R_K\big(q;\mathcal C_v^\phi(x)\big)
  \iff
  \min_{j\in\{A,B\}} s\big(q,c_j^{(\phi)}\big)>\tau_q.
  \label{eq:corecall_equiv}
\end{equation}
在阶段一中，生成可行性判据$\mathcal V_{\mathrm{comp}}(q)$专门在相同背景$B_0$下检验单块弱毒性与双块协同诱导性：
\begin{equation}
  \begin{aligned}
    \mathcal V_{\mathrm{comp}}(q)=\mathbb I\Big[
    &J\big(q,a^*,G_{\mathrm{shadow}}(q,C_{00})\big)=0\;\land\;
    \bigwedge_{uv\in\{10,01\}}J\big(q,a^*,G_{\mathrm{shadow}}(q,C_{uv})\big)=0 \\
    &\land\; J\big(q,a^*,G_{\mathrm{shadow}}(q,C_{11})\big)=1\Big].
  \end{aligned}
  \label{eq:gen_gate}
\end{equation}
当$\mathcal V_{\mathrm{comp}}(q)=0$时，提议模型按分项判据定向修正载荷：若$Y_{10}=1$或$Y_{01}=1$，则收窄对应角色块的信息外延以消除单块独立触发；若$Y_{11}=0$，则强化$\mathcal P_A$中勘误规则的表述清晰度及$\mathcal P_A,\mathcal P_B$之间的代号绑定。通过验证后冻结$(\mathcal P_A,\mathcal P_B)$与外围垫片，转入阶段二执行分块感知的检索触发器优化。

\subsubsection{阶段二：分块感知的检索触发器优化}

\textbf{1) 多副本触发器对称布局与窗口覆盖机制。}在冻结核心载荷的前提下，于前后外围语义垫片的自然句边界处对称插入$R=2$个定长触发器词元序列$\mathbf t_j=(t_{j,1},\dots,t_{j,L_{\mathrm{trig}}})$，默认长度$L_{\mathrm{trig}}=10$：
\begin{equation}
  P_j(\mathbf t_j)=s_{j,1}^{\mathrm{pre}}\oplus\mathbf t_j^{(1)}\oplus s_{j,2}^{\mathrm{pre}}\oplus\mathcal P_j\oplus s_{j,1}^{\mathrm{post}}\oplus\mathbf t_j^{(2)}\oplus s_{j,2}^{\mathrm{post}}.
  \label{eq:trigger_layout}
\end{equation}
由于前后两个触发器副本被中间的核心载荷$\mathcal P_j$隔开，当三者与中间垫片的总包络跨度不超过分块容量$K_{\mathrm{size}}$时，任何完整包含核心载荷$\mathcal P_j$的分块窗口必然至少完整包含其中一个触发器副本，从而在未知切分相位下维持核心载荷与检索触发信号的同块共现。

\textbf{2) 分块鲁棒检索损失。}设影子分块视图集合为$\Phi_{\mathrm{shadow}}=\{\phi_m\}_{m=1}^M$，单视图配置$\phi_m=(K_{\mathrm{size},m},O_m,\xi_m)$包含窗口容量$K_{\mathrm{size},m}$、重叠词元数$O_m$与切分起始相位$\xi_m$。记角色段$j$中核心载荷$\mathcal P_j$、第$r$个触发器副本及二者之间垫片构成的包络跨度词元长度为$n^{(r)}>0$；当$I_j(\phi)=1$时，主块$c_j^{(\phi)}$实际保留的该包络词元长度记为$n^{(r)}(\phi)$。定义角色$j$在视图$\phi$下的\textbf{存活权重}$w_j(\phi)$与\textbf{凹幂次截断惩罚函数}$h_p(w)$为：
\begin{equation}
  w_j(\phi)=\begin{cases}
    \max_{r\in\{1,\dots,R\}}\dfrac{n^{(r)}(\phi)}{n^{(r)}}\in[0,1], & I_j(\phi)=1,\\
    0, & I_j(\phi)=0,
  \end{cases}\qquad
  h_p(w)=1-w^p\quad(p>1).
  \label{eq:survival_weight}
\end{equation}
在$(0,1)$区间上，$h_p(w)$满足$h_p''(w)=-p(p-1)w^{p-2}<0$，能够对发生边界截断的视图施加非线性惩罚。以$\phi_0\in\Phi_{\mathrm{shadow}}$为参考分块视图，定义角色$j$在影子视图集$\Phi_{\mathrm{shadow}}$上的\textbf{分块鲁棒检索损失}$\mathcal L_{\mathrm{rob}}(\mathbf t_j)$为：
\begin{equation}
\begin{aligned}
  \mathcal L_{\mathrm{rob}}(\mathbf t_j)&=
  \frac{1}{M}\sum_{\phi\in\Phi_{\mathrm{shadow}}}\Big[
  w_j(\phi)\,\ell_{\mathrm{ret}}\big(c_j^{(\phi)}(\mathbf t_j)\big)
  +\lambda_{\mathrm{trunc}}\big(1-w_j(\phi)^p\big)
  +\lambda_{\mathrm{var}}\big|s\big(q,c_j^{(\phi_0)}(\mathbf t_j)\big)-s\big(q,c_j^{(\phi)}(\mathbf t_j)\big)\big|\Big],\\
  \ell_{\mathrm{ret}}(c)&=\operatorname{softplus}\!\left(\frac{\tau_q+\delta-s(q,c)}{T}\right),
\end{aligned}
  \label{eq:chunk_rob_loss}
\end{equation}
其中$\delta>0$为得分裕度，$T>0$为平滑温度，$\lambda_{\mathrm{trunc}},\lambda_{\mathrm{var}}\ge 0$分别为截断惩罚权重与跨视图得分波动权重。

\textbf{3) 局部流畅度约束与词法检查器。}为约束梯度搜索生成自然可读的触发器并抑制边界处的困惑度异常\cite{alon2023detecting,jain2023baseline}，本研究截取每个触发器副本及其紧邻的前后各一个完整句子构成局部三句窗口$W_j^{(r)}=s_{j,1}^{(r)}\oplus\mathbf t_j^{(r)}\oplus s_{j,2}^{(r)}$，利用冻结的本地因果语言模型计算平均负对数似然作为局部流畅度损失$\mathcal L_{\mathrm{ppl}}(\mathbf t_j)$。同时，采用Doc2Query\cite{nogueira2019document}生成的伪查询初始化触发器序列$\mathbf t=(t_1,\dots,t_{L_{\mathrm{trig}}})$，并定义序列级词法检查器$\mathcal M_{\mathrm{lex}}(\mathbf t;q,a^*,y_{\mathrm{true}})\in\{0,1\}$，要求候选序列满足以下三项准入条件：
\begin{enumerate}[label=(\alph*),leftmargin=2.2em,itemsep=0pt]
  \item 序列中每个词元均为完整ASCII英文词元，且任意相邻位置词元满足$t_i\neq t_{i+1}$；
  \item 完整序列$\mathbf t$与查询$q$的最长公共连续词组长度小于2，避免直接复读查询原句；
  \item 序列中不含任何属于$a^*$或$y_{\mathrm{true}}$的词元，维持单块弱毒性。
\end{enumerate}

\textbf{4) 双块交替坐标梯度搜索与重切分复核。}求解过程如算法\ref{alg:attack}所示。每轮迭代优先选择当前损失较大的瓶颈角色块$j^\star=\arg\max_{j\in\{A,B\}}\mathcal L_{\mathrm{rob}}(\mathbf t_j)$，执行反向传播获取触发器各位置词元嵌入梯度，在满足$\mathcal M_{\mathrm{lex}}(\mathbf t_{j^\star}[i\to v];q,a^*,y_{\mathrm{true}})=1$的词表子集上按一阶泰勒内积得分筛选前$B_{\mathrm{cand}}$个候选替换\cite{ebrahimi-etal-2018-hotflip,zou2023universal}：
\begin{equation}
  \mathbf g_i=\nabla_{e_{t_i}}\mathcal L_{\mathrm{rob}}(\mathbf t_{j^\star}),\qquad
  \Delta_{i,v}=-\mathbf g_i^\top(e_v-e_{t_i}),
  \label{eq:first_order}
\end{equation}
随后在影子分块视图集上批量前向计算精确总损失$\mathcal L_{\mathrm{rob}}+\lambda_{\mathrm{ppl}}\mathcal L_{\mathrm{ppl}}$，贪心采纳使总损失下降的最优词元替换。迭代结束后将优化后的$P_A(\mathbf t_A),P_B(\mathbf t_B)$植入源文档组装为$D_{\mathrm{adv}}$，并在影子视图集上执行全文重切分，复核有效联合召回事件$Z_\phi(D_{\mathrm{adv}})$与受控组合生成判据$\mathcal V_{\mathrm{comp}}(D_{\mathrm{adv}})$。

\begin{algorithm}[htbp]
  \small
  \caption{Two-Stage Cross-Chunk Payload Construction}
  \label{alg:attack}
  \KwIn{query $q$, answers $y_{\mathrm{true}},a^*$, carrier document $D$, clean Top-$K$ chunks $\{d_{(1)},\dots,d_{(K)}\}$ with threshold $\tau_q=s(q,d_{(K-1)})$, shadow chunkers $\Phi_{\mathrm{shadow}}$, shadow generator $G_{\mathrm{shadow}}$}
  \KwOut{poisoned source document $D_{\mathrm{adv}}$}
  \tcp{Stage 1: Controlled dual-chunk payload and semantic shim synthesis}
  Select paragraph slots $(k_A,k_B)\in\mathcal F_{\mathrm{slot}}$ on $D$ via Eq.~\eqref{eq:slot_anchor}\tcp*[r]{cross-chunk geometric separation}
  Initialize $(\mathcal P_A,\mathcal P_B,\mathcal S_A,\mathcal S_B)\leftarrow\operatorname{PROPOSE}(q,y_{\mathrm{true}},a^*,D;G_{\mathrm{shadow}})$\;
  \For{$r\leftarrow1$ \KwTo $T_{\mathrm{gen}}$}{
    $c_j\leftarrow\mathcal S_j^{\mathrm{pre}}\oplus\mathcal P_j\oplus\mathcal S_j^{\mathrm{post}}$ for $j\in\{A,B\}$;\quad Construct $C_{00},C_{10},C_{01},C_{11}$ via Eq.~\eqref{eq:attack_composition}\;
    \lIf{$\mathcal V_{\mathrm{comp}}(q)=1$ \textnormal{in Eq.~\eqref{eq:gen_gate}}}{\textbf{break}}\tcp*[r]{single-chunk benign, dual-chunk effective}
    $(\mathcal P_A,\mathcal P_B,\mathcal S_A,\mathcal S_B)\leftarrow\operatorname{REVISE}(\mathcal P_A,\mathcal P_B,\mathcal S_A,\mathcal S_B;G_{\mathrm{shadow}})$\;
  }
  Freeze core payloads $(\mathcal P_A,\mathcal P_B)$ and semantic shims $(\mathcal S_A,\mathcal S_B)$\;
  \tcp{Stage 2: Chunking-aware alternating coordinate trigger optimization}
  Initialize triggers $\mathbf t_A,\mathbf t_B$ via Doc2Query s.t.\ $\mathcal M_{\mathrm{lex}}(\mathbf t_j;q,a^*,y_{\mathrm{true}})=1$\;
  \For{$t\leftarrow1$ \KwTo $T_{\mathrm{ret}}$}{
    $j^\star\leftarrow\arg\max_{j\in\{A,B\}}\mathcal L_{\mathrm{rob}}(\mathbf t_j)$\tcp*[r]{prioritize bottleneck role chunk}
    Compute token gradients $\mathbf g_i=\nabla_{e_{t_i}}\mathcal L_{\mathrm{rob}}(\mathbf t_{j^\star})$ for $i=1,\dots,L_{\mathrm{trig}}$ via Eq.~\eqref{eq:first_order}\;
    $\mathcal B\leftarrow\operatorname{TOP}_{B_{\mathrm{cand}}}\big\{(i,v):\Delta_{i,v}=-\mathbf g_i^\top(e_v-e_{t_i}),\ \mathcal M_{\mathrm{lex}}(\mathbf t_{j^\star}[i\to v];q,a^*,y_{\mathrm{true}})=1\big\}$\;
    $(i^\star,v^\star)\leftarrow\arg\min_{(i,v)\in\mathcal B}\big[\mathcal L_{\mathrm{rob}}+\lambda_{\mathrm{ppl}}\mathcal L_{\mathrm{ppl}}\big](\mathbf t_{j^\star}[i\to v])$\;

  }
  $D_{\mathrm{adv}}\leftarrow\operatorname{ASSEMBLE}(D, k_A, P_A(\mathbf t_A), k_B, P_B(\mathbf t_B))$\tcp*[r]{verify $Z_\phi(D_{\mathrm{adv}})$ after re-chunking}
  \Return{$D_{\mathrm{adv}}$}\;
\end{algorithm}

\subsection{研究点二：基于检索上下文表征分析的检索增强生成安全防御方法}

\subsubsection{研究内容与问题形式化}

研究点一表明，组合式投毒中的每个攻击块都可以保持较高的语义合理性与检索相关性，攻击效果在多个同源文本块共同进入上下文后才显现；与此同时，检索操纵、单文档投毒与分布式投毒等攻击在单块异常、集合分布与跨块结构上呈现差异化的特征形态。针对这一情况，本研究的防御目标是在多类投毒攻击下降低攻击成功率，同时保留正常多跳问答所需的桥接证据，并在此基础上控制额外延迟与计算开销。

防御者将防御机制部署在服务端检索阶段之后、生成阶段之前，可读取查询$q$、Top-$K$候选文本块$\mathcal C_q=\{c_1,\dots,c_K\}$、各块的稠密向量$z_i$与BM25稀疏向量$v_i$，以及摄入系统记录的来源标识$z_{\mathrm{doc}}(c_i)$与块内起止偏移。来源标识以系统元数据为准，文本内容中声称的来源仅作为普通文本处理；防御决策仅依赖在线检索上下文与离线干净语料统计量，每个查询至多调用一次本地结构化判别模型。设$\mathcal A$为攻击方法族，$\mathcal Q_{\mathrm{clean}}$为干净查询集，$\pi$为防御策略，$\pi(\mathcal C_q)$为其输出的净化上下文，则防御侧的形式化约束框架可写为：
\begin{equation}
\begin{aligned}
  \pi^*=\arg\min_{\pi}\ &\max_{a\in\mathcal A}\ \mathrm{ASR}_a(\pi)\\
  \text{s.t.}\quad &\mathrm{ACC}_{\mathrm{clean}}(\pi)\ge\mathrm{ACC}_{\mathrm{clean}}(\mathrm{id})-\epsilon_{\mathrm{acc}},\qquad
  \mathrm{BR}(\pi)\ge\beta_{\mathrm{br}},\qquad
  \mathbb E[T(\pi)]\le T_{\max},
\end{aligned}
  \label{eq:defense_objective}
\end{equation}
其中$\mathrm{ASR}_a(\pi)$为攻击$a$下经防御后的攻击成功率，$\mathrm{ACC}_{\mathrm{clean}}(\pi)$与$\mathrm{ACC}_{\mathrm{clean}}(\mathrm{id})$分别为干净查询集在启用防御策略$\pi$与基线无防御策略$\mathrm{id}$下的回答准确率，$\epsilon_{\mathrm{acc}}$为允许的准确率损失，$\mathrm{BR}(\pi)$为正常多跳问答中桥接证据的保留率，$\beta_{\mathrm{br}}$为其下限，$T(\pi)$为单查询的端到端防御延迟，$T_{\max}$为延迟预算。

为同时满足式\eqref{eq:defense_objective}中的低攻击成功率、高多跳桥接保留率与低延迟约束，本研究构建\textbf{“统计—图结构初筛+按需结构化LLM判定”的双阶段级联机制}：阶段一通过单块检索统计特征建立高危/可疑/可信的初筛标签，并结合上下文实体—命题图提取跨块组合告警；阶段二仅在待审触发事件$E_{\mathrm{esc}}(q)=\{\mathcal S_{\mathrm{judge}}(q)\neq\emptyset\}$成立时按需调用一次结构化判别核查并剥离投毒块。设阶段一谱统计、子窗编码与构图耗时为$T_{\mathrm{stat}},T_{\mathrm{sub}},T_{\mathrm{graph}}$，阶段二判别耗时为$T_{\mathrm{judge}}$，二阶段审查触发率为$p_{\mathrm{esc}}=\Pr(E_{\mathrm{esc}}(q))$，则单查询期望防御延迟分解为：
\begin{equation}
  \mathbb E\big[T(\pi)\big]=\mathbb E\big[T_{\mathrm{stat}}+T_{\mathrm{sub}}+T_{\mathrm{graph}}\big]+p_{\mathrm{esc}}\cdot\mathbb E\big[T_{\mathrm{judge}}\mid E_{\mathrm{esc}}(q)\big],
  \label{eq:latency_decomp}
\end{equation}
整体框架如\autoref{fig:defense_framework}所示。

\subsubsection{检索统计特征与查询级分位校准}

在RAG对抗投毒攻击中，攻击文本为强行挤入Top-$K$检索结果并夹带额外载荷，往往在稠密向量流形与稀疏词项子空间上产生经验可分的分布偏移\cite{mahalanobis1936generalized,lee2018simple}。为消除特征参数拟合与阈值标定之间的同源过拟合偏差，离线阶段按独立查询与源文档将干净开发数据划分为互不相交的\textbf{特征拟合集$\mathcal D_{\mathrm{fit}}$}与\textbf{查询级检索后校准集$\mathcal D_{\mathrm{cal}}$}：在$\mathcal D_{\mathrm{fit}}$上预计算稠密嵌入均值$\mu$、Ledoit-Wolf线性收缩协方差矩阵特征分解$\Sigma_\beta=(1-\beta)S+\beta\frac{\operatorname{tr}(S)}{d}I_d=V\operatorname{diag}(\tilde\lambda_1,\dots,\tilde\lambda_d)V^\top$\cite{ledoit2004well}，并对干净语料的BM25词项矩阵\cite{robertson2009probabilistic}执行截断奇异值分解\cite{deerwester1990indexing}提取前$r_{\mathrm{svd}}$维主子空间正交基$V_{\mathrm{svd}}$。在线阶段，对每个候选文本块$c_i\in\mathcal C_q$提取以下四项经验检索统计特征：
\begin{subequations}\label{eq:dynamics_features}
\begin{enumerate}[label=\arabic*.,leftmargin=1.8em,itemsep=2pt]
  \item \textbf{稠密低方差尾谱马氏距离$s_{\mathrm{tail}}(z_i)$}：以低方差尾谱方向$m>r_0$上的特征值倒数加权投影平方和度量候选向量相对干净中心$\mu$的尾谱偏离程度：
  \begin{equation}
    s_{\mathrm{tail}}(z_i)=\sum_{m=r_0+1}^{d}\frac{\big[(z_i-\mu)^\top V_{:,m}\big]^2}{\tilde\lambda_m}.
    \label{eq:feat_tail}
  \end{equation}
  \item \textbf{稀疏词项子空间截断残差比$\tau_{\mathrm{svd}}(c_i)$}：通过计算候选块BM25向量$v_i$投影至干净主子空间$V_{\mathrm{svd}}$后在正交补空间上的能量占比，捕获偏离常见词项共现结构的异常词元组合：
  \begin{equation}
    \tau_{\mathrm{svd}}(c_i)=1-\frac{\|v_i^\top V_{\mathrm{svd}}\|_2^2}{\|v_i\|_2^2+\epsilon}.
    \label{eq:feat_svd}
  \end{equation}
  \item \textbf{候选池内查询切法向散度比$\rho_{\mathrm{tan}}(c_i;\mathcal C_q)$}：设归一化查询向量为$\hat x$，当前Top-$K$候选池$\mathcal C_q$单位向量的几何中位数为$\hat c_{\mathrm{pool}}$。将块向量相对池中心的位移$\Delta u_i=\hat z_i-\hat c_{\mathrm{pool}}$正交分解为沿查询方向的切向分量$t_i=\hat x^\top\Delta u_i$与垂直于查询方向的法向分量$o_i=\|\Delta u_i-t_i\hat x\|_2$，以二者之比度量候选块在当前检索池内偏离查询主轴的相对离散程度：
  \begin{equation}
    \rho_{\mathrm{tan}}(c_i;\mathcal C_q)=\frac{o_i}{|t_i|+\epsilon_0}.
    \label{eq:feat_tan}
  \end{equation}
  \item \textbf{块内首尾子窗余弦漂移$d_{\mathrm{intra}}(c_i)$}：将文本块$c_i$按词元序列均分为前后两个子窗$c_i^{(1)}$与$c_i^{(2)}$，以两子窗编码向量的余弦距离度量在外围垫片句边界插入触发器或异质后缀引起的局部语义折角：
  \begin{equation}
    d_{\mathrm{intra}}(c_i)=1-\cos\big(f(c_i^{(1)}),f(c_i^{(2)})\big).
    \label{eq:feat_intra}
  \end{equation}
\end{enumerate}
\end{subequations}

记拟合集$\mathcal D_{\mathrm{fit}}$在第$r\in\{1,2,3,4\}$维特征上的均值与标准差为$\mu_{f,r},\sigma_{f,r}$，逐维标准化为$\tilde f_{i,r}=(f_{i,r}-\mu_{f,r})/\sigma_{f,r}$以构成$\tilde{\mathbf f}_i$。在$\mathcal D_{\mathrm{fit}}$干净块上施加自监督随机边界词元替换构造合成扰动负样本，训练逻辑回归并冻结权重$\mathbf w$，得到单块检索统计异常度$A(q,c_i)=\mathbf w^\top\tilde{\mathbf f}_i$。

\textbf{查询级最大异常度分位校准与三向分流机制。}同一查询检索出的$K$个候选块共享查询上下文与池中心$\hat c_{\mathrm{pool}}$，其异常得分在查询内部耦合而在独立查询之间满足可交换性。据此，本研究以\textbf{独立查询}作为校准交换单元：在冻结全部特征与评分参数后，于校准集$\mathcal D_{\mathrm{cal}}$的$n$条可交换干净查询$\{q_1,\dots,q_n\}$上分别计算每条查询的候选池最大异常度$M_j=\max_{1\le i\le K}A(q_j,c_{j,i})$，并按升序排列为次序统计量$M_{(1)}\le M_{(2)}\le\dots\le M_{(n)}$。对给定的查询级统计误警预算$\alpha\in(0,1)$，由可交换非符合性分位数的秩均匀性质\cite{vovk2005algorithmic,angelopoulos2023conformal}设定校准阈值$\tau_\alpha$，即可在无需先验分布假设的条件下约束新干净查询$q_{\mathrm{new}}$的统计误警率：
\begin{equation}
  \tau_\alpha=M_{\left(\lceil(n+1)(1-\alpha)\rceil\right)},\qquad
  \Pr\Big(\exists 1\le i\le K:A(q_{\mathrm{new}},c_{\mathrm{new},i})>\tau_\alpha\Big)=\Pr\big(M_{\mathrm{new}}>\tau_\alpha\big)\le\alpha.
  \label{eq:quantile_calib}
\end{equation}
设定两级查询级误警预算$\alpha_{\mathrm{high}}<\alpha_{\mathrm{low}}$，按式\eqref{eq:quantile_calib}确定高危阈值$\tau_{\mathrm{high}}=\tau_{\alpha_{\mathrm{high}}}$与可疑阈值$\tau_{\mathrm{low}}=\tau_{\alpha_{\mathrm{low}}}$，建立\textbf{三向分流机制}：当$A(q,c_i)>\tau_{\mathrm{high}}$时，归入\textbf{高危剔除区（红区）}直接剪除；当$\tau_{\mathrm{low}}<A(q,c_i)\le\tau_{\mathrm{high}}$时，归入\textbf{存疑待审区（灰区）}并作为存疑待审块送入阶段二待审集$\mathcal S_{\mathrm{judge}}$；当$A(q,c_i)\le\tau_{\mathrm{low}}$时，归入\textbf{可信放行区（绿区）}列为暂可信块，继续接受跨块结构检验。

\subsubsection{上下文实体—命题图与结构化LLM判定}

\textbf{1) 临时上下文实体—命题图构建与结构告警。}在研究点一等组合式投毒下，单个文本块的语言表述与统计特征趋近正常文本，单块异常度$A(q,c_i)$可能满足$A(q,c_i)\le\tau_{\mathrm{low}}$\cite{zheng2025grada,zhou2025trustrag}。为此，本研究在经统计通道剪除高危块后的存活集合$\mathcal C_{\mathrm{surv}}$上，在线构建临时上下文实体—命题有向多重图$\mathcal G_q=(\mathcal V_q,\mathcal E_q)$：
\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item \textbf{节点集$\mathcal V_q$}：采用预训练英语NLP流水线spaCy\cite{honnibal2020spacy}执行词性标注、命名实体识别与名词短语识别，并结合正则表达式匹配技术代号、分类编号等结构化标识，提取各存活文本块$c_i\in\mathcal C_{\mathrm{surv}}$中的实体与属性节点构成$\mathcal V_q=\bigcup_{c_i\in\mathcal C_{\mathrm{surv}}}\mathcal E(c_i)$。
  \item \textbf{有向多重边集$\mathcal E_q$}：采用Stanford OpenIE\cite{angeli2015leveraging}抽取文本块中的主语—关系—宾语三元组$(u,r,v)$，结合依存句法与否定触发词规则判定命题极性$\mathrm{pol}\in\{+1,-1\}$，构成命题有向边$e=(u,v,r,\mathrm{pol})\in\mathcal E_q$，每条边同时绑定所属文本块标识$\mathrm{chunk}(e)=c_i$及源文档标识$\mathrm{doc}(e)=z_{\mathrm{doc}}(c_i)$。
\end{itemize}

基于$\mathcal G_q$与文档溯源元数据，对存活集合$\mathcal C_{\mathrm{surv}}$中满足$i<j$的任意文本块对$(c_i,c_j)$定义三项成对结构升级指示器：
\begin{subequations}\label{eq:struct_evidence}
\begin{align}
  \Phi_{\mathrm{prov}}(c_i,c_j)&=\mathbb I\Big[z_{\mathrm{doc}}(c_i)=z_{\mathrm{doc}}(c_j)\;\land\;\operatorname{gap}(c_i,c_j)\ge\tau_{\mathrm{spacer}}\Big], \label{eq:phi_prov}\\
  \Phi_{\mathrm{bridge}}(c_i,c_j)&=\mathbb I\Big[\exists u\in\big(\mathcal E(c_i)\cap\mathcal E(c_j)\big)\setminus\mathcal E(q):\mathrm{DF}(u)\le\tau_{\mathrm{df}}\Big], \label{eq:phi_bridge}\\
  \Phi_{\mathrm{conflict}}(c_i,c_j)&=\mathbb I\Big[\exists e_1\in\mathcal E_q(c_i),\,e_2\in\mathcal E_q(c_j):(u_1=u_2\land r_1=r_2)\;\land\;(\mathrm{pol}_1\neq\mathrm{pol}_2\lor v_1\perp v_2)\Big], \label{eq:phi_conflict}
\end{align}
\end{subequations}
其中$\operatorname{gap}(c_i,c_j)$为同源两块在源文档中的词元跨度间隔；$\mathrm{DF}(u)$为查询外共享桥接实体$u\in(\mathcal E(c_i)\cap\mathcal E(c_j))\setminus\mathcal E(q)$在全语料库中的文档频率\cite{zhang2026inceptionrag}；$v_1\perp v_2$表示两块对同一主语和单值属性关系给出了互斥的宾语取值。由于正常长文档多跳问答同样可能召回同源远距段落或包含桥接实体\cite{yin2026rade}，上述三项结构指示器专门作为将相关文本块对加入待审集$\mathcal S_{\mathrm{judge}}$的升级信号。在统计通道误警率受$\alpha_{\mathrm{low}}$控制的前提下，记干净查询分布上三类结构事件的触发概率分别为$\rho_{\mathrm{prov}}^{\mathrm{clean}},\rho_{\mathrm{bridge}}^{\mathrm{clean}},\rho_{\mathrm{conflict}}^{\mathrm{clean}}$，由并集界可得干净查询的二阶段审查触发率上界：
\begin{equation}
  p_{\mathrm{esc}}=\Pr\big(E_{\mathrm{esc}}(q_{\mathrm{new}})\big)\le\min\Big\{1,\;\alpha_{\mathrm{low}}+\rho_{\mathrm{prov}}^{\mathrm{clean}}+\rho_{\mathrm{bridge}}^{\mathrm{clean}}+\rho_{\mathrm{conflict}}^{\mathrm{clean}}\Big\}.
  \label{eq:pesc_bound}
\end{equation}

\textbf{2) 异源参照锚点选择与结构化LLM判定。}当$\mathcal S_{\mathrm{judge}}\neq\emptyset$时，系统从暂可信块候选池$\mathcal C_{\mathrm{clean\_cand}}=\{c\in\mathcal C_{\mathrm{surv}}\setminus\mathcal S_{\mathrm{judge}}:z_{\mathrm{doc}}(c)\notin z_{\mathrm{doc}}(\mathcal S_{\mathrm{judge}})\}$中选取检索得分最高的文本块作为异源参照锚点$c_{\mathrm{anchor}}$：
\begin{equation}
  c_{\mathrm{anchor}}=\begin{cases}
    \arg\max_{c\in\mathcal C_{\mathrm{clean\_cand}}} s(q,c), & \mathcal C_{\mathrm{clean\_cand}}\neq\emptyset,\\
    \varnothing, & \mathcal C_{\mathrm{clean\_cand}}=\emptyset.
  \end{cases}
  \label{eq:anchor}
\end{equation}
式\eqref{eq:anchor}通过文档来源隔离条件$z_{\mathrm{doc}}(c)\notin z_{\mathrm{doc}}(\mathcal S_{\mathrm{judge}})$确保参照锚点来自独立于待审块的外部文档，为阶段二提供跨源比对基准；当$\mathcal C_{\mathrm{clean\_cand}}=\emptyset$时，结构化判别模型直接依据待审块自身的命题修辞与跨块代号绑定结构执行独立裁决。随后，系统将查询$q$、参照锚点$c_{\mathrm{anchor}}$、存疑待审块集合$\mathcal S_{\mathrm{judge}}$及其在阶段一触发的结构告警组装为结构化提示词，调用一次本地结构化判别模型$\mathcal M$\cite{zhang2025traceback,chiang2023judging}依次执行三步核查：
\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item \textbf{第一步：细粒度命题与修辞意图分解}：提取每个存疑待审块的核心主—谓—宾命题，识别是否存在“点名原始常识答案后宣称其已失效或按新标准重分类”的嵌入式勘误修辞，或伪造系统权威指令标记；
  \item \textbf{第二步：跨块桥接与代号绑定审计}：针对触发$\Phi_{\mathrm{prov}}$或$\Phi_{\mathrm{bridge}}$的成对文本块，联合审查其中一块是否定义了特定分类代号或属性映射规则，且另一块将查询主体绑定至该代号以构成三段论逻辑拼接；
  \item \textbf{第三步：跨源锚点一致性裁决}：结合异源参照锚点$c_{\mathrm{anchor}}$进行交叉比对，输出确认参与单点篡改或跨块协同投毒的恶意文本块集合$\mathcal U\subseteq\mathcal S_{\mathrm{judge}}$，从存活上下文$\mathcal C_{\mathrm{surv}}$中剥离$\mathcal U$并按检索排名保留前$m$个净化文本块交付生成模型。
\end{itemize}

完整流程如算法\ref{alg:defense}所示。

\begin{algorithm}[htbp]
  \small
  \caption{Cascaded Statistical--Structural Triage and Structured Adjudication}
  \label{alg:defense}
  \KwIn{query $q$, retrieved Top-$K$ chunks $\mathcal C_q=\{c_1,\dots,c_K\}$, calibrated thresholds $\tau_{\mathrm{low}},\tau_{\mathrm{high}},\tau_{\mathrm{spacer}},\tau_{\mathrm{df}}$, structured discriminative model $\mathcal M$, target context size $m$}
  \KwOut{sanitized context $\mathcal C^*$}
  $\mathcal C_{\mathrm{surv}}\leftarrow\emptyset$;\quad $\mathcal S_{\mathrm{judge}}\leftarrow\emptyset$\;
  \tcp{Stage 1a: Query-calibrated retrieval-statistics three-way triage}
  \ForEach{$c_i\in\mathcal C_q$}{
    Compute anomaly score $A(q,c_i)=\mathbf w^\top\tilde{\mathbf f}_i$ from the four features in Eq.~\eqref{eq:dynamics_features}\;
    \uIf{$A(q,c_i)>\tau_{\mathrm{high}}$}{Prune $c_i$\tcp*[r]{Red zone: high-risk removal}}
    \Else{
      $\mathcal C_{\mathrm{surv}}\leftarrow\mathcal C_{\mathrm{surv}}\cup\{c_i\}$\tcp*[r]{Green/Gray zone: surviving chunk}
      \lIf{$A(q,c_i)>\tau_{\mathrm{low}}$}{$\mathcal S_{\mathrm{judge}}\leftarrow\mathcal S_{\mathrm{judge}}\cup\{c_i\}$}\tcp*[r]{Gray zone: suspicious chunk}
    }
  }
  \tcp{Stage 1b: Entity--proposition multigraph structural escalation}
  Construct entity--proposition directed multigraph $\mathcal G_q=(\mathcal V_q,\mathcal E_q)$ on $\mathcal C_{\mathrm{surv}}$\;
  \ForEach{$(c_i,c_j)\in\mathcal C_{\mathrm{surv}}\times\mathcal C_{\mathrm{surv}}$ \textnormal{with} $i<j$}{
    \lIf{$\Phi_{\mathrm{prov}}(c_i,c_j)\lor\Phi_{\mathrm{bridge}}(c_i,c_j)\lor\Phi_{\mathrm{conflict}}(c_i,c_j)$}{$\mathcal S_{\mathrm{judge}}\leftarrow\mathcal S_{\mathrm{judge}}\cup\{c_i,c_j\}$}\tcp*[r]{Eq.~\eqref{eq:struct_evidence}}
  }
  \lIf{$\mathcal S_{\mathrm{judge}}=\emptyset$}{\Return{$\operatorname{TOP}_m(\mathcal C_{\mathrm{surv}})$}}\tcp*[r]{fast path: bypass Stage 2 LLM judge}
  \tcp{Stage 2: Cross-source anchored structured LLM adjudication}
  Select cross-source reference anchor $c_{\mathrm{anchor}}$ from $\mathcal C_{\mathrm{surv}}\setminus\mathcal S_{\mathrm{judge}}$ via Eq.~\eqref{eq:anchor}\;
  $\mathcal U\leftarrow\operatorname{JUDGE}_{\mathcal M}(q,c_{\mathrm{anchor}},\mathcal S_{\mathrm{judge}},\mathcal G_q)$\tcp*[r]{3-step proposition \& bridge audit}
  $\mathcal C^*\leftarrow\operatorname{TOP}_m(\mathcal C_{\mathrm{surv}}\setminus\mathcal U)$\;
  \Return{$\mathcal C^*$}\;
\end{algorithm}

\subsection{原型应用系统}

为展示两个研究点的有效性及应用价值，本研究拟设计并实现RAG投毒攻防联合测试系统，将攻击与防御接入相同的知识库、检索器和生成器配置。系统前端用于实验配置与结果展示，后端负责载荷构造、上下文审查与指标统计，主要模块划分如下。

\begin{itemize}[leftmargin=2em,itemsep=0pt]
  \item 攻击测试模块：对应研究点一，执行单源载荷构造、受害者侧分块、联合召回与组合生成验证。
  \item 防御测试模块：对应研究点二，执行检索统计初筛、结构证据升级与结构化判别，并支持与基线方法的统一比较。
  \item 日志审计模块：记录来源标识、块偏移、检索排名、分流决策与最终回答，按独立查询统计安全与效用指标。
  \item 可视化模块：展示源文档与文本块的对应关系、联合召回情况、分流结果及防御前后的证据变化。
  \item 数据库模块：保存数据划分、索引配置、载荷版本、运行日志与评测结果，为实验复现提供数据支持。
\end{itemize}
