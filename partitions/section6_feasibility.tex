\section{研究基础与可行性分析}

\subsection{理论可行性分析}

\textbf{攻击侧条件性理论支撑与方法动机。}研究点一将单源文档受控预算下的跨块前提分离\cite{chang2025oneshot,zhang2026inceptionrag}与分块感知的离散触发器搜索\cite{nie2026crcp,ebrahimi-etal-2018-hotflip,zou2023universal}组织为两阶段解耦框架，其核心数学性质在以下显式条件下成立：
\begin{enumerate}[leftmargin=2em,itemsep=1pt]
  \item \textbf{共同召回的一般排名条件与搜索代理}：对任意分块视图$\phi$，记非角色候选块集合为$\mathcal O_\phi(x)=\mathcal C_v^\phi(x)\setminus\{c_A^{(\phi)},c_B^{(\phi)}\}$，其第$K-1$高分为$t_\phi(x)$。当$K\ge 2$、$|\mathcal O_\phi(x)|\ge K-1$、$c_A^{(\phi)}\neq c_B^{(\phi)}$且候选得分严格全序时，双角色块共同进入Top-$K$当且仅当$\min_{j\in\{A,B\}}s(q,c_j^{(\phi)})>t_\phi(x)$。影子背景阈值$\tau_{q,s}=s_s(q,d_{(K-1)})$作为搜索阶段的常值计算代理，当$D_{\mathrm{adv}}$的其余非角色块得分均低于$\tau_{q,s}$时与$t_\phi(x)$一致；最终验收则直接在完整更新池上按确定性全序统计有效联合召回事件$Z_\phi(x)$。
  \item \textbf{条件性窗口覆盖引理与布局—词元变量分离}：在同一分词器坐标系下，设角色段内左触发器、核心载荷与右触发器的半开词元区间分别为$L=[\ell_0,\ell_1)$、$P=[p_0,p_1)$、$R=[\tilde r_0,\tilde r_1)$（$\ell_1\le p_0<p_1\le\tilde r_0$）。对任意容量为$K_{\mathrm{size}}$的窗口$W=[a,a+K_{\mathrm{size}})$，若$P\subseteq W$且含中间垫片在内的双触发器总包络跨度满足$\tilde r_1-\ell_0\le K_{\mathrm{size}}$，则必有$L\subseteq W$或$R\subseteq W$。同时，凹幂次函数$h_p(w)=1-w^p$（$p>1$）在$(0,1)$上满足$h_p''(w)=-p(p-1)w^{p-2}<0$且$\lim_{p\to\infty}h_p(w)=\mathbb I[w<1]$；在固定分词器坐标、槽位与定长词元替换下有$\partial h_p(w_j(\phi))/\partial e_{t_i}=0$，故$h_p(w_j(\phi))$专门作为阶段间几何布局筛选与完整性评价指标，而固定布局下的定长词元内环则通过跨视图检索间隔损失调整检索信号。
  \item \textbf{等背景受控组合判据}：阶段一固定前$K-2$个高分干净块$B_0$与长度匹配的中性替代块$N_A,N_B$，在相同背景$B_0$下比较$C_{00},C_{10},C_{01},C_{11}$，从实验设计上隔离了“挤占干净竞争块名额”与“跨块前提语义组合”两类效应\cite{liu2024autodan,alon2023detecting,jain2023baseline}。
\end{enumerate}

\textbf{防御侧条件性理论支撑与方法动机。}研究点二构建的双阶段级联机制将经验特征初筛、无分布分位校准与结构化核查相结合：
\begin{enumerate}[leftmargin=2em,itemsep=1pt]
  \item \textbf{拟合—校准划分与经验统计表征}：离线阶段按独立查询与源文档将干净开发数据划分为互不相交的特征拟合集$\mathcal D_{\mathrm{fit}}$与查询级校准集$\mathcal D_{\mathrm{cal}}$。在$\mathcal D_{\mathrm{fit}}$上，当$\beta\in(0,1)$且样本协方差迹$\operatorname{tr}(S)>0$时，Ledoit-Wolf线性收缩估计\cite{ledoit2004well}保证协方差矩阵正定可逆；结合低方差尾谱马氏距离\cite{mahalanobis1936generalized,lee2018simple}、BM25截断奇异值残差\cite{deerwester1990indexing,robertson2009probabilistic}、候选池内查询切法向散度比及块内子窗余弦漂移，提供待在真实攻击流上检验的经验异常评分$A(q,c_i)$。
  \item \textbf{查询级最大异常度校准定理}：针对同一查询内$K$个候选块得分耦合的特性，以独立查询为交换单元，在$\mathcal D_{\mathrm{cal}}$的$n$条可交换干净查询上计算查询级最大异常度$M_j=\max_{1\le i\le K}A(q_j,c_{j,i})$，取$k(\alpha)=\lceil(n+1)(1-\alpha)\rceil$与$\tau_\alpha=M_{(k(\alpha))}$（当$k(\alpha)=n+1$时置$\tau_\alpha=+\infty$）。当新干净查询$q_{\mathrm{new}}$与校准查询在冻结检索与评分协议下可交换时，由秩均匀性与并列分保守秩性质\cite{vovk2005algorithmic,angelopoulos2023conformal}可得有限样本边际误警率上界$\Pr(\exists i:A(q_{\mathrm{new}},c_{\mathrm{new},i})>\tau_\alpha)=\Pr(M_{\mathrm{new}}>\tau_\alpha)\le\alpha$。
  \item \textbf{查询级送审触发率上界与来源分离核查}：在统计通道查询级误警率受$\alpha_{\mathrm{low}}$控制的前提下，由并集界得干净查询的二阶段审查触发率上界$p_{\mathrm{esc}}\le\min\{1,\alpha_{\mathrm{low}}+\rho_{\mathrm{prov}}^{\mathrm{clean}}+\rho_{\mathrm{bridge}}^{\mathrm{clean}}+\rho_{\mathrm{conflict}}^{\mathrm{clean}}\}$；阶段二通过来源标识分离条件$z_{\mathrm{doc}}(c)\notin z_{\mathrm{doc}}(\mathcal S_{\mathrm{judge}})$确保参照锚点来自独立于待审块的外部文档\cite{chiang2023judging,zhang2025traceback,yin2026rade}。
\end{enumerate}

围绕\autoref{tab:exp_setup}，实验按“主设置机制闭环$\rightarrow$攻防对抗与效用权衡$\rightarrow$跨尺度与跨检索器泛化边界”三层递进组织：
\begin{itemize}[leftmargin=2em,itemsep=2pt]
  \item \textbf{第一层：主配置下的单源跨块协同机制验证与归因实验}：在主设置（$K_{\mathrm{size}}=256$、Contriever、$|\mathcal D_{\mathrm{adv}}|=1$）下，完整跑通“源文档改写$\rightarrow$全文分块$\rightarrow$自然Top-$5$检索$\rightarrow$生成”链路，逐题记录布局可行率、重切分后$Z_{\phi_s}$通过率、$\mathcal V_{\mathrm{comp}}^{\mathrm{final}}$通过率与端到端ASR；同时对比固定$K-2$背景$B_0$与中性替代块的四组受控上下文（$C_{00},C_{10},C_{01},C_{11}$及$BA$反序对照）与自然检索回填消融上下文，分别度量受控语义协同效应与自然检索竞争行为，并统计影子至受害者模型的迁移差$\Delta_{\mathrm{gen}}$。
  \item \textbf{第二层：多类投毒下的鲁棒防御、多跳证据保留与延迟分解实验}：在涵盖检索操纵、单点投毒与研究点一跨块组合投毒的混合攻击集及多跳干净集上，对比五项代表性防御基线；联合报告查询级校准下的经验误警率、检出率、残余ASR、攻击下ACC、$\Delta\mathrm{CACC}$、$\mathrm{Gap}_{\mathrm{other}}$、多跳桥接保留率$\mathrm{BR}$、触发率$p_{\mathrm{esc}}$及式\eqref{eq:latency_decomp}的各阶段耗时均值，并对四维统计特征、三类多重图结构指示器与异源锚点分离约束开展逐通道消融。
  \item \textbf{第三层：未知分块边界鲁棒性与跨检索器迁移边界实验}：在$K_{\mathrm{size}}\in\{128,256,512\}$三档分块容量、多相位验收视图集及BM25、Contriever-MS、ANCE、BGE-m3四类黑盒检索器上评测跨配置有效联合召回率$\widehat p_{\mathrm{joint}}$、逐分词器重算跨度后的角色保持率与迁移ASR，明确方法在不同分块粒度与检索范式下的实证性能边界。
\end{itemize}

\subsection{实验可行性分析}

\textbf{前期研究基础。}本研究前期已建成覆盖NQ、MS MARCO和HotpotQA三个数据集的统一评测底座，完成了Contriever、Contriever-MS、ANCE、BGE-m3和BM25五类检索器在多档分块容量下的同分块对齐索引。在基线评测方面，已完成全量20,428条查询的检索与生成覆盖运行，并在具备标准QA参考标签的17,036条查询/检索器分母上完成了$K_{\mathrm{size}}=256,K=5$主设置的干净语义回答准确率（ACC）标定（Contriever在NQ、HotpotQA、MS MARCO上的语义ACC分别为$71.31\%$、$47.68\%$与$60.13\%$，BGE-m3分别为$80.01\%$、$62.75\%$与$71.75\%$，BM25分别为$71.81\%$、$64.43\%$与$63.61\%$）。在攻击先导探索方面，前期手工Top-5概念验证（4个干净回答正确的目标实例）中有3例实现双块共同进入自然Top-5并命中目标答案，其中1例医院计数查询展现出自然双角色块依赖；在50条查询、150个候选载荷的独立增补诊断实验中，Contriever下后缀触发与前后缀触发分别在$49.0\%$与$24.1\%$的样本上保持了高检索排名；同时，前期闭环验收脚本已调通完整角色跨度判定与精确排名核验门禁。上述前期结果为本研究提供了可复现的工程底座与存在性先导证据，而在等背景受控判据$\mathcal V_{\mathrm{comp}}$与全文重切分约束下实现稳定的自动化双块联合Top-$K$搜索及跨配置迁移，正是本课题拟重点攻克与评测的核心研究内容。

\textbf{检索缓存适用条件与评测协议可行性。}系统已为每条查询预计算缓存了Top-1000检索排名与查询向量。对于编码器参数固定、背景块向量恒定的稠密检索器（Contriever、Contriever-MS、ANCE、BGE-m3），当替换更新源文档时，只要完整移除旧源文档所属的全部切分块、纳入新源文档切分出的全部文本块、采用一致的确定性并列分全序，且移除旧块后缓存深度内仍保留至少$K$个有效候选块，增量归并即可精确还原全库Top-$K$排序。对于BM25检索器，由于替换源文档会更新语料库逆文档频率（IDF）与平均文档长度，进而影响背景文档之间的相对得分顺序，实验中将明确区分“冻结语料IDF的快速近似归并协议”与“更新语料统计量的完整BM25重算协议”，保持跨基线对比口径一致。

\textbf{硬件资源条件可行性。}本研究依托自筹的高性能计算工作站开展实验，前期已完成核心算子与生成服务的基准耗时实测：在RTX 4090上，稠密检索编码器批处理前向（Batch=32）耗时约$9.06\text{ ms}$，单步HotFlip梯度替换约$5.53\text{ ms}$；本地部署的Qwen3.8-27B-FP8 LLM生成服务单次短回答生成耗时约$1.84\text{s}$。
据此测算，研究点一阶段二的分块鲁棒触发器优化在单张RTX 4090上单条目标查询耗时约$2\sim 4$分钟，标准评测查询集的离线载荷构造可在$15\sim 20$小时内完成。研究点二阶段一的矩阵谱运算耗时$T_{\mathrm{stat}}<2\text{ ms}$，块内子窗编码$T_{\mathrm{sub}}$约$20\sim 40\text{ ms}$，轻量级实体—命题构图$T_{\mathrm{graph}}$约$10\sim 25\text{ ms}$，绝大多数干净查询在阶段一即可直接放行，仅对少量进入待审集$\mathcal S_{\mathrm{judge}}$的查询按概率$p_{\mathrm{esc}}$执行单次结构化判别。围绕前期已本地化集成的PoisonedRAG、CorruptRAG、InceptionRAG、CamoDocs及RAGDefender、TrustRAG、RobustRAG、TRIS等十余项代表性攻防基线，结合本地检索归并缓存，整个实验矩阵的单轮评估总耗时可控制在$30\sim 45$小时以内，实验算力与时间成本可控。
