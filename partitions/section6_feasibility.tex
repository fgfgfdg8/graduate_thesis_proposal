\section{研究基础与可行性分析}

\subsection{理论可行性分析}

\textbf{攻击侧理论基础。}本研究提出的同源多文本块协同投毒框架建立在检索增强生成投毒建模与离散对抗优化两方面的成熟研究基础之上。在生成诱导与多文本协同方面，Zou等\cite{zou2025poisonedrag}提出的检索与生成双条件联合建模框架确立了知识库投毒的形式化分析范式，Chang等\cite{chang2025oneshot}与Zhang等\cite{zhang2026inceptionrag}进一步证实大语言模型在推理阶段具备整合跨段落证据链与三段论互补前提以导出指定结论的上下文演绎能力，为本研究在单一源文档内解耦通用规则块$\mathcal P_A$与实例绑定块$\mathcal P_B$提供了生成机理依据。在未知分块下的检索优化方面，Ebrahimi等\cite{ebrahimi-etal-2018-hotflip}提出的HotFlip与Zou等\cite{zou2023universal}提出的GCG证明利用词元嵌入的一阶泰勒梯度初筛结合前向精确重评可有效求解离散文本搜索问题，Nie等\cite{nie2026crcp}则验证了将分块切分建模为随机边界变换并在多切分视图上优化期望损失的可行性。上述前人工作为本研究采用两阶段解耦策略、在固定核心载荷语义的前提下通过双侧触发器交替坐标搜索提升双块共同召回率提供了扎实的理论支撑。

\textbf{防御侧理论基础。}本研究提出的两阶段级联防御方法依托于高维表示空间分布外检测、无分布共形分位校准以及结构化冲突核验的既有理论成果。在单块检索统计表征方面，Mahalanobis\cite{mahalanobis1936generalized}与Lee等\cite{lee2018simple}建立的马氏距离检测理论表明对抗扰动在低方差特征子空间中会产生显著的统计偏离，Ledoit与Wolf\cite{ledoit2004well}提出的线性收缩估计保证了高维有限样本下协方差矩阵的正定可逆性，而Deerwester等\cite{deerwester1990indexing}的潜在语义分析理论则为度量稀疏词项偏离语料主子空间的残差能量提供了数学工具，共同构成了阶段一构造四维检索统计特征的理论基础。在阈值设定方面，Vovk等\cite{vovk2005algorithmic}与Angelopoulos等\cite{angelopoulos2023conformal}发展的可交换样本顺序统计量与共形预测理论证明，基于独立干净校准集的分位数阈值可在无需先验分布假设的条件下严格约束新查询的边际假阳性率上界。在跨块关系与语义复核方面，成熟的开放域关系抽取技术\cite{honnibal2020spacy,angeli2015leveraging}以及经Zheng等\cite{chiang2023judging}、Zhang等\cite{zhang2025traceback}和Yin等\cite{yin2026rade}验证的大语言模型证据审计范式，为本研究利用实体—命题捕获跨块关联并结合异源参照文本执行单次复核提供了可靠的方法学依据。综上，本课题在攻防两侧均具备坚实的理论基础。

\subsection{实验设计与评价方法}

\textbf{实验配置。}本研究在统一的实验环境与分层评测协议下对两个研究点开展实验评估，具体的数据集、分块尺度、检索器矩阵与对比基线配置如\autoref{tab:exp_setup}所示。

\textbf{主要评价指标。}设评测查询集合为$\mathcal Q$（样本数$N=|\mathcal Q|$），固定评估分块视图集合为$\Phi_{\mathrm{eval}}$，查询$q\in\mathcal Q$对应的候选投毒源文档$x_q$在$\Phi_{\mathrm{eval}}$上的结构有效视图子集为$\Phi_{\mathrm{eval}}^+(x_q)=\{\phi\in\Phi_{\mathrm{eval}}:I_A(\phi)=1\land I_B(\phi)=1\land c_A^{(\phi)}\neq c_B^{(\phi)}\}$，各项评价指标的定义与计算式如下：
\begin{itemize}[leftmargin=2em,itemsep=2pt]
  \item \textbf{端到端攻击成功率（$\mathrm{ASR}$）}：度量目标系统最终生成的回答$\hat y_q$被语义判定器$J$判定为命中预设错误答案$a_q^*$的查询比例，计算式为 $\mathrm{ASR}=\frac{1}{N}\sum_{q\in\mathcal Q}\mathbb I\big[J(q,a_q^*,\hat y_q)=1\big]$。
  % \item \textbf{结构有效覆盖率（$v$）}：度量候选投毒源文档在评估分块视图集中保持双角色完整且落入不同分块的比例，计算式为 $v=\frac{1}{N}\sum_{q\in\mathcal Q}\frac{|\Phi_{\mathrm{eval}}^+(x_q)|}{|\Phi_{\mathrm{eval}}|}$。
  % \item \textbf{条件共同召回率（$r$）}：度量在结构有效视图非空的查询子集$\mathcal Q^+=\{q\in\mathcal Q:\Phi_{\mathrm{eval}}^+(x_q)\neq\emptyset\}$上两个角色块共同进入Top-$K$检索结果的比例，计算式为 $r=\frac{1}{|\mathcal Q^+|}\sum_{q\in\mathcal Q^+}\frac{1}{|\Phi_{\mathrm{eval}}^+(x_q)|}\sum_{\phi\in\Phi_{\mathrm{eval}}^+(x_q)}Z_\phi(x_q)$。
  \item \textbf{总体共同召回率（$p$）}：度量攻击侧候选投毒源文档在全部评估分块视图上的总体双块共同召回率（无效视图计为$0$，单题满足$p_q=v_q r_q$），计算式为 $p=\frac{1}{N}\sum_{q\in\mathcal Q}\frac{1}{|\Phi_{\mathrm{eval}}|}\sum_{\phi\in\Phi_{\mathrm{eval}}}Z_\phi(x_q)$。
  % \item \textbf{受控组合判据通过率（$\mathrm{Pass}_{\mathrm{comp}}$）}：度量固定背景四组对照上下文中满足单块均不命中、双块联合命中目标答案$a_q^*$的查询比例，计算式为 $\mathrm{Pass}_{\mathrm{comp}}=\frac{1}{N}\sum_{q\in\mathcal Q}\mathcal V_{\mathrm{comp}}(x_q)$。
  \item \textbf{回答准确率（$\mathrm{ACC}$）与干净准确率变化量（$\Delta\mathrm{CACC}$）}：分别度量攻击侧系统输出命中标准答案$y_{q,\mathrm{true}}$的查询比例及部署防御策略$\pi$前后的干净准确率差值，计算式为 $\mathrm{ACC}=\frac{1}{N}\sum_{q\in\mathcal Q}\mathbb I\big[J(q,y_{q,\mathrm{true}},\hat y_q)=1\big]$ 与 $\Delta\mathrm{CACC}=\mathrm{ACC}_{\mathrm{clean}}(\pi)-\mathrm{ACC}_{\mathrm{clean}}(\mathrm{id})$。
  % \item \textbf{非目标残余响应率（$\mathrm{Gap}_{\mathrm{other}}$）}：在互斥判分准则下度量既未命中标准答案也未命中目标答案（涵盖拒答、无关回答及其他非目标错误回答）的查询比例，计算式为 $\mathrm{Gap}_{\mathrm{other}}=\frac{1}{N}\sum_{q\in\mathcal Q}\mathbb I\big[J(q,y_{q,\mathrm{true}},\hat y_q)=0\land J(q,a_q^*,\hat y_q)=0\big]=1-\mathrm{ACC}-\mathrm{ASR}$。
 %  \item \textbf{影子—受害者生成迁移差（$\Delta_{\mathrm{gen}}$）}：度量双块竞争上下文$C_{11}$在影子生成模型与受害者生成模型上的目标答案命中率之差，计算式为 $\Delta_{\mathrm{gen}}=\frac{1}{N}\sum_{q\in\mathcal Q}\Big(\mathbb I\big[J(q,a_q^*,G_{\mathrm{shadow}}(q,C_{11}))=1\big]-\mathbb I\big[J(q,a_q^*,G_\omega(q,C_{11}))=1\big]\Big)$。
  % \item \textbf{多跳桥接证据保留率（$\mathrm{BR}$）}：设多跳查询集$\mathcal Q_{\mathrm{mh}}$中查询$q$在候选集$\mathcal C_q$内的真实支撑事实块子集为$\mathcal G_q^{\mathrm{gold}}\subseteq\mathcal C_q$，防御过滤后上下文为$\mathcal C_q^*=\pi(\mathcal C_q)$，计算式为 $\mathrm{BR}=\frac{1}{|\mathcal Q_{\mathrm{mh}}|}\sum_{q\in\mathcal Q_{\mathrm{mh}}}\frac{|\mathcal C_q^*\cap\mathcal G_q^{\mathrm{gold}}|}{|\mathcal G_q^{\mathrm{gold}}|}$。
  \item \textbf{假阳性率（$\mathrm{FPR}_q$）}：度量防御侧干净查询集$\mathcal Q_{\mathrm{clean}}$中触发高阈值直接剔除的查询比例，计算式为 $\mathrm{FPR}_q=\frac{1}{|\mathcal Q_{\mathrm{clean}}|}\sum_{q\in\mathcal Q_{\mathrm{clean}}}\mathbb I\big[\max_{c_i\in\mathcal C_q}A(q,c_i)>\tau_{\mathrm{high}}\big]$。
\end{itemize}

围绕\autoref{tab:exp_setup}，拟依次开展以下四组实验：
\begin{itemize}[leftmargin=2em,itemsep=2pt]
  \item \textbf{攻击实验}：在主配置与单一源文档改写约束下，完整执行源文档改写、受害者侧分块、自然Top-$5$检索与回答生成流程，并结合固定背景四元组受控对照以及自然检索上下文的配对移除回填对照开展归因分析。该实验旨在解决单一源文档切分出的同源文本块能否在真实检索竞争中共同召回并协同操纵生成输出这一核心问题，用于分离检索席位挤占效应与跨块前提合成效应，验证单块证据不足而双块协同导出目标答案的攻击机制。
  \item \textbf{防御实验}：在涵盖检索排名操纵、单点直接投毒与同源跨块组合投毒的混合攻击数据以及正常多跳问答数据上，将所提防御方法与代表性过滤及聚合基线进行同口径对比，并严格隔离未参与开发调参的攻击类型以检验跨攻击泛化能力。该实验旨在解决防御机制如何在阻断隐蔽组合投毒的同时避免误删正常跨块桥接证据并控制在线计算开销的问题，用于验证两阶段级联防御在安全性、问答效用与推理延迟三者之间的综合权衡效果。
  \item \textbf{迁移实验}：将主配置下构造的投毒源文档与防御方法扩展至多种分块窗口容量、切分起始相位以及不同训练范式的词项与稠密检索器上进行测试。该实验旨在解决攻防方法对受害者侧未知分块参数与异构检索表示空间的适应性问题，通过考察跨分块配置下的角色完整性保持能力与跨检索器迁移表现，明确所提攻防框架在不同系统环境下的适用范围与性能边界。
  \item \textbf{消融实验}：在主配置下分别对研究点一的段落插入位置预选、双侧触发器布局与跨视图软间隔检索损失，以及研究点二的四维检索统计特征、实体—命题图关系检查与异源参照文本约束开展逐项移除对照。该实验旨在回答攻防框架中各子模块是否提供独立增益的问题，通过考察移除单一组件前后的检索召回、组合生成、投毒检出与多跳证据保留变化，验证两阶段解耦构造与统计—关系级联复核设计的必要性。
\end{itemize}

\subsection{实验可行性分析}

\textbf{前期研究基础。}本研究前期已建成覆盖NQ、MS MARCO和HotpotQA三个数据集的统一评测底座，完成了Contriever、Contriever-MS、ANCE、BGE-m3和BM25五类检索器在多档分块容量下的同分块对齐索引。在基线评测方面，已完成全量20,428条查询的检索与生成覆盖运行，并在具备标准QA参考标签的17,036条查询/检索器分母上完成了$K_{\mathrm{size}}=256,K=5$主设置的干净语义回答准确率（ACC）标定（Contriever在NQ、HotpotQA、MS MARCO上的语义ACC分别为$71.31\%$、$47.68\%$与$60.13\%$，BGE-m3分别为$80.01\%$、$62.75\%$与$71.75\%$，BM25分别为$71.81\%$、$64.43\%$与$63.61\%$）。在攻击先导探索方面，前期手工Top-5概念验证（4个干净回答正确的目标实例）中有3例实现双块共同进入自然Top-5并命中目标答案，其中1例医院计数查询展现出自然双角色块依赖；在50条查询、150个候选载荷的独立增补诊断实验中，Contriever下后缀触发与前后缀触发分别在$49.0\%$与$24.1\%$的样本上保持了高检索排名；同时，前期已完成完整角色跨度判定与精确排名核验流程的联调测试。上述前期工作为本研究提供了扎实的数据底座与先导实验依据，而在等背景受控组合判据与全文重切分约束下实现稳定的自动化双块联合Top-$K$搜索及跨配置迁移，正是本课题拟重点攻克与评测的核心研究内容。

\textbf{研究资源可行性。}本研究依托自筹的高性能计算工作站开展实验，前期已完成局部算子与单次生成服务的基准耗时实测：在RTX 4090上，稠密检索编码器批处理前向（Batch=32）耗时约$9.06\text{ ms}$，单步HotFlip梯度替换约$5.53\text{ ms}$；本地部署的Qwen3.8-27B-FP8 LLM生成服务单次短回答生成耗时约$1.84\text{ s}$。攻击实验使用三个数据集中各抽样100题获取的300题子集，主要涵盖金融、法律、生物医学和科学事实问答等重要领域，以保证问题的典型性。按阶段二单题$2\sim 4$分钟的估算，单张RTX 4090完成一次300题阶段二优化约需$10\sim 20$小时；阶段一构造及其重试、迁移评价和防御测试另行计时。研究点二阶段一的矩阵谱运算耗时$T_{\mathrm{stat}}<2\text{ ms}$，块内子窗编码$T_{\mathrm{sub}}$约$20\sim 40\text{ ms}$，轻量级实体—命题构图$T_{\mathrm{graph}}$约$10\sim 25\text{ ms}$，阶段二LLM复核耗时按实测送审触发率$p_{\mathrm{esc}}$与单次判别耗时计算。围绕前期已本地化集成的PoisonedRAG、CorruptRAG、InceptionRAG、CamoDocs及RAGDefender、TrustRAG、RobustRAG、TRIS等代表性攻防基线，结合本地检索归并缓存，总体算力与时间成本可控。
