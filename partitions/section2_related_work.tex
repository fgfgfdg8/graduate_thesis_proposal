\section{相关研究现状}

\subsection{检索增强生成技术研究现状}

检索增强生成技术的相关研究主要围绕外部知识检索与生成联合建模、检索器训练以及检索上下文组织等方面展开。

领域早期研究探索了将外部知识与语言模型结合的模式。Guu等\cite{guu2020realm}提出的REALM将检索文档作为隐变量，用掩码语言建模任务提供训练信号，联合学习知识检索与信息利用；Lewis等\cite{lewis2020retrieval}提出检索增强生成框架，将预训练生成式语言模型与稠密检索器整合，将检索结果纳入生成模型的输入。Izacard等\cite{izacard2021leveraging}提出的FiD分别编码查询与多段证据，再由解码器通过交叉注意力融合这些表示以生成答案。

在知识库构建方面，RAG系统通常将原始文档进行解析、清洗和分块，转换为可索引的检索单元。文档分块策略包括固定长度、句子或段落边界、语义分块以及重叠窗口，固定长度、自然边界和重叠窗口分别影响输入规模、语义完整性和边界截断。同一源文档产生的多个文本块可能分别包含回答所需的不同事实，也可能因重叠而包含相同内容\cite{gao2023retrieval}。因此，源文档到检索单元的转换会改变证据的组织方式，分块与检索策略共同影响RAG系统的检索与生成表现\cite{liu2025ragsurvey,yuan2026ragoptimization}。

在文本表示与检索方面，常见检索方式包括稀疏检索、稠密检索与混合检索：稀疏检索依据词项匹配及统计权重衡量相关性，稠密检索通过编码器将查询与文本映射为连续向量并按内积或余弦相似度搜索候选，混合检索融合稀疏与稠密检索的分数或排名\cite{liu2025ragsurvey,yuan2026ragoptimization}。Karpukhin等\cite{karpukhin2020dense}提出的稠密段落检索（Dense Passage Retrieval，DPR）采用双编码器分别表示查询和段落，利用问答相关性标注、批内负样本及难负样本训练模型，支持大规模向量预计算与检索。针对批内负样本难以反映全库检索竞争的问题，Xiong等\cite{xiong2021approximate}提出的近似最近邻负例对比估计方法（Approximate Nearest Neighbor Negative Contrastive Estimation，ANCE）从全语料的近似最近邻索引中选取难负样本，并随训练异步更新文档表示与索引。在无标注场景下，Izacard等\cite{izacard2022unsupervised}提出的Contriever利用同一文档的随机裁剪片段构造正样本，结合词元删除、动量编码器和负样本队列开展无监督对比学习，并使用微软机器阅读理解数据集（Microsoft MAchine Reading COmprehension，MS MARCO）\cite{bajaj2018msmarcohumangenerated}微调得到Contriever-MS模型。

经过检索召回后，系统可对候选文本重排序，并按上下文长度预算选择和排列证据\cite{gao2023retrieval,liu2025ragsurvey,yuan2026ragoptimization}。生成模型最终接收的是经过分块、检索排序和上下文组织后的证据集合，RAG系统的安全问题因而涉及从文档摄入分块到检索上下文组织的整条链路。

\subsection{检索增强生成系统投毒攻击研究现状}

现有RAG投毒攻击研究由检索排名操纵扩展至检索与生成联合投毒，并涉及单文档预算、后门触发、分块适应及多文本组合等设置。

早期NLP对抗攻击通过词元修改影响模型输出。Ebrahimi等\cite{ebrahimi-etal-2018-hotflip}提出的HotFlip将输入文本表示为one-hot向量，利用梯度估计词元替换的影响，实验表明少量词元替换可改变模型的分类结果；Wallace等\cite{wallace2019universal}通过梯度搜索构造通用对抗触发序列，将该序列附加到不同输入上以诱导目标输出；Zou等\cite{zou2023universal}提出的贪心坐标梯度方法（Greedy Coordinate Gradient，GCG）结合贪心搜索与梯度估计生成可迁移对抗后缀。词元搜索可能产生不自然的词元组合，使文本偏离自然语言分布，Liu等\cite{liu2024autodan}在AutoDAN中指出此类后缀容易被基于困惑度（Perplexity，PPL）的检测器识别，并采用分层遗传搜索生成可读性更高的对抗提示。

面向RAG系统的定向知识投毒通常同时考虑进入检索结果和影响最终回答。在检索操纵研究方面，Zhong等\cite{zhong-etal-2023-poisoning}提出的对抗段落注入方法从自然段落出发，利用基于梯度的词元替换最大化攻击段落与训练查询集合的平均嵌入相似度，并通过聚类生成多个攻击段落以提升未见查询上的Top-$k$检索排名；Ben-Tov等\cite{ben2025gasliteing}提出的GASLITE在不依赖目标语料内容、保持检索模型参数固定的条件下，通过嵌入空间梯度搜索构造携带指定信息且针对目标查询分布获得高检索排名的文本，并评估了在多种稠密检索器上的攻击迁移效果。这类方法主要优化攻击文本自身的检索排名，未直接建模恶意内容进入上下文后与正常证据的生成竞争。

在检索与生成联合投毒方面，Zou等\cite{zou2025poisonedrag}提出的PoisonedRAG将知识库投毒形式化为检索条件与生成条件联合满足的优化问题，把攻击文本拆分为检索子串与生成子串；实验显示，在其百万级文本知识库设置中，注入5条投毒文本即可影响目标问答并诱导模型输出指定答案。Chang等\cite{chang2025oneshot}提出的AuthChain则面向多跳问答，将投毒预算限制为单个文档，通过提取查询意图、证据节点及关系构造自洽证据链，使单个投毒文档在进入检索结果后影响多跳生成。Zhang等\cite{zhang2026corruptrag}提出的CorruptRAG同样将攻击预算限制为单个投毒文本，联合设计文本的检索相关性与生成诱导内容，分析单文档预算下的知识投毒效果。

在训练后门与触发式攻击方面，Cheng等\cite{cheng2024trojanrag}提出的TrojanRAG利用对比学习与正交优化微调检索器参数，在检索器中植入触发词后门；Chaudhari等\cite{chaudhari2026phantom}提出的Phantom在不修改模型参数的条件下构造触发式单文档攻击，先通过嵌入优化使文档在查询包含特定触发词时进入检索结果，再利用多坐标梯度优化生成诱导拒答、偏见输出或信息泄露的对抗文本。上述单文档与触发式方法采用不同的攻击权限和优化目标；其攻击载荷主要集中在单一文本内部，未利用同源分块之间的信息分工。

在分块适应与多文本组合方面，Nie等\cite{nie2026crcp}提出的CRCP关注文档级攻击信号在受害者侧分块和重排序过程中的损失，将分块与重排序纳入优化约束以保持单个攻击块的检索与生成效果。Zhang等\cite{zhang2026inceptionrag}提出的InceptionRAG研究多文本逻辑组合投毒，分别构造关联代理实体与目标答案的属性文本以及建立实体等价关系的桥接文本，并利用零阶后缀优化（Zeroth-Order Suffix Optimization，ZOSO）提升检索概率；该方法假设攻击者直接向知识库写入多个独立检索单元，未建模单一源文档经受害者侧分块形成多个同源检索单元的过程。

综上，已有投毒研究大多将注入文本直接视为独立检索单元，而在实际RAG流程中，外部源文档通常需经受害者侧分块后才以多个文本块参与检索。本研究关注攻击者仅控制单个源文档、分块策略由受害者系统决定时，该源文档切分出的多个同源文本块能否分别承担互补前提、共同进入检索结果并在生成阶段组合导出目标答案。

\subsection{检索增强生成系统防御研究现状}

现有RAG投毒防御研究主要围绕恶意文本过滤、检索上下文关系分析、鲁棒证据聚合以及生成结果责任归因等方向展开。

在检索后文本检测与过滤方面，Kim等\cite{kim2025gmtp}提出的梯度掩码词元概率方法（Gradient-based Masked Token Probability，GMTP）利用检索相似度对词元的梯度定位高影响位置，再以掩码语言模型计算这些词元的条件概率，结合检索贡献与语言流畅度识别异常词元；自然语言改写可能减弱这类词元异常信号。Kim等\cite{kim2025ragdefender}提出的RAGDefender利用检索结果之间的相似性与聚集结构识别异常段落，计算开销较低；当攻击者通过多个语义互补、内容差异较大的文本块组合实施投毒时，各攻击块不易形成高相似度簇。

在检索上下文结构分析方面，Zhou等\cite{zhou2025trustrag}提出的TrustRAG结合聚类过滤与模型自评估处理知识冲突；Zheng等\cite{zheng2025grada}提出的GRADA在重排序阶段依据文档相似性构造加权图，通过得分传播与查询相关性修正识别异常文本。TrustRAG结合聚类结构与模型知识，GRADA依赖文档图上的相关性与得分传播；当投毒块与正常文本保持相似连接模式时，结构信号可能难以区分二者，而正常多跳问答中的低连接桥接段落也可能被误判。Moradi等\cite{cegrag2026}提出的CEG-RAG利用上下文表示进行投毒检测，提取交叉编码重排序器的最后一层表示并通过多实例学习定位异常文本块，但其建模对象仍为单块实例异常，未显式刻画跨块前提组合。

在生成阶段的鲁棒证据聚合方面，Xiang等\cite{xiang2024certifiably}提出的RobustRAG对检索文本分组独立生成答案后再聚合，在受限投毒比例下提供可证明鲁棒性；Tan等\cite{tan2026prarag}提出的PRA-RAG通过固定规模文本子集的表示空间分析选取代表性证据邻域；He等\cite{he2026shieldrag}提出的ShieldRAG利用滑动窗口组织多组证据并基于共识信息调整表示空间。这类方法依赖正常证据占多数并能形成语义共识；在正常多跳问答中，拆分证据组可能隔断跨块推理链，而多组候选生成或子集搜索也会增加在线推理延迟。

在生成结果责任归因与事后取证方面，Yin等\cite{yin2026rade}提出的RADE先生成临时回答，再估计各检索文本对生成路径的有向影响与相对共识的语义风险，利用正常校准样本上的一致性分位数设定阈值，以区分有害文本与正常桥接文本。Zhang等\cite{zhang2025traceback}提出的RAGForensics以查询和已发生的错误回答为输入，调用大语言模型逐条判断候选文本是否支持该错误回答；Zhang等\cite{zhang2026ragorigin}提出的RAGOrigin结合检索排名、语义相关性和生成影响计算责任分数并聚类隔离投毒文本，用于定位与错误回答相关的投毒文本。这些工作主要面向错误回答产生后的归因分析或需先执行临时生成，与生成前在线过滤的任务设置不同。

综合来看，现有防御方法主要依赖单块统计异常、集合高相似度聚类或多轮分组生成。在跨块组合投毒下，单个攻击块可保持自然表述，而正常多跳问答同样包含同源远距段落或跨块实体桥接。为此，本文将在现有研究的基础上，进一步研究结合检索统计特征与跨块关系的投毒检测方法，以增强RAG系统在隐蔽型分布式投毒下的可靠性和安全性。
